## 生成步骤（已跑通）

1. **解析引脚**：官方符号 4 个 unit → 49 脚主键名 + 完整 pinmux
2. **Capture XML**：异构 4 分符，`File → Import → Library XML`
3. **焊盘 pxml**：`r85_20` / `r20_85` / `r420`，`padstack_editor -x`
4. **封装脚本**：`allegro -nograph -s QFN48_6X6_P0D4.scr`
5. **入库**：`.pad` → `01Pad_lib`，`.dra/.psm` → `01Psm_lib`

## Capture 导入

1. OrCAD Capture CIS 17.2 → `File` → `Import` → `Library XML`
2. 选 `ul_HPM5361IEG1\OrcadCaptureXML\2026-08-14_18-21-03.xml`
3. 另存为 `01captureLib\HPM5361IEG1.OLB`
4. 放置时只用 **U?A / U?B / U?C / U?D**

## 电源注意（IEG1）

- `VPMC` 与 `DCDC_IN` **内部共用**，接 3.3 V
- `DCDC_LP` 若软件关 DCDC：**悬空，禁止接地**
- `VSS`(49) 散热焊盘必须焊到 GND
- 多个 `VDD_SOC` / `VIO_B00` 同名 Power，Capture 会自动短接
- `PA00` = ISP_UART_TX，`PA01` = ISP_UART_RX，`PA24` = USB_DP，`PA25` = USB_DM
