# 三路 Buck-Boost 电源架构设计要点

> 主控：先楫半导体 **HPM6284IEP2**（BGA116）  
> 拓扑：四开关同步 Buck-Boost；CH1 两组 DCDC 交错并联  
> 输入：三路独立，每路 **4.5–60 V**  
> 文档用途：外设分配、传感方案、保护与控制策略备忘

---

## 1. 系统指标

| 通道 | 输出电压 | 输出电流 | 开关频率 | 拓扑说明 |
|------|----------|----------|----------|----------|
| CH1 | 12 V | 100 A | **150 kHz**/相（交错后纹波 ~300 kHz） | 两组四开关 Buck-Boost **交错并联**（相位差 180°） |
| CH2 | 5 V | 30 A | **250 kHz** | 单路四开关 Buck-Boost |
| CH3 | 3.3 V | 30 A | **300 kHz** | 单路四开关 Buck-Boost |

功能需求：

- 过压保护（OVP）
- 过流保护（OCP）
- 电压输出模式（CV）
- 电流输出模式（CC）

## 2. 整体架构

```
                    ┌─────────────────────────────────────────────┐
                    │              HPM6284IEP2                    │
                    │  PWM0(HR)→CH1  PWM1(HR)→CH2  PWM2→CH3       │
                    │  ADC0/1/2 快环   ACMP 硬件封锁   SPI0→INA229 │
                    └─────────────────────────────────────────────┘
                         │              │              │
         ┌───────────────┼──────────────┼──────────────┼───────────┐
         │               │              │              │           │
    Vin1 4.5-60V    Vin2 4.5-60V   Vin3 4.5-60V    调试/CAN/USB
         │               │              │
    ┌────┴────┐     ┌────┴────┐    ┌────┴────┐
    │ CH1×2   │     │  CH2    │    │  CH3    │
    │ 交错BB  │     │  BB     │    │  BB     │
    └────┬────┘     └────┬────┘    └────┬────┘
         │               │              │
      12V/100A         5V/30A        3.3V/30A
```

每相交错 / 每路四开关：

- 输入桥臂：HS + LS（互补 + 死区）
- 输出桥臂：HS + LS（互补 + 死区）
- 合计 **4 路 PWM / 相（路）**；CH1 两相共 **8 路 PWM**

## 3. 开关频率分配

### 3.1 推荐取值

| 通道 | 每相开关频率 \(f_{sw}\) | 输出纹波等效频率 | 选取理由 |
|------|------------------------|------------------|----------|
| CH1（12V/100A，2 相交错） | **150 kHz**（可调 100–200 kHz） | **300 kHz**（2×） | 电流大，优先降开关损耗与温升；交错抬高纹波频率，电感可不大 |
| CH2（5V/30A） | **250 kHz**（可调 200–300 kHz） | 250 kHz | 功率中等，体积与效率折中 |
| CH3（3.3V/30A） | **300 kHz**（可调 250–350 kHz） | 300 kHz | 低压小电流相对好做，略抬频率缩小磁性件 |

**默认定频方案（推荐落板值）：**

- CH1 PhaseA / PhaseB：**150 kHz**，相位差 **180°**
- CH2：**250 kHz**
- CH3：**300 kHz**

### 3.2 为什么这样分

1. **CH1 必须偏低**：100 A × 开关损耗（尤其 Vin 到 60 V）是热设计瓶颈；150 kHz 便于选 60–100 V MOSFET，效率优先。
2. **交错补偿纹波**：单相 150 kHz 时输出电流纹波等效约 300 kHz，输入电流纹波也改善，电容压力下降。
3. **CH2/CH3 可略高**：30 A 损耗可接受，略高 \(f_{sw}\) 换更小电感与输出电容。
4. **三路不同频**：刻意错开（150 / 250 / 300），减轻共地/机壳上的差拍与 EMI 尖峰堆叠；若同机箱 EMC 仍差，可再微调 ±10–20 kHz。
5. **MCU 能力够用**：HPM6284 HRPWM 100 ps，在 150–300 kHz 下占空比分辨率充足；PWM 触发 ADC 做峰值/谷值采样也从容。

### 3.3 与磁性件、控制环的对应关系（粗算方向）

| 通道 | \(f_{sw}\) | 单相电感电流纹波目标（经验） | 控制环提示 |
|------|------------|------------------------------|------------|
| CH1 每相 | 150 kHz | \(\Delta I_L \approx 20\%\sim40\%\) 单相平均电流（约 50 A） | 电流环带宽约 \(f_{sw}/10\sim f_{sw}/6\)；均流环更慢 |
| CH2 | 250 kHz | \(\Delta I_L \approx 20\%\sim40\%\) of 30 A | 电压环带宽低于电流环约 5–10 倍 |
| CH3 | 300 kHz | 同上 | 同 CH2 |

四开关 Buck-Boost 在 **Buck / Boost / 过渡区** 占空比与有效伏秒不同，电感按 **最恶劣 Vin（4.5 V 与 60 V）** 分别核算，取较大者。

### 3.4 可调范围与禁忌

| 场景 | 建议 |
|------|------|
| 追求极致效率 / 散热紧 | CH1 降到 **100–120 kHz**（电感变大） |
| 追求体积 | CH1 提到 **200 kHz**；CH2/CH3 提到 **350–400 kHz**（开关损耗与 EMI 变差） |
| 同频同步（便于共时钟） | 可统一 **200 kHz**，CH1 仍 180° 交错；EMI 可能不如错频 |
| 音频噪声 | 全部 \(f_{sw} \ge 100\,\mathrm{kHz}\)，避免可闻啸叫 |
| 死区 | 按驱动与 MOSFET \(t_d\) 设，常见 **50–150 ns**，高频时占比增大，需计入效率 |

### 3.5 PWM 模块与频率对应

| 通道 | PWM 模块 | \(f_{sw}\) | 同步 |
|------|----------|------------|------|
| CH1 | PWM0（HRPWM） | 150 kHz | PhaseB = PhaseA + 180°（TRGM/SYNT） |
| CH2 | PWM1（HRPWM） | 250 kHz | 独立时基 |
| CH3 | PWM2 | 300 kHz | 独立时基 |

ADC 采样：由各通道 PWM 在电感电流谷/峰时刻触发；CH1 两相各自触发一次。

## 4. 传感策略（核心原则）

### 4.1 快环 + 慢环分离

| 层级 | 器件 | 用途 | 带宽/节奏 |
|------|------|------|-----------|
| 快环 | **INA240**（模拟）→ 片内 ADC | 电流环、交错均流、峰值/平均电流控制 | PWM 同步采样 |
| 慢环/计量 | **INA229**（SPI 数字） | 精确电流/电压/功率/能量、软保护阈值、上报 | 1–10 ms 级 |
| 硬件保护 | **ACMP** + TRGM → PWM Fault | 逐周期 OCP / 快速 OVP 封锁 | 硬件级，无软件延迟 |

**不要只用 INA229 做电流环**：SPI + 内部转换偏慢，不适合峰值电流模式与交错均流快环。

### 4.2 同一分流电阻能否共用 INA240 与 INA229？

**可以共用**，两者均为高阻差分取样，并联测 \(V_{shunt}\)。

必须遵守：

1. **开尔文星形接法**：从分流电阻两端焊盘分别引出功率回路、INA240、INA229 的 sense 线，禁止一条 sense 线串到两个芯片。
2. **滤波各自独立**：各自在芯片管脚旁放差分 RC；不要共用一组滤波再分叉。
3. **量程同时满足两边**：
   - INA229 满量程约 ±40.96 mV 或 ±163.84 mV
   - INA240 输出需落在 ADC 量程内（注意增益档）
   - 100 A 场景分流压降通常取几十 mV 级
4. **偏置电流**：INA229 为 nA 级；INA240 稍大，对 mΩ 级分流一般可忽略；若串联滤波电阻较大，需核算偏置误差。
5. **共模与地**：高边取样时共模跟母线；低边注意功率地回流不灌入 sense 回路。快环优先 INA240（PWM 抑制好），慢环用 INA229。

### 4.3 分流电阻粗算提示

- CH1 100 A：分流约 **0.25–0.5 mΩ**（兼顾功耗与信噪比）
- CH2/CH3 30 A：分流约 **1–2 mΩ** 量级（按实际压降与器件量程再定）

## 5. MCU 外设资源分配

封装说明：HPM6284**IEP2** = BGA116（IO 较紧）；布线冲突多时可改用 **IPA2（LQFP144）**。

### 5.1 PWM

| 通道 | PWM 模块 | 精度 | 通道占用 | 说明 |
|------|----------|------|----------|------|
| CH1 | **PWM0（HRPWM）** | 100 ps | P0–P7（8 通道） | PhaseA：P0–P3；PhaseB：P4–P7；180° 交错 |
| CH2 | **PWM1（HRPWM）** | 100 ps | P0–P3（4 通道） | 输入桥 + 输出桥 |
| CH3 | **PWM2** | 3.0 ns | P0–P3（4 通道） | 输入桥 + 输出桥 |
| 预留 | PWM3 | 3.0 ns | — | 同步辅助、风扇、冗余等 |

推荐引脚方向（避免与 ADC 模拟脚冲突）：

| 用途 | 推荐 GPIO |
|------|-----------|
| PWM0（CH1） | **PB12–PB19**（PWM0_P0…P7） |
| PWM0 Fault | PC08 等 FAULT/TRGM 脚 |
| PWM1（CH2） | **PB00–PB03** 或 PA11–PA14 |
| PWM2（CH3） | **PB24–PB27** |

每对互补由 PWM 模块插入死区；外部配半桥驱动（注意 60 V 耐压与隔离/电平位移）。

### 5.2 ADC 快环（3×16bit）

| ADC | 绑定通道 | 典型模拟量 |
|-----|----------|------------|
| ADC0 | CH1 | Vin1、Vout1、IphA、IphB、Iout1、NTC1 |
| ADC1 | CH2 | Vin2、Vout2、Iind2、Iout2、NTC2 |
| ADC2 | CH3 | Vin3、Vout3、Iind3、Iout3、NTC3 |

- 模拟输入优先使用 **PC04–PC23** 一带 ADC 脚
- **PWM 与 ADC 不可同脚复用**
- 由各通道 PWM 的 TRGM 在电流谷/峰时刻触发对应 ADC
- CH1 两相分别采样，软件做均流

### 5.3 ACMP 硬件保护

| 比较器 | 建议功能 | 动作 |
|--------|----------|------|
| ACMP0 | CH1 过流（Iout 或 Iph） | → TRGM → PWM0 Fault 封锁 |
| ACMP1 | CH1 / 关键线过压 | → PWM0 Fault |
| ACMP2 | CH2 OCP | → PWM1 Fault |
| ACMP3 | CH3 OCP | → PWM2 Fault |

阈值可用片内 8bit DAC 或外部基准。CH2/CH3 OVP 可用软件 + GPIO，或外扩比较器进 TRGM。

### 5.4 INA229（SPI 慢环）

建议 **6 片**（每通道输入侧 + 输出侧各 1）；省成本可只保留输出侧 **3 片**。

| 信号 | 外设/类型 | 推荐脚方向 |
|------|-----------|------------|
| SCLK / MOSI / MISO | SPI0 | PA08 / PA09 / PA07 |
| CS ×6 | GPIO | PA10、PA28–PA31、另选空闲脚 |
| ALERT | GPIO 下降沿（可线或） | 如 PB08 + 上拉 |

SPI 时钟 ≤ 10 MHz（INA229 上限）。ALERT 作二次保护与日志，**不替代 ACMP 硬件封锁**。

### 5.5 通讯与系统

| 功能 | 外设 | 说明 |
|------|------|------|
| 调试串口 | UART0 | 避开 SPI CS 占用脚 |
| 上位机（可选） | USB0 HS-PHY | 片内 PHY |
| 现场总线（可选） | CAN0 | — |
| 外部 Flash | XPI0 | 启动电路固定，勿占用 |
| 驱动器 Enable | GPIO | 每通道至少 1 路 |
| 预充 / 继电器 | GPIO | 按板级预留 |
| CV/CC、通道使能 | GPIO 拨码/按键 | — |
| 状态 LED | GPIO | — |
| 看门狗 | WDG | 必须使能 |

双核建议：

- **Core0**：CH1 快环 + 保护
- **Core1**：CH2/CH3 + SPI/通信/UI

### 5.6 资源占用一览

```
PWM0(HR) ████████  CH1 交错 8ch + Fault
PWM1(HR) ████----  CH2 4ch + Fault
PWM2     ████----  CH3 4ch + Fault
PWM3     --------  预留

ADC0     CH1 Vin/Vout/IphA/IphB/Iout/NTC
ADC1     CH2 Vin/Vout/I/Iout/NTC
ADC2     CH3 Vin/Vout/I/Iout/NTC

ACMP0~3  硬件 OCP/OVP → PWM Fault
SPI0     6×INA229（或 3×）
UART0    调试
CAN0/USB 可选
GPTMR    软定时
WDG      必须
```

## 6. 控制与保护逻辑

### 6.1 CV / CC

1. **CV（电压模式）**：电压环（PI）给出电流给定 → 内环电流（峰值或平均）→ 占空比  
2. **CC（电流模式）**：电流环直接跟随设定；电压环作上限钳位  
3. 模式切换由状态机管理；OCP 阈值可随模式通过 DAC/寄存器调整  

### 6.2 保护优先级

1. **硬件（最快）**：ACMP → PWM Fault，逐周期封锁  
2. **数字传感器**：INA229 ALERT / 软件阈值，锁存、日志、上报  
3. **软件**：持续过流/过压、过温、通信丢失 → 锁存关机，需清故障后重启  

### 6.3 交错均流（CH1）

- 采样 IphA、IphB  
- 差分进入均流环，微调 PhaseB 占空比  
- 相位由 SYNT / TRGM 保持 180°  

### 6.4 INA229 软件节奏

- 周期 1–10 ms 读取  
- 用于校零、功率/能量累计、保护阈值更新、上位机上报

| 项目 | 建议 |
|------|------|
| 快环电流放大器 | INA240（高压侧，PWM 抑制好）；或低端分流 + 运放 |

## 8. 设计检查清单

- [ ] 三路输入独立，每路 4.5–60 V 耐压与浪涌考虑完整
