# RK3576 头部板 NFC 读卡器

选型正文：[`docs/RK3576_AI头部板_NFC读卡器选型.md`](../../docs/RK3576_AI头部板_NFC读卡器选型.md)

默认料：**PN7160A1HN/C100**（芯片，I2C，HVQFN40）。  
**OM27160A1HN** 只是这块芯片的评估板，用来先调软件，不进产品、也不用买两套。  
公开原理图 / Linux 开源：PN7160 成套；ST25R3916B 有原理图但 Linux+I2C 要自己接；FM17550 官网几乎只有说明书。  
不要用 FM11NT082C / ST25DV 标签芯片承担读卡。
