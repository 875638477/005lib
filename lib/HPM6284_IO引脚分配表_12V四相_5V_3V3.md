# HPM6284 IO 引脚分配表

> 拓扑：**四开关 Buck-Boost**  
> 配置：**12V 四相交错** + **5V 单相** + **3.3V 单相**  
> 推荐封装：**HPM6284IPA2（eLQFP144）**  
> 说明：IEP2（BGA116）上 **PB02–PB07 / PA10–PA15 等未引出**，无法让 PWM1 出满 8 路；四相若坚持 IEP2 见文末「BGA116 变通表」。

---

## 0. 外设总览

| 输出 | 相数 | PWM 模块 | 精度 | \(f_{sw}\) | ADC |
|------|------|----------|------|------------|-----|
| 12 V / 100 A | 4 相，相移 90° | **PWM0 + PWM1** | 100 ps HR | 150 kHz | ADC0 |
| 5 V / 30 A | 1 相 | **PWM2** | 3.0 ns | 250 kHz | ADC1 |
| 3.3 V / 30 A | 1 相 | **PWM3** | 3.0 ns | 300 kHz | ADC2 |

每相四开关：输入桥 HS/LS + 输出桥 HS/LS = **4 路 PWM**（两对互补）。

> 若希望 BOOT 脚完全不动：3.3V 可改用 **PA24–PA27（PWM3_P4–P7）**，把 P0–P3 空出。

### 1.7 PWM Fault（硬件封锁）

| 信号 | 功能 | GPIO | ALT | 接到 |
|------|------|------|-----|------|
| FAULT_CH1 | PWM0_FAULT_0 | **PB11** | ALT16 | CH1 OCP/OVP 比较器输出（可线或） |
| FAULT_CH1B | PWM1_FAULT_0 | **PB08** | ALT16 | 与上同故障网，封锁 Phase3/4 |
| FAULT_CH2 | PWM2_FAULT_0 | **PC08** | ALT17 | CH2 保护（若 PC08 作 ADC 则改用 TRGM 输入） |
| FAULT_CH3 | PWM3_FAULT_0 | **PA11** | ALT17 | CH3 保护 |

> Fault 也可用 **TRGM 输入脚 + 内部互联** 进各 PWM，以腾出 PC08 给 ADC。推荐：比较器 → TRGM → PWM Fault，少占专用 Fault 脚。

## 2. ADC 快环采样（模拟脚，FUNC = Analog）

全部设为 **模拟模式**，由对应 PWM 的 TRGM 触发采样。

### 2.1 ADC0 ← 12V 四相

| 信号 | ADC 通道 | GPIO | 前端 |
|------|----------|------|------|
| VIN1 | ADC0_INA2 | **PC06** | 分压 ≤3.3V |
| VOUT1_12V | ADC0_INA3 | **PC07** | 分压 |
| IPH1 | ADC0_INA4 | **PC08** | INA240（Phase1 相电流，见 [`IPH相电流说明_计算分配与使用.md`](./IPH相电流说明_计算分配与使用.md)） |
| IPH2 | ADC0_INA5 | **PC09** | INA240（Phase2） |
| IPH3 | ADC0_INA6 | **PC10** | INA240（Phase3） |
| IPH4 | ADC0_INA7 | **PC11** | INA240（Phase4） |
| IOUT1 | ADC0_INA8 | **PC12** | INA240（输出**总**电流，≠ 单相 IPH） |
| NTC1 | ADC0_INA9 | **PC13** | 分压 |

### 2.2 ADC1 ← 5V 单相

| 信号 | ADC 通道 | GPIO | 前端 |
|------|----------|------|------|
| VIN2 | ADC1_INA6 | **PC14** | 分压 |
| VOUT2_5V | ADC1_INA7 | **PC15** | 分压 |
| IIND2 | ADC1_INA8 | **PC16** | INA240 |
| IOUT2 | ADC1_INA9 | **PC17** | INA240 |
| NTC2 | ADC1_INA10 | **PC18** | 分压 |

### 2.3 ADC2 ← 3.3V 单相

| 信号 | ADC 通道 | GPIO | 前端 |
|------|----------|------|------|
| VIN3 | ADC2_INA7 | **PC19** | 分压 |
| VOUT3_3V3 | ADC2_INA8 | **PC20** | 分压 |
| IIND3 | ADC2_INA9 | **PC21** | INA240 |
| IOUT3 | ADC2_INA10 | **PC22** | INA240（LQFP144 有此脚） |
| NTC3 | ADC2_INA11 | **PC23** | 分压 |

> IEP2 无 PC22/PC23：NTC3/IOUT3 改挂 **PC17/PC18** 由 ADC2 通道复用采样，或减少一路 NTC。

## 3. ACMP 硬件保护

| 比较器 | 用途 | 正端模拟输入建议 | 阈值 | 输出去向 |
|--------|------|------------------|------|----------|
| ACMP0 | CH1 过流 | IOUT1 或 IPH 合成（与 PC12 同网经缓冲） | 内部 8bit DAC | → TRGM → PWM0/1 Fault |
| ACMP1 | CH1 过压 | VOUT1 分压 | 内部 DAC / 外部基准 | → TRGM → PWM0/1 Fault |
| ACMP2 | CH2 过流 | IOUT2 | 内部 DAC | → TRGM → PWM2 Fault |
| ACMP3 | CH3 过流 | IOUT3 | 内部 DAC | → TRGM → PWM3 Fault |

具体 ACMP 正/负端引脚按数据手册 ACMP_CMPx_INP/INN 与上述 ADC 脚复用表选，**比较器输入与 ADC 可同网，勿与 PWM 数字脚冲突**。

## 6. 引脚占用速查（IPA2）

### PWM（24 路）

```
PB12-PB19  PWM0  12V Ph1+Ph2
PB00-PB07  PWM1  12V Ph3+Ph4
PB24-PB27  PWM2  5V
PA20-PA23  PWM3  3.3V
PB11/PB08  Fault CH1
```

### ADC（约 18 路模拟）

```
PC06-PC13  ADC0  12V
PC14-PC18  ADC1  5V
PC19-PC23  ADC2  3.3V
```

### SPI / GPIO

```
PA28-PA31  SPI0 + CS_VOUT1
PB20-PB23  CS / ALERT
PA24-PA27  EN / 预充
PY06/PY07  UART0
```

## 7. IEP2（BGA116）变通分配

**问题**：BGA116 **无 PB02–PB07**，PWM1 无法出齐 8 路 → 不能按上面「PWM0+PWM1 双 HR」做四相。

| 方案 | 12V 四相 | 5V | 3.3V | 代价 |
|------|----------|----|------|------|
| **A. 换 IPA2（推荐）** | PWM0+PWM1 全 HR | PWM2 | PWM3 | 封装更大，脚齐 |
| **B. 坚持 IEP2** | Ph1–2：**PWM0** PB12–19（HR）；Ph3–4：**PWM2** PB24–31（3ns） | **PWM3** PA20–23 | **PWM3** PA24–27 | Ph3/4 分辨率降为 3ns；5V/3.3V 挤在同一 PWM3 |

IEP2 方案 B 要点：

- 仍可四相，相移用 TRGM/SYNT 同步  
- ADC 仅 **PC06–PC21** 可用（无 PC00–05、无 PC22+）  
- 强烈建议：**新板直接上 IPA2**，按本文第 1–6 节贴片

## 8. 软件 Pinmux 提示（HPM SDK）

```c
/* 示例：12V Phase1 输入桥 */
HPM_IOC->PAD[IOC_PAD_PB12].FUNC_CTL = IOC_PB12_FUNC_CTL_PWM0_P_0;
HPM_IOC->PAD[IOC_PAD_PB13].FUNC_CTL = IOC_PB13_FUNC_CTL_PWM0_P_1;
/* ADC */
HPM_IOC->PAD[IOC_PAD_PC06].FUNC_CTL = IOC_PAD_FUNC_CTL_ANALOG_MASK;
/* SPI0 */
HPM_IOC->PAD[IOC_PAD_PA30].FUNC_CTL = IOC_PA30_FUNC_CTL_SPI0_SCLK;
HPM_IOC->PAD[IOC_PAD_PA31].FUNC_CTL = IOC_PA31_FUNC_CTL_SPI0_MOSI;
HPM_IOC->PAD[IOC_PAD_PA29].FUNC_CTL = IOC_PA29_FUNC_CTL_SPI0_MISO;
```

量产前请用官方 **HPM Pinmux Tool** 再对一次封装（IPA2 vs IEP2）冲突检查。
