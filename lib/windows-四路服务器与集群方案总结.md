# Windows 集群、双主板互联与 LGA 3647 四路方案总结

> 本文档整理自一次技术对话：从「一系统控制两台电脑」出发，逐步细化到 Windows 集群、双路主板互联、LGA 3647 四路 CPU 与四路主板选型。

---

## 1. 「一个系统同时控制两台计算机」常见误解

普通 Windows / macOS / 家用 Linux **不能**让两台实体机共享同一个 OS 内核。

| 真实需求 | 可行做法 |
|----------|----------|
| 一套键鼠管两台 | KVM 切换器，或 Input Leap / Barrier / Synergy |
| 远程操作另一台 | RDP、VNC、TeamViewer、RustDesk、SSH |
| 两台一起算力/一起跑服务 | 集群、容器编排（K8s 等） |
| 一台挂了业务继续 | Windows Failover Cluster 等高可用方案 |
| 两台完全共用一个桌面 OS | 基本不现实 |

---

## 2. Windows 集群方案概览

### 2.1 Windows Failover Cluster（故障转移集群）

- **定位**：微软官方高可用，适合服务器
- **效果**：节点故障时业务自动切换（非「两台合成一台桌面」）
- **典型用途**：文件服务器、SQL Always On / FCI、Hyper-V VM 高可用、通用服务角色
- **条件**：
  - Windows Server（完整 Failover Clustering；家用 Win10/11 不可做正式故障转移集群）
  - ≥2 节点、心跳网络、共享存储或 S2D / 部分无共享方案
  - 通常需加入域；配置 Quorum 防脑裂

### 2.2 Storage Spaces Direct（S2D）

- 用各节点本地盘组成软件定义存储，再配合 Failover Cluster
- 适合无传统 SAN；建议 Windows Server Datacenter + 高速网（最好 RDMA）

### 2.3 Hyper-V 集群

- Hyper-V + Failover Cluster
- 支持 Live Migration；宿主机维护/故障时 VM 可迁移或快速恢复

### 2.4 网络负载均衡（NLB）

- 流量分到多台（如 IIS）
- 配置相对简单；不适合强状态/强一致数据库

### 2.5 应用级多节点

| 方案 | 用途 |
|------|------|
| SQL Always On AG | 数据库高可用 / 读写分离 |
| DFS-N / DFS-R | 文件命名空间与副本 |
| IIS + ARR / 反向代理 | Web 层横向扩展 |
| Kubernetes on Windows | 容器编排 |

### 2.6 两节点最小架构示意

```text
[域控 / 仲裁见证]
        |
   ┌----+----┐
节点A(Windows Server)  节点B(Windows Server)
   | 心跳网 / 业务网 |
   └----共享存储----+
         |
   集群角色（文件/SQL/VM…）
```

步骤概览：加域 → 安装故障转移群集 → 配置存储 → 验证并创建集群 → 添加角色 → 测试故障转移。

## 3. 两块双路服务器主板如何「连成一个整体」

### 3.1 核心结论

- 双路主板上的 **UPI/QPI 只连同板另一颗 CPU**，**不能**用网线/普通线缆把两块双路板拼成一块四路 SMP。
- 「成一个整体」在工程上通常指：**高速互联 + 集群软件（± 共享存储）**。
- 若要 **一份统一内存地址空间、四颗 CPU 对等访问**，应买 **四路主板/四路整机**，或厂商 **Scale-Up** 方案。

### 3.2 可行路径

| 方案 | 说明 |
|------|------|
| A. 高速网 + 软件集群 | 10/25/100GbE（最好 RoCE）或 InfiniBand；Windows Failover / Hyper-V / S2D；Linux 用 K8s、Slurm、MPI |
| B. 共享存储 + 故障转移 | SAN / iSCSI / NVMe-oF + 集群 VIP，对外像一台服务 |
| C. 真·多机箱 Scale-Up | 极少见、昂贵；普通双路板做不到 |
| D. 最小互联清单 | 每台完整主机 + 业务网/集群网分离 + BMC 管理 + 仲裁见证 |

### 3.3 物理连接示意

```text
[交换机-业务] -------- NIC1@节点A / NIC1@节点B
[交换机-集群/RDMA] --- NIC2@节点A / NIC2@节点B
[管理交换机] --------- BMC-A / BMC-B
```

## 4. LGA 3647 是否有支持 4 路的 CPU

**有。** Socket P（LGA 3647）对应第 1/2 代 Intel Xeon Scalable。

### 4.1 按系列路数上限

| 系列 | 最大路数 | 能否 4 路 |
|------|----------|-----------|
| Platinum 81xx / 82xx | ≤8S | 能 |
| Gold 51xx / 61xx / 52xx / 62xx | ≤4S | 能 |
| Silver / Bronze | ≤2S | 不能 |
| Xeon W-31xx / W-32xx | 基本 1S 工作站 | 不能当服务器 4 路 |
| Platinum 92xx | BGA/专用平台，通常 ≤2S | 勿按普通 4 路板选型 |

后缀注意：

- **-U**：单路专用，不可多路
- **-M / -L**：大内存档，路数仍跟 Gold/Platinum
- **-F / -T / -Y / -N** 等：功能变体，一般不改变 4S/8S 上限

### 4.2 常见可 4 路型号举例

**第 1 代 Skylake-SP**

- Platinum：8153、8156、8158、8160、8164、8168、8170、8176、8180 等（含部分 -M/-F/-T）
- Gold 61xx：6126、6128、6130、6132、6134、6136、6138、6140、6142、6144、6146、6148、6150、6152、6154…
- Gold 51xx：5115、5118、5120、5122…

**第 2 代 Cascade Lake-SP**

- Platinum：8253、8256、8260、8268、8270、8276、8280 等（含 -M/-L/-Y）
- Gold 62xx：6226、6230、6234、6238、6240、6242、6248、6252、6254、6258R…（避开 -U）
- Gold 52xx：5215、5217、5218、5220、5222…

### 4.3 落地条件

1. CPU 必须是 Gold 或 Platinum（非 -U）
2. 主板/整机必须是 **4 路平台**（板内 UPI 拓扑）
3. 四颗建议同型号同步进
4. 内存、供电、散热按 4S 规范配置

## 5. LGA 3647 四路主板 / 整机推荐

### 5.1 选型现实

- 真正的 3647 四路板很少当「通用散板」零售
- 多为厂商专有板型，与机箱、导风罩、Riser 绑定
- **优先买四路整机**，再考虑散板

### 5.2 整机推荐

| 优先级 | 型号 | 说明 |
|--------|------|------|
| 性价比首选 | Dell PowerEdge R940 | 3U 四路，48 DIMM，二手货源多 |
| 企业稳妥 | HPE ProLiant DL580 Gen10 | 4U 四路，RAS 好 |
| 可扩 8 路 | Lenovo ThinkSystem SR950 | 可从 4S 扩到 8S |
| 超微方案 | Supermicro SYS-8049U 系列 | 对应主板 X11QPH+ |

### 5.3 超微四路主板（多为整机专用）

| 主板 | 路数 | 内存 | 备注 |
|------|------|------|------|
| MBD-X11QPH+ | 4× LGA 3647 | 48 DIMM，最高约 12TB | 常见于 8049U；For SuperServer Only |
| MBD-X11QPL | 4× LGA 3647 | 48 DIMM | 扩展更全；多为整机专用 |

说明：华硕/技嘉常见 3647 板（如 Z11PR-D16、MD71-HB0）多为 **双路**，不是四路。

### 5.4 按场景怎么选

- 数据库 / 大内存 / 虚拟化 → R940 或 DL580 Gen10
- 以后可能扩到 8 路 → SR950
- 认准超微生态 → SYS-8049U + X11QPH+
- 预算紧 → 二手 R940 / DL580 Gen10（确认电源、风扇、导风罩齐全）

### 5.5 采购核对清单

- [ ] 4 颗同代同型号 Gold/Platinum（非 -U）
- [ ] BIOS 支持目标 CPU 代际（Cascade Lake 需对应版本）
- [ ] 专有板型配件齐全（机箱、导风罩、转接卡）
- [ ] 电源按 4×高 TDP CPU + 内存/盘/卡预留（常见双路 1600W+ 冗余）

## 6. 决策速查

```text
想一套键鼠控制两台？     → KVM / Input Leap
想远程管两台？           → RDP / SSH
想业务高可用？           → Windows Failover Cluster（需 Server）
想两台一起算？           → 高速网 + 集群/MPI/K8s
想四颗 CPU 共享内存？    → 买四路整机（LGA3647：Gold/Platinum + R940 等）
想两块双路板拼成四路？   → 做不到（UPI 不出板）
```
