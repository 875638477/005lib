# HPM53M1 DCDC 设计记录

两套方案**完全独立、互不相关**：各自独立的功率板、独立的 MCU、独立的母线与负载。不得把方案 B 的 12V 输出当作方案 A 的母线，也不得共用控制或采样。

| 文档 | 应用 | 拓扑（已冻结） |
|---|---|---|
| [方案 A](./Scheme-A-HPM53M1-12V-5A-Bidirectional-FSBB.md) | 12V **固定**母线 ↔ 3S3P（11–12.6V），5A 充/放 | **四开关双向 Buck-Boost（FSBB）**，两相交错；**禁止只用 Buck** |
| [方案 B](./Scheme-B-HPM53M1-24-55V-12V-100A-Buck.md) | 24–55V → 12V / **100A 持续** | 三相交错同步 **Buck**（单向） |

## 通用说明

- 两板均用 **HPM53M1IN91（QFN80）**，但 BOM、引脚、固件各自成套。
- PWM1 片内直连三相预驱。桥臂1 = P_0/P_1 (PA00/PA01)，桥臂2 = P_2/P_3 (PA02/PA03)，桥臂3 = P_4/P_5 (PA04/PA05)。
- 引脚最终分配须用先楫 Pinmux 工具与 HPM SDK 交叉核对。
