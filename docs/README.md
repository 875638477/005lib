# HPM53M1 双向/降压 DCDC 设计记录

本目录保存两套**相互独立**的功率板方案，均基于 **HPM53M1IN91（QFN80, 9×9mm）**。

| 文档 | 应用 | 关键约束（已确认） |
|---|---|---|
| [Scheme-A](./Scheme-A-HPM53M1-12V-5A-Bidirectional-Buck.md) | 12V 母线 ↔ 3S3P 锂电（11–12.6V），5A 双向 | **母线固定 12.0V**；仅同步 Buck；两相交错 |
| [Scheme-B](./Scheme-B-HPM53M1-24-55V-12V-100A-Buck.md) | 24–55V → 12V 降压 | **100A 持续**；三相交错；每管位 3×NMOS 并联 |

## 通用说明

- HPM53M1 **PWM1 在片内直连三相预驱**，软件配置 PWM1 互补通道即可，无需外接 HIN/LIN。
- PWM1 与桥臂对应：桥臂1 = P_0/P_1 (PA00/PA01)，桥臂2 = P_2/P_3 (PA02/PA03)，桥臂3 = P_4/P_5 (PA04/PA05)。
- 引脚最终分配须用先楫 **Pinmux 工具**与 HPM SDK 交叉核对。
