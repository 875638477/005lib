# 03 — DPS-1200FB / Common Slot 64Pin 定义

> 综合 slundell、ColinTD、CSPS 社区整理。双面金手指：**底面 1–32，顶面 33–64**。视角以电源输出端金手指朝向观察者为准，制板时务必对照实物照片确认左右与正反。

## 1. 物理结构

```text
        （插入方向 → 背板插座）

   底面:  1 .......... 13 | 14 .......... 26 | 27 28 29 30 31 32
          <<<< +12V >>>>   <<<<  GND  >>>>   < 控制/管理 >

   顶面: 64 .......... 52 | 51 .......... 39 | 38 37 36 35 34 33
          <<<< +12V >>>>   <<<<  GND  >>>>   < 控制/管理 >
```

功率针成排并联；控制针集中在同一端。

推荐连接器示例（开源转接板常用）：

- 直插：`WingTat S-64M-2.54-5` 或同规格 2.54 mm 64Pin 边缘插座
- 弯插：`WingTat S-64L-2.54-5`

## 2. 引脚表

| 面 | Pin | 信号 | 背板处理建议 |
| --- | --- | --- | --- |
| 底 | 01–13 | `+12V` | 全部并到 `VBUS_12V`，大铜皮 |
| 底 | 14–26 | `GND` | 全部并到 `PGND` |
| 底 | 27 | `ADR` | 地址配置（可扩展到 28/29） |
| 底 | 28 | `ADR/NC` | 按版本用作地址或 NC |
| 底 | 29 | `ADR/NC` | 按版本用作地址或 NC |
| 底 | 30 | `SGND` | 信号地，近插座与 PGND 连接 |
| 底 | 31 | `SCL` | 公共 PMBus 时钟，上拉 |
| 底 | 32 | `SDA` | 公共 PMBus 数据，上拉 |
| 顶 | 33 | `EN#` / `PSON#` | 低有效使能，开漏到 SGND |
| 顶 | 34 | `LOAD_SHARE` / `IMON` | 测试点；高级均流再用 |
| 顶 | 35 | `PSOK` / `STATUS` | LED / MCU 输入 |
| 顶 | 36 | `PRE` / `PRESENT` | 经 10k–22k 上拉到 12VSB |
| 顶 | 37 | `12VSB` | 待机电源；可经二极管汇到 SBS_BUS |
| 顶 | 38 | `PSALARM` / `PSIN` | 告警到 MCU/LED |
| 顶 | 39–51 | `GND` | 并到 `PGND` |
| 顶 | 52–64 | `+12V` | 并到 `VBUS_12V` |

## 3. 关键信号电气意图（社区结论）

### PRE（36）

- 平台侧用派生自 12VSB 的上拉表示“期待有电源”
- 插入后被模块钳位到较低电压，平台据此检测在位
- 模块侧看到上拉，认为自己已插入到位

### EN#（33）

- 内部常上拉到模块逻辑电源（如 3V3 via ~10k）
- 拉到地即允许主 12V 输出
- 可用开关、跳线或 MCU 开漏驱动

### 12VSB（37）

- AC 存在即有输出
- **只能给控制电路**，不可当主功率源

### LOAD_SHARE（34）

- 与输出电流/均流相关的模拟脚
- 可测电压随负载变化；并联高级用法见工作原理文档

## 4. 双槽背板网络命名

| 网络名 | 含义 |
| --- | --- |
| `V12A` / `V12B` | 各槽本地 12V（ORing 前） |
| `VBUS_12V` | 公共 12V 母排 |
| `PGND` | 功率地 |
| `SB_A` / `SB_B` | 各槽 12VSB |
| `SBS_BUS` | 二极管汇流后的待机总线 |
| `EN_A#` / `EN_B#` | 分槽使能 |
| `PRE_A` / `PRE_B` | 分槽在位偏置 |
| `PSOK_A` / `PSOK_B` | 状态 |
| `SCL` / `SDA` | 公共管理总线 |
| `ADR_A*` / `ADR_B*` | 地址绑定位 |

## 5. 核对清单（制板前）

1. 用万用表确认 Pin1 一侧确实是大面积 +12V 铜皮
2. 确认 Pin36 是否为短针
3. 确认 SCL/SDA 是否与你的模块丝印/实测一致
4. 空载测量 12VSB 是否在 ~12 V
5. 再做 PRE/EN 使能实验，最后才接大负载
