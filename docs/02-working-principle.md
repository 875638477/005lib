# 02 — 工作原理

## 1. 上电时序（单模块）

```text
AC 插入
   │
   ▼
内部待机电源启动 ──► 12VSB 出现（金手指 Pin37）
   │
   ▼
模块 MCU / 逻辑上电（可应答 I2C，主 12V 仍关闭）
   │
   ▼
背板给出 PRESENT（Pin36 被拉向 12VSB 一侧）
   │
   ▼
背板拉低 ENABLE#（Pin33 → GND）
   │
   ▼
主变换器启动 ──► +12V 建立
   │
   ▼
PSOK/STATUS 变为“正常”电平（社区常见约 ~3.2 V 表示 OK）
```

要点：

1. **仅有 AC 不等于有 12V 主输出**。必须正确处理 `PRE` 与 `EN`。
2. `12VSB` 一直可用于点亮指示灯、给 MCU、上拉 Present。
3. Present 针在很多模块上是 **短针（Last Make / First Break）**，保证插入到位后再真正认为在位，拔出时先断开。

## 2. 正确使能方式（推荐）

社区与实测较一致的做法：

| 步骤 | 连接 | 说明 |
| --- | --- | --- |
| 1 | Pin36 `PRE` ← R（约 10k–22k）← Pin37 `12VSB` | 告诉 PSU“已插入且允许工作” |
| 2 | Pin33 `EN#` → 开关/开漏 → Pin30 `SGND` | 低电平使能主输出 |

不推荐把 Pin33–Pin36 长期硬短；临时测试可用电阻跨接，成品背板应拆成上面两步。

### MCU 控制建议

```text
12VSB ──► DC-DC/LDO ──► 3V3 ──► MCU
MCU 开漏 GPIO ──► EN#
MCU 输入（分压/钳位）◄── PSOK / ALARM
MCU I2C ◄──► SCL/SDA
```

软启动顺序建议：检测 Present → 延时数十 ms → 拉低 EN → 轮询 PSOK → 再允许大负载接通。

## 3. 热插拔原理

Common Slot 设计目标就是在机箱带电时更换电源：

1. **机械导轨**保证金手指对准
2. **长短针**控制信号通断顺序
3. **内部软启动**限制冲击电流
4. **背板母排低阻抗**减小插拔火花与压降

背板设计注意：

- 功率铜皮足够宽/厚，避免单点过热
- 控制地与功率地在插座近端单点汇合，MCU 采样远离大电流路径
- 空槽的 `EN` 不要误拉低到会干扰总线的状态；空槽 Present 应呈现“不在位”

## 4. 双路并联与均流

### 4.1 Active Droop（下垂均流）

HP Common Slot 电源普遍使用内部下垂特性：

```text
Vout ≈ Vset - k × Iout
```

两台电源并在同一母排时，电流大的那台电压略低，自动把电流分给另一台。社区对 DPS-1200FB 量级描述约为 **数 mV/A**（例如 ~3 mV/A），具体以实测为准。

因此 **基础双路背板可以把两槽 +12V 直接并联**，不必先上外置均流控制器。

### 4.2 LOAD_SHARE（Pin34）

Pin34 在不同资料中称为 `IMON` / `LOAD_SHARE`：

- 可反映输出电流相关的模拟量
- 并联时可参与模块间“请求助力”的信息交互
- 也可被外部电路用来做电流限制/调节实验

参考设计默认：

- **Rev A**：Pin34 各自引出测试点，两槽可不互连
- 需要更紧均流时：查阅具体版本行为后再决定是否互连或经电阻网络连接

### 4.3 要不要 ORing？

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| **直接并联** | 简单、压降小、效率高 | 一路内部短路时可能拖垮母排 |
| **肖特基二极管 ORing** | 故障隔离简单 | 100A 级损耗巨大，不现实 |
| **MOSFET ORing**（TPS2412/13 等） | 低损耗隔离 | 成本与布局复杂度上升 |

服务器原装背板常见思路是：电源模块自身可并联，背板侧重汇流；部分平台会在下游再做保护。本参考设计 **Rev A 直并**，**Rev B 可选 ORing FET**。

## 5. 冗余切换

### 5.1 1+1 热冗余（推荐默认）

两路都使能，同时均流。单路故障时：

1. 故障模块 PSOK/ALARM 变化或掉输出
2. 母排电压由另一路维持（可能瞬间下凹）
3. 系统继续运行；BMC 告警并提示更换

设计负载应 **按单路能力留裕量**（例如持续负载 ≤ 80–90 A @12V，视输入电压与散热）。

### 5.2 主备模式

```text
正常：EN_A=0(使能), EN_B=1(关闭主输出，保留 12VSB)
故障：检测到 A 异常 → EN_B=0
```

优点是轻载更省电；缺点是切换有短暂母排跌落，需要足够输出电容与快速检测。

## 6. PMBus / I2C 管理

### 6.1 物理层

- Pin31 / Pin32：`SCL` / `SDA`（部分兼容资料可能对调，焊接前核对）
- Pin30：信号地
- Pin27–29：地址选择（社区记录可拉低改地址）
- 总线需上拉；电平以 PSU 侧为准（常见为逻辑电平，**勿假定可直接接 5V 强推**）

### 6.2 双槽地址

示例（来自社区，需实测）：

| ADR 脚状态 | EEPROM | MCU |
| --- | --- | --- |
| 默认（为 1） | ~0x57 | ~0x5F |
| 拉低 | ~0x50 | ~0x58 |

背板应把槽位0、槽位1 的 ADR 绑成不同组合。

### 6.3 能力边界

DPS-1200FB 的命令集 **不完全等同标准 PMBus 教科书映射**；raplin 等逆向显示存在厂商私有寄存器。背板硬件仍按标准 I2C 走线即可，软件层再适配。

## 7. 功率路径与损耗

以单路 12V/100A 估算：

| 环节 | 关注点 |
| --- | --- |
| 金手指接触电阻 | 多针并联；接触不良会局部灼伤 |
| PCB 铜皮 | 厚铜/多并联层/汇流铜排 |
| 输出端子 | M6/M8 铜柱、铜排或大电流连接器 |
| 线缆 | 按电流选截面积，压降与发热同时算 |
| 连接器温升 | 满载后红外测温，建议热点 < 行业自定阈值（如 30–40°C 温升） |

双路冗余时母排按“单路故障后仍能走全电流”设计；扩流模式按“两路之和”设计。

## 8. 故障与保护协同

背板可增加的保护（模块内部保护之外）：

- 输出总保险丝 / 断路器
- 母排过压监测（防止异常调压）
- 输入侧独立 AC 开关（每槽一把）
- 烟雾/温度传感器联锁断开 EN

不要依赖背板去“修复”模块内部故障；发现异味、啸叫、外壳过热应立即断电。
