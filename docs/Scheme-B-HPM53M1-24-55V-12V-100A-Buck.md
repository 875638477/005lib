# 方案 B：HPM53M1 — 24–55V → 12V / 100A 持续三相交错 Buck

**文档版本：** v1.0  
**日期：** 2026-09-03  
**MCU：** HPM53M1IN91（QFN80）  
**状态：** 设计基线（Design Baseline）

---

## 1. 需求记录（已冻结）

| 项目 | 规格 |
|---|---|
| 输入电压 | **24–55V DC**（标称 48V） |
| 输出 | **12.0V / 100A 持续**（**1200W 连续**，非峰值） |
| 拓扑 | **同步 Buck**，三相交错 |
| MOS | 每开关位置 **3×NMOS 并联**（共 18 只） |
| 驱动 | HPM53M1 **片内 150V 预驱直驱** |
| 方向 | 单向降压（24–55V → 12V） |

---

## 2. 功率预算与热设计（100A 持续）

### 2.1 功率

| 量 | 数值 |
|---|---|
| P_out | 12V × 100A = **1200W** |
| P_in @48V, η=93% | ≈ **1290W**, I_in ≈ **26.9A** |
| P_in @24V, η=91% | ≈ **1319W**, I_in ≈ **55.0A** |
| 总损耗 @满载 | **84–120W**（须全部散出） |

### 2.2 损耗分解（48V 输入，D=0.25，fs=120kHz）

| 项目 | 估算 |
|---|---|
| 导通损耗（18×MOS, Rds_eff≈1.33mΩ/位置） | ~25–35W |
| 开关损耗（Qg×3并×6位置×fs） | ~30–50W |
| 电感 DCR（3×15µH, DCR~3mΩ） | ~8–12W |
| 合计 | **~65–95W** |

### 2.3 热设计强制要求（100A 持续）

| 项目 | 要求 |
|---|---|
| 散热器 | **强制风冷**，风量 ≥ **30 CFM** 直吹 MOS 区 |
| PCB 铜厚 | **外层 4oz**，内层 2oz 地平面 |
| 输出母排 | **10mm 镀锡铜排** 或 ≥8×2mm 铜片并联 |
| 温升目标 | MOS 外壳 < **85°C** @40°C 环境满载 1h |
| 热成像 | 满载 30min 无热点 >100°C |

> **警告：** 100A 持续对 9×9mm QFN 预驱是极限应用；栅极驱动走线、V12 去耦、MOS 并联对称性必须量产级验证。

## 3. 功率拓扑

```
Vin(24~55V) ─┬─[半桥1: 3×HS + 3×LS]─┬─ L1(15µH/50A) ──┐
             ├─[半桥2: 3×HS + 3×LS]─┼─ L2(15µH/50A) ──┼── 12V / 100A
             └─[半桥3: 3×HS + 3×LS]─┴─ L3(15µH/50A) ──┘
                  120° 交错, fs = 120kHz
```

---

## 4. 关键器件选型（BOM 基线）

### 4.1 功率 MOSFET（18 只，每管位 3 并联）

| 位号 | 推荐型号 | 关键参数 | 数量 |
|---|---|---|---|
| Q1–Q18 | Infineon **BSC040N08NS5** | 80V, Rds=4.0mΩ, Qg=45nC, Id=100A | 18 |
| 备选（更高余量） | Infineon **BSC320N10NS3** | 100V, Rds=3.2mΩ | 18 |
| 备选（更低损耗） | Infineon **BSC030N08NS5** | 80V, Rds=3.0mΩ | 18 |

**并联规则：**
- 每只 MOS **独立 2.2Ω 栅极电阻**（禁止只在一颗上串 Rg）
- 源极/漏极铜皮**等长等宽**（对称布局）
- 单管持续电流设计值：**≤12A**（100A÷3 相 ÷3 并，留 10% 裕量）

### 4.2 电感（3 只）

| 位号 | 参数 | 推荐 |
|---|---|---|
| L1–L3 | **15µH / Isat ≥50A / DCR ≤3mΩ** | Vishay **IHLP-4040DZ-15** 或 Würth **744311150** |

**电感计算（48V→12V, 每相 33.3A, ΔI=6A）：**

\[
L = \frac{(48-12) \times 0.25}{120\text{k} \times 6} \approx 12.5\,\mu\text{H} \Rightarrow \text{取 } 15\,\mu\text{H}
\]

### 4.3 电容

| 位号 | 参数 | 说明 |
|---|---|---|
| C_in | **470µF/100V 电解 ×6** + **10µF/100V 1206 陶瓷 ×6** | 贴近功率级，ESR 低 |
| C_out | **470µF/25V 聚合物 ×10** + **22µF/25V 陶瓷 ×10** | 12V 输出，100A 纹波电流 |
| C_bs ×3 | **2.2µF/50V X7R** | 三相自举（3 并 MOS 加大） |

### 4.4 电流采样（3 相）

| 位号 | 参数 | 接法 |
|---|---|---|
| R_s1–R_s3 | **2mΩ / 3W / 1%**（2725） | 每相 1 只，接 AMPA/AMPB/OPA0 |

| 通道 | 放大 | 灵敏度 | 满量程 |
|---|---|---|---|
| 相1 | AMPA, 增益 10V/V | 0.02 V/A | ±50A |
| 相2 | AMPB, 增益 10V/V | 0.02 V/A | ±50A |
| 相3 | OPA0 PGA 增益 10V/V → ADCIN3/4 | 0.02 V/A | ±50A |

### 4.5 辅助电源

| 功能 | 方案 |
|---|---|
| 预驱 V12（59 脚） | Vin 经 **LM5164** 或 **TPS54331** 降压至 **12V/1.5A**（独立，不取自 12V 输出） |
| MCU 5V（25 脚） | 12V_aux → **AP7361C-50** |
| 隔离/使能 | 输入 UVLO：Vin < 22V 禁止启动 |

## 9. 栅极驱动能力校核（3 并 MOS）

| 项目 | 数值 |
|---|---|
| Qg_total | 3 × 45nC = **135nC** |
| I_drive | +0.8A / −1.2A（HPM53M1 预驱） |
| t_rise | 135nC / 0.8A ≈ **169ns** |
| @120kHz | 可接受；若边沿过慢，Rg 降至 **1.0Ω** 并加强 V12 去耦 |

**若量产测试边沿 >300ns：** 在 HO/LO 到并联 MOS 间增加 **单路非门驱动缓冲**（如 74LVC244 + 分立推挽）——列为 v1.1 工程变更项。

## 10. PCB 布局要点（100A 持续）

```
层叠建议：4 层
  L1: 4oz 功率 + 信号
  L2: GND 平面
  L3: 2oz 功率回流
  L4: 4oz 12V 输出铺铜 + 信号

布局顺序：
  1. 三只半桥对称放置，L1/L2/L3 呈 120° 物理对称
  2. 输入电容组紧贴各相 HS 漏极
  3. 输出电容组紧贴电感输出端，汇流至中央铜排
  4. 分流电阻 Kelvin 接法，信号走内层
  5. HPM53M1 远离功率电感，下方密集过孔散热
  6. V12 走线宽度 ≥0.5mm，去耦电容距 59 脚 <3mm
```

### 10.1 铜皮电流密度

| 路径 | 100A 持续推荐 |
|---|---|
| 12V 输出主铜排 | 宽 ≥30mm（4oz）或铜排 |
| Vin 主回路 | 宽 ≥20mm（4oz） |
| MOS 源极并联 | 每管等长 ≤10mm 分支 |
