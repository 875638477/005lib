## 2. 固定 12V 母线的物理限制（设计结论）

> **在「母线固定 12.0V + 仅 Buck」条件下，无法将电池恒压充至 12.6V。**

### 2.1 原因

同步 Buck 充电方向：\(V_{bat} \approx D \cdot V_{bus} - I \cdot R_{loss}\)

- 占空比上限 \(D_{max}\) 受死区、开关损耗、采样窗口限制，工程上取 **0.90–0.93**
- 故充电 CV 上限：

\[
V_{bat,max} \approx 12.0 \times 0.92 \approx 11.0\text{–}11.2\,\text{V}
\]

（若 fs=250kHz、死区 100–150ns，实测上限多在 **11.0–11.4V**）

### 2.2 可实现的运行区间

| 电池电压 | 12V 固定母线下的行为 |
|---|---|
| **11.0 – ~11.1V** | ✅ **充电**（CC→CV，CV 建议 **11.1V**） |
| **~11.1 – 12.0V** | ✅ **充电**（恒流至 CV 截止） |
| **12.0 – 12.6V** | ❌ 不能继续 Buck 充电；✅ 可 **放电** 至 12V 母线（同步反向） |
| **< 12.0V 向母线放电** | ❌ Buck 无法升压，**不能**把 11V 电池升到 12V 母线 |

### 2.3 软件策略（必须实现）

```
状态机：
  CHARGE_CC    : Ibat = +I_cmd, Vbus=12V 固定
  CHARGE_CV    : Vbat → V_cv_limit (默认 11.1V，禁止 >11.4V)
  DISCHARGE    : Vbus 环稳定 12V, Ibat < 0, 仅当 Vbat > 12.2V 允许大电流
  IDLE         : Vbat 在 11~12.2V 中间区，根据指令选择充/放
  FAULT        : OCP/OTP/UVP

切换条件：
  请求充电 且 Vbat < V_cv_limit  → CHARGE
  请求放电 且 Vbat > 12.2V       → DISCHARGE（Vbat 接近 12V 时自动限流）
  Vbat ≥ 12.0V 且请求充电        → 拒绝/转 IDLE（防止误充）
```

### 2.4 与「11–12.6V 包电压」需求的对照

| 原始需求 | 本方案可达 | 备注 |
|---|---|---|
| 充至 12.6V | ❌ | 需提高母线至 ≥13.5V 或改四开关拓扑 |
| 从 11V 充电 | ✅ | CC 充电至 ~11.1V CV |
| 5A 放电至 12V 母线 | ✅（部分 SOC） | 仅 Vbat > ~12.2V 段可大电流放电 |
| 5A 充电 | ✅ | 自 11V 充至 ~11.1V |

**若业务必须满充 12.6V：** 本方案 A 不满足，需另板（升压段或 FSBB）——见方案 B 思路或独立 Charger。

## 3. 功率拓扑

```
12V_BUS (固定) ─┬─[HS1/LS1]─┬─ L1 ──┐
                │  桥臂1     │       ├── BAT+ (3S3P)
                └─[HS2/LS2]─┴─ L2 ──┘
                     桥臂2
                BAT- ── PGND
```

- **相数：** 2，**180° 交错**
- **开关频率：** **250 kHz**
- **每相电流：** 2.5A 平均（5A 总）

## 4. 关键器件选型（BOM 基线）

### 4.1 功率半导体

| 位号 | 功能 | 推荐型号 | 关键参数 | 数量 |
|---|---|---|---|---|
| Q1,Q3 | 相1/2 高侧 | Infineon **BSC010N04LS** | 40V, Rds=1.1mΩ, Qg≈13nC | 2 |
| Q2,Q4 | 相1/2 低侧 | 同上 | 同上 | 2 |
| 备选 |  | Nexperia **PSMN1R0-40YSF** | 40V, Rds=1.0mΩ | 4 |

> 5A 等级**不需要 MOS 并联**。

### 4.2 磁性元件

| 位号 | 参数 | 推荐 |
|---|---|---|
| L1, L2 | **6.8µH / 饱和 ≥12A / DCR <8mΩ** | Würth **74438367068** 或同等 |
| 纹波电流（每相） | ΔI ≈ 1.2–1.8A（≈50–70%） | fs=250kHz, Vin=12V, Vout=11V 时 |

**电感计算（校核）：**

\[
L = \frac{(V_{in}-V_{out}) \cdot D}{f_s \cdot \Delta I}
  = \frac{(12-11) \times 0.92}{250\text{k} \times 1.5} \approx 2.5\,\mu\text{H（最小值）}
\]

取 **6.8µH** 以降低纹波、改善均流。

### 4.3 电容

| 位号 | 参数 | 说明 |
|---|---|---|
| C_in | 100µF/25V 陶瓷 ×2 + 220µF/16V 电解 | 贴近半桥 |
| C_out | 220µF/16V 聚合物 + 100µF/16V 陶瓷 | 电池端口 |
| C_bs1, C_bs2 | 1µF/25V X7R | VB1-VS1, VB2-VS2 自举 |

### 4.4 采样电阻

| 位号 | 参数 | 说明 |
|---|---|---|
| R_s1, R_s2 | **5mΩ / 1W / 1%**（2512） | 每相一只，接 AMPA/AMPB |

增益 **20 V/V** → 灵敏度 **0.1 V/A**，±5A 对应 ±0.5V（ADC 余量充足）。

### 4.5 栅极电阻

| 位号 | 参数 |
|---|---|
| R_g1–R_g4 | **2.2Ω**（HO/LO 各串 1 颗） |

## 8. 保护阈值

| 保护 | 阈值 | 动作 |
|---|---|---|
| 充电 OCP | 6A（每相 3.5A） | 硬件 ACMP → PWM1_FAULT |
| 放电 OCP | −6A | 同上 |
| 电池 OVP | 11.5V（充电路径） | 软件关断 + 告警 |
| 电池 UVP | 9.0V（3×3.0V） | 禁止放电 |
| MOS OTP | 100°C（NTC） | 降额 → 关断 |
| 母线 UVP | 10.5V | 禁止充电 |
