# 06 — 安全与测试流程

## 1. 安全要点

1. **AC 侧危险**：模块内部有高压；不要打开外壳带电作业
2. **12V/100A 危险**：短路火花可熔化金属，建议输出串断路器
3. **热**：满载连接器可能很烫
4. **风扇**：高速叶片；测试时固定模块
5. **浮地串联 24V/48V 改装** 不在本设计范围，且有外壳带电风险

## 2. 空板检查

1. 目检短路、桥连、反贴
2. 万用表：`VBUS_12V` 对 `PGND` 不应接近 0Ω（电容会先充电）
3. 确认 EN 开关默认断开（主输出关闭）
4. 确认 ADR 跳线符合双地址方案

## 3. 单槽首次上电

1. 只插槽 A，AC 供电
2. 测 `SB_A ≈ 12V`
3. 确认 PRE 网络电压符合预期（被模块钳位后非 12V 满幅）
4. 闭合 `EN_A`，测 `VBUS_12V ≈ 12V`
5. 观察 PSOK LED / 风扇启动
6. 轻载（例如 1–5 A 电子负载或汽车灯泡）运行 5 分钟，摸温
7. 断开 EN，电压应落回接近 0（视放电电阻）

## 4. 双槽测试

1. 槽 A、B 都插入，先都 EN 断开
2. 确认两路 SB 正常，I2C 地址不冲突（扫总线）
3. 先使能 A，再使能 B（或相反），观察母排无异常振荡
4. 逐步加载，记录两路电流（若有钳表/PMBus）
5. 模拟冗余：带载时拔掉一路 AC（注意安全操作流程），观察另一路是否顶住、电压跌落幅度

## 5. 通过判据（建议）

| 项目 | 建议判据 |
| --- | --- |
| 空载 12V | 11.8–12.8 V（视版本） |
| 轻载稳定 | 无反复启停 |
| 均流 | 两路电流差异可接受（如 <20% @中等负载，视布线） |
| 温升 | 连接器/铜皮触手可接受或 < 你设阈值 |
| 拔插 | 热拔插无持续拉弧、无烧毁 |

## 6. 失败时

- 立即断 AC
- 检查使能网络是否误接功率
- 检查是否地址冲突导致异常（少见但应排除）
- 单槽复测定位是模块问题还是背板问题
