# 05 — PCB 设计指南

## 1. 设计约束总表

| 参数 | 建议（Rev A 实验板） | 更高可靠版本 |
| --- | --- | --- |
| 板厚 | 2.0 mm | 2.4–3.2 mm + 铜排 |
| 铜厚 | 2 oz 外层起 | 3–4 oz 或内层厚铜 |
| 层数 | 4 层 | 4–6 层 |
| 目标电流 | 单路满载 ~100 A；冗余按单路 | 扩流按合流水 |
| 表面处理 | 无铅喷锡 / 沉金 | 功率区可沉锡+加锡 |
| 阻焊 | 功率母排局部开窗 | 开窗上锡或装铜排 |

## 2. 推荐叠层（4 层）

```text
L1 (Top)    : 元件 + 局部信号 + 功率铜皮
L2 (Inner1) : PGND 完整平面
L3 (Inner2) : VBUS_12V 平面 / 厚铜灌注
L4 (Bottom) : 功率铜皮 + 少量信号
```

若只有 2 层：必须极大面积并铜 + 大量过孔，并强烈建议外加铜排；不推荐满载长期运行。

## 3. 载流经验公式（起步）

外层 1 oz 铜、温升 20°C、宽度粗估：

- ~10 A ≈ 5–6 mm（外层，视条件）
- 100 A 级 **不能** 靠单根细走线，必须：
  - 整片铜皮（数十 mm 宽）
  - 多内层并联
  - 矩阵过孔（via farm）
  - 或螺丝固定铜排

**过孔**：例如 0.3 mm 钻孔过孔，单孔载流有限；100A 级往往需要数十到上百个并联，并计算镀层厚度。更稳妥是 **铜柱/铜排跨接**。

## 4. 布局分区

```text
+-------------------+-------------------+------------------+
|   SLOT A 插座      |   中央功率母排     |   SLOT B 插座     |
|   控制件靠近信号端 |   去耦/TVS/铜柱    |   控制件靠近信号端|
+-------------------+-------------------+------------------+
|              输出铜柱 / 铜排区（板边）                      |
+----------------------------------------------------------+
```

规则：

1. **功率左右对称**，缩短两槽到母排的路径差，利于均流
2. **信号区远离母排回流突变区**
3. PMBus 双线等长并行走，旁附 SGND
4. LED/开关放在板边方便操作
5. 插座正下方尽量不要走敏感信号

## 5. 插座扇出

- `+12V` 针立刻进入大铜皮，禁止先过细颈
- `GND` 同样立即入地平面
- 控制针用 0.3–0.5 mm 走线引出到电阻网络
- 在插座安装孔附近加大机械铜环，防止插拔撬裂焊盘

## 6. 散热与机械

- 满载时连接器与铜皮是热点：红外验收
- 大铜皮与机箱之间注意爬电距离；输出正对机壳要绝缘
- 安装孔：金属螺丝需垫片/绝缘，避免把 12V 短到机箱
- 建议 6–8 个 M3 固定点，均匀支撑插拔力

## 7. DRC 建议起点

| 规则 | 值 |
| --- | --- |
| 最小线宽（信号） | 0.2 mm |
| 最小间距（信号） | 0.2 mm |
| 功率铜皮间距 | ≥ 1.0 mm（12V 对地） |
| 板边距 | ≥ 1.0 mm |
| 孔到铜 | 按厂家能力 |

## 8. 制造备注（写给 PCB 厂）

```text
- 4层, 2.0mm, 外层2oz / 内层1oz（或按报价升到外层3oz）
- 功率网络: VBUS_12V, PGND 大面积覆铜
- 阻焊开窗区域见 Gerber 的 *.gko / 文档标注
- 阻抗控制: 不需要
- 电测: 必须
```

## 10. 从文档到可生产文件

当前仓库提供 **原理图级参考 + PCB 约束 + 布局草图**。若需可直接打样的 Gerber：

1. 用 KiCad 7/8 按 `hardware/schematic/` 网表建工程
2. 导入设计规则
3. 按笼子实际开孔尺寸改板框
4. 导出 Gerber + 钻孔 + BOM + CPL

板框依赖具体笼子，故未锁死单一外形尺寸。
