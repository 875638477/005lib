# 方案 A：HPM53M1 — 12V 固定母线 ↔ 3S3P 锂电双向四开关 Buck-Boost

**文档版本：** v3.1  
**日期：** 2026-09-03  
**MCU：** HPM53M1IN91（QFN80）  
**状态：** 设计基线（Design Baseline）  
**与方案 B 关系：** **完全独立、不相关**。本板不引用方案 B 的母线、功率级或控制。

---

## 1. 需求记录（已冻结）

| 项目 | 规格 |
|---|---|
| 母线 | **固定 12.0V** |
| 电池 | 3S3P 锂电，包电压 **11.0–12.6V** |
| 电流 | 充/放 **5A 持续**（约 63W） |
| 拓扑 | **单相四开关同步 Buck-Boost（FSBB）**，**禁止只用 Buck** |
| 相数 | **两路半桥**（4 只 NMOS + 1 电感），**不做交错** |
| 驱动 | HPM53M1 **片内两路预驱直驱**，不用外置驱动 |
| 方向 | 同一功率级双向：12V↔电池 |

### 1.1 为什么必须用 Buck-Boost

固定 12.0V 母线对 11.0–12.6V 电池：

| 工况 | 电压关系 | 所需模式 |
|---|---|---|
| 充电，Vbat=11.0V | 12.0 → 11.0 | **Buck** |
| 充电，Vbat=12.6V（满充 CV） | 12.0 → 12.6 | **Boost** |
| 充电，Vbat≈12.0V | 电压交叉 | **Buck-Boost 混合** |
| 放电，Vbat=11.0V → 撑 12V | 11.0 → 12.0 | **Boost** |
| 放电，Vbat=12.6V → 12V | 12.6 → 12.0 | **Buck** |

只用 Buck 无法满充 12.6V，也无法从 11V 向 12V 母线放电。本方案 **全程 FSBB**。

5A 单相足够，**不需要两相交错**。HPM53M1 两路预驱正好覆盖 4 管。

## 2. 功率拓扑（单相 FSBB，两路半桥）

```
12V_BUS ── [S1/S2] ── L1 ── [S3/S4] ── BAT+
            桥臂1              桥臂2
            母线侧              电池侧
BAT- ── PGND
```

| 开关 | 位置 | 预驱 | 作用（正向充电） |
|---|---|---|---|
| S1 | 母线侧上管 | HO1 | Buck 开关 |
| S2 | 母线侧下管 | LO1 | Buck 同步整流 |
| S3 | 电池侧上管 | HO2 | Boost 同步整流 |
| S4 | 电池侧下管 | LO2 | Boost 开关 |

- **开关频率：** **200 kHz**
- **电感电流：** 5A 平均
- 放电：同一 4 管，电感电流反向，环路从电池电流环切到母线电压环
- **桥臂3（HO3/LO3）悬空不用**

## 3. 工作模式（软件必须实现）

定义：\(V_{bus}=12.0\,\text{V}\) 固定；滞回窗口 **±0.3V**。

| 模式 | 条件（充电） | S1/S2 | S3/S4 |
|---|---|---|---|
| **BUCK** | Vbat < 11.7V | PWM + 死区 | S3 常通，S4 常断 |
| **BOOST** | Vbat > 12.3V | S1 常通，S2 常断 | PWM + 死区 |
| **MIX** | 11.7V ≤ Vbat ≤ 12.3V | 两对均 PWM | 两对均 PWM |

放电时把「输入/输出」对调：Vbus 目标 12.0V，电流为负。

```
状态机：
  CHARGE_CC     : Ibat = +5.0A，按 Vbat 选 BUCK/MIX/BOOST
  CHARGE_CV     : Vbat → 12.60V，截止电流 0.2A
  DISCHARGE     : Vbus 环 = 12.00V，|Ibat| ≤ 5.0A
  IDLE          : S1–S4 全部关断
  FAULT         : 硬件刹车 + 锁存

禁止：
  - 只用 Buck 试图充到 12.6V
  - MIX 区无滞回来回切模式
```

### 4.1 功率 MOSFET（4 只，不并联）

| 位号 | 功能 | 推荐型号 | 关键参数 | 数量 |
|---|---|---|---|---|
| S1–S4 | FSBB 全管 | Infineon **BSC010N04LS** | 40V, Rds=1.1mΩ, Qg≈13nC | 4 |
| 备选 |  | Nexperia **PSMN1R0-40YSF** | 40V, Rds=1.0mΩ | 4 |

### 4.2 磁性元件

| 位号 | 参数 | 推荐 |
|---|---|---|
| L1 | **6.8µH / Isat ≥12A / DCR <8mΩ** | Würth **74438367068** 或同等 |

**电感校核（Boost，Vin=12V, Vout=12.6V, ΔI=1.5A）：**

\[
L \ge \frac{V_{bus}\cdot D\cdot(1-D)}{f_s\cdot\Delta I}
  \approx \frac{12\times0.05\times0.95}{200\text{k}\times1.5} \approx 1.9\,\mu\text{H}
\]

取 **6.8µH** 以降纹波。

### 4.3 电容

| 位号 | 参数 | 说明 |
|---|---|---|
| C_bus | 100µF/25V 陶瓷 ×2 + 220µF/16V 电解 | 12V 母线侧 |
| C_bat | 220µF/16V 聚合物 + 100µF/16V 陶瓷 | 电池端口 |
| C_bs1, C_bs2 | 1µF/25V X7R | VB1-VS1、VB2-VS2 自举 |

### 4.4 电流采样（高边 / 电感串联 — 不能直接进 ADC）

5mΩ 分流若串在电感或电池正极，两端对地约 **11–12.6V**（电感上还会跟开关节点跳变）。HPM53M1 合封 AMP 由 **ALDO 3.3V** 供电，轨到轨也只相对 3.3V；ADC 输入同样是 0–VREFH（3.3V）。**不能把 12V 共模的分流两端接到 INA+/INA− 或 ADC 脚。**

**推荐做法：5mΩ + 高压共模电流检测芯片 → 地参考电压 → ADC。**

```
SW1 ── L1 ── R_s(5mΩ) ── SW2
                 │  │
              IN+ IN−     INA240（共模 −4~80V）
                    │
                   OUT ── ADCIN3
                   REF ── 1.65V（双向零点）
```

| 位号 | 型号 | 说明 |
|---|---|---|
| R_s | **5mΩ / 1W / 1%**，2512，**开尔文 4 线** | 串在电感与桥臂2 中点之间 |
| U_cs | TI **INA240A2**（增益 **50 V/V**） | 专为 PWM 共模设计，双向 |
| 备选 | INA241A2 / 国产 **SGM840** 同类 | 共模须覆盖 0–20V 且抗 PWM |

**信号换算（双向，REF=1.65V）：**

\[
V_{\mathrm{ADC}} = 1.65 + 50 \times I_L \times 0.005 = 1.65 + 0.25\,I_L
\]

| \(I_L\) | \(V_{\mathrm{shunt}}\) | \(V_{\mathrm{ADC}}\) |
|---|---|---|
| +5.0A（充电） | +25mV | **2.90V** |
| 0 | 0 | **1.65V** |
| −5.0A（放电） | −25mV | **0.40V** |
| ±6.0A（OCP） | ±30mV | 0.15V / 3.15V（仍在 0–3.3V 内） |

REF：VAA 经 **10k/10k** 分压 + 100nF，或片内 DAC 出 1.65V。INA240 用 **+5V**（与 VCC5V 同网）供电，不要用 3.3V（输出摆幅不够）。

输入端：每脚对地 **10Ω + 100pF** 共模滤波，差分再并 **1nF**；靠近芯片放置。

**不要用片内 AMPA 做这条高边通路。** AMPA 仅当分流改到 **电池负极低边**（对地几十 mV）时才可接。

### 4.5 备选：低边分流 + 片内 AMPA（仅电池回线）

若只做包电流 CC-CV、不做电感电流内环：

- R_s 改到 **BAT− 与 PGND 之间**（低边，共模≈0）
- AMPA 接成差分，增益 20：\(V_{\mathrm{OUTA}}=1.65+0.1\,I_{\mathrm{bat}}\)
- OUTA 进 ADCIN3

低边测的是包电流，不是电感电流；FSBB 电流环仍建议用上面的 INA240。
