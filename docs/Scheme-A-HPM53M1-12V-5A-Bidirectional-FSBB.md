# 方案 A：HPM53M1 — 12V 固定母线 ↔ 3S3P 锂电双向两相交错四开关 Buck-Boost

**文档版本：** v2.0  
**日期：** 2026-09-03  
**MCU：** HPM53M1IN91（QFN80）  
**状态：** 设计基线（Design Baseline）  
**与方案 B 关系：** **完全独立、不相关**。本板不引用方案 B 的母线、功率级或控制。

## 1. 需求记录（已冻结）

| 项目 | 规格 |
|---|---|
| 母线 | **固定 12.0V** |
| 电池 | 3S3P 锂电，包电压 **11.0–12.6V** |
| 电流 | 充/放 **5A 持续**（约 63W） |
| 拓扑 | **四开关同步 Buck-Boost（FSBB）**，**禁止只用 Buck** |
| 交错 | **两相 180°**（每相一套独立 4 管 FSBB） |
| 驱动 | HPM53M1 片内预驱直驱 NMOS（第 4 半桥外置，见 §5） |
| 方向 | 同一功率级双向：12V↔电池 |

### 1.1 为什么必须用 Buck-Boost

固定 12.0V 母线对 11.0–12.6V 电池：

| 工况 | 电压关系 | 所需模式 |
|---|---|---|
| 充电，Vbat=11.0V | 12.0 → 11.0 | **Buck** |
| 充电，Vbat=12.6V（满充 CV） | 12.0 → 12.6 | **Boost** |
| 充电，Vbat≈12.0V | 电压交叉 | **Buck-Boost 混合** |
| 放电，Vbat=11.0V → 撑 12V | 11.0 → 12.0 | **Boost** |
| 放电，Vbat=12.6V → 12V | 12.6 → 12.0 | **Buck** |

只用 Buck 无法满充 12.6V，也无法从 11V 向 12V 母线放电。本方案 **全程 FSBB**。

## 2. 功率拓扑（两相交错 FSBB）

每相为独立四开关 H 桥 + 电感；两相输出并联到电池，输入并联到 12V 母线。

```
12V_BUS ──┬── [S1/S2 半桥] ── L1 ── [S3/S4 半桥] ──┬── BAT+
          │        相1 Buck侧           相1 Boost侧    │
          └── [S5/S6 半桥] ── L2 ── [S7/S8 半桥] ──┘
                   相2 Buck侧           相2 Boost侧
          BAT- ── PGND
```

| 开关 | 位置 | 作用（正向充电） |
|---|---|---|
| S1 / S5 | 母线侧上管 | Buck 开关 |
| S2 / S6 | 母线侧下管 | Buck 同步整流 |
| S3 / S7 | 电池侧上管 | Boost 同步整流 |
| S4 / S8 | 电池侧下管 | Boost 开关 |

- **相数：** 2，**180° 交错**
- **开关频率：** **200 kHz**
- **每相电流：** 2.5A 平均（总 5A）
- 放电：同一 8 管，电感电流反向，环路从电池电流环切到母线电压环

## 3. 工作模式（软件必须实现）

定义：\(V_{bus}=12.0\,\text{V}\) 固定；滞回窗口 **±0.3V**。

| 模式 | 条件（充电） | S1/S2 | S3/S4 |
|---|---|---|---|
| **BUCK** | Vbat < 11.7V | PWM + 死区 | S3 常通，S4 常断 |
| **BOOST** | Vbat > 12.3V | S1 常通，S2 常断 | PWM + 死区 |
| **MIX** | 11.7V ≤ Vbat ≤ 12.3V | 两对均 PWM（小占空比叠加） | 两对均 PWM |

放电时把「输入/输出」对调：Vbus 目标 12.0V，电流为负。

```
状态机：
  CHARGE_CC     : Ibat = +5.0A，按 Vbat 选 BUCK/MIX/BOOST
  CHARGE_CV     : Vbat → 12.60V，截止电流 0.2A
  DISCHARGE     : Vbus 环 = 12.00V，|Ibat| ≤ 5.0A
  IDLE          : 全部 PWM 关断，S1–S8 关
  FAULT         : 硬件刹车 + 锁存

禁止：
  - 只用 Buck 试图充到 12.6V
  - MIX 区无滞回来回切模式
```

## 4. 关键器件选型（BOM 基线）

### 4.1 功率 MOSFET（8 只，不并联）

| 位号 | 功能 | 推荐型号 | 关键参数 | 数量 |
|---|---|---|---|---|
| S1–S8 | 两相 FSBB 全管 | Infineon **BSC010N04LS** | 40V, Rds=1.1mΩ, Qg≈13nC | 8 |
| 备选 |  | Nexperia **PSMN1R0-40YSF** | 40V, Rds=1.0mΩ | 8 |

5A 等级每管位 **1 只**，不并联。

### 4.2 磁性元件

| 位号 | 参数 | 推荐 |
|---|---|---|
| L1, L2 | **6.8µH / Isat ≥12A / DCR <8mΩ** | Würth **74438367068** 或同等 |

**电感校核（MIX/Boost 最恶劣，Vin=12V, Vout=12.6V, ΔI=1.5A）：**

\[
L \ge \frac{V_{bus}\cdot D\cdot(1-D)}{f_s\cdot\Delta I}
  \approx \frac{12\times0.05\times0.95}{200\text{k}\times1.5} \approx 1.9\,\mu\text{H}
\]

取 **6.8µH**，降低纹波并改善两相均流。

### 4.3 电容

| 位号 | 参数 | 说明 |
|---|---|---|
| C_bus | 100µF/25V 陶瓷 ×2 + 220µF/16V 电解 | 12V 母线侧 |
| C_bat | 220µF/16V 聚合物 + 100µF/16V 陶瓷 | 电池端口 |
| C_bs1–C_bs4 | 1µF/25V X7R | 四个半桥自举 |

### 4.4 采样电阻

| 位号 | 参数 | 说明 |
|---|---|---|
| R_s1, R_s2 | **5mΩ / 1W / 1%**（2512） | 每相电感电流，接 AMPA/AMPB |

### 4.5 栅极电阻

|---|---|

## 5. 预驱分配（HPM53M1 只有 3 路半桥）

两相交错 FSBB = **4 个半桥**。片内预驱只有 3 路，第 4 路必须外置。

| 半桥 | 开关 | 驱动来源 | 输出脚 |
|---|---|---|---|
| 相1 母线侧 | S1/S2 | **片内桥臂1** | HO1(73)/LO1(60) |
| 相1 电池侧 | S3/S4 | **片内桥臂2** | HO2(69)/LO2(61) |
| 相2 母线侧 | S5/S6 | **片内桥臂3** | HO3(65)/LO3(62) |
| 相2 电池侧 | S7/S8 | **外置 UCC27282** | 由 PWM0 互补驱动 |

外置驱动：**TI UCC27282**（120V 半桥，3A，带互锁），12V 供电即可。  
PWM0 从 PA26/PA27 出互补 PWM（与 PWM1 经 TRGM **180° 同步**）。

> 若后续坚持 **8 管全部片内直驱**：只能改成 **单相 4 管 FSBB**（放弃交错）。5A 下单相完全够用，作为可选简化版见 §13。

## 13. 可选简化：单相 4 管全直驱（放弃交错）

若不要外置 UCC27282，可做成 **单相 FSBB**：

| 半桥 | MOS | 驱动 |
|---|---|---|
| 母线侧 | S1/S2 | HO1/LO1 |
| 电池侧 | S3/S4 | HO2/LO2 |
| 桥臂3 | — | 悬空；PA04/PA05 改 CAN1 |

5A 下纹波略大，控制更简单，**仍是完整 Buck-Boost，可满充 12.6V**。默认基线仍为 §2 两相交错版。
