# 24V → 220V / 4000W 离网逆变器设计（主控 HPM6284）

> 封装按 **HPM6284IPA / eLQFP144**。  
> 本文给出可落地的拓扑、电参数、引脚分配、采样链路和保护架构。  
> 400V 母线与 220V 交流侧有致命电压，24V 侧持续电流约 200A，必须按安规与热设计评审后才能制板。

---

## 1. 设计目标

| 项目 | 指标 |
| --- | --- |
| 输入 | DC 20–30V（标称 24V，铅酸 / 8S 磷酸铁锂） |
| 输出 | 单相 220V ±3% / 50Hz，纯正弦 |
| 额定功率 | 4000W 阻性连续 |
| 过载 | 5000W / 10min，8000W / 5s（电机启动） |
| 效率 | 满载 ≥ 90%，半载 ≥ 92%（目标） |
| 空载损耗 | ≤ 25W |
| THD | 阻性满载 ≤ 3% |
| 冷却 | 强制风冷，双风扇 |
| 形态 | 离网 / UPS，非并网 |

### 1.1 电应力估算

效率按 90%：

- 输入功率 \(P_{in}=4000/0.90=4444\,\mathrm{W}\)
- 标称输入电流 \(I_{in}=4444/24=185\,\mathrm{A}\)
- 低压欠压点电流 \(I_{in,20V}=4444/20=222\,\mathrm{A}\)
- 5s 浪涌（8kW）输入约 \(370\,\mathrm{A}\)
- 交流额定电流 \(I_{ac}=4000/220=18.2\,\mathrm{A_{rms}}\)，峰值 \(25.7\,\mathrm{A}\)
- 母线按 380V：\(I_{bus}\approx4000/380=10.5\,\mathrm{A}\)
- **四相均流后每相输入** \(I_{ph}=185/4\approx46\,\mathrm{A}\)，浪涌每相约 \(93\,\mathrm{A}\)

**结论：24V / 4kW 必须用高频隔离升压，不能单级 Boost。**  
前级采用 **四相交错全桥**（每相一座四管全桥 + 变压器），把 185A 拆成 4×46A，输入纹波按 90° 交错抵消。

## 2. 推荐拓扑：四相交错全桥 + SPWM 逆变

```
  24V 电池
      │
      ├─ 输入熔断 / 接触器 / 预充
      ├─ 电解 + 薄膜（低压母排）
      │
      ├──────────────┬──────────────┬──────────────┐
      ▼              ▼              ▼              ▼
  全桥相1 0°     全桥相2 90°    全桥相3 180°   全桥相4 270°
  PWM0 P0-P3     PWM0 P4-P7     PWM3 P0-P3     PWM3 P4-P7
  T1 + 整流      T2 + 整流      T3 + 整流      T4 + 整流
      │              │              │              │
      └──────────────┴──────────────┴──────────────┘
                         │
                         ▼  360–400V 高压母线
                         │
 ┌────────────────────────────────┐
 │  后级：单相全桥 SPWM 20kHz      │  PWM1 (HRPWM)
 │  单极性调制 + LC 滤波           │
 └────────────────────────────────┘
                         │
                         ▼  220V / 50Hz
```

每相都是独立的 **四管全桥**：对角管同时导通，A 臂 / B 臂互补 + 死区。电压调节用 **移相**（A 臂固定 50%，B 臂相对移动，即每相一套 PSFB）。四相载波互差 90°，不是把一只大全桥的管子简单并联。

### 2.1 为什么用四相交错全桥

| 拓扑 | 4kW@24V 评价 |
| --- | --- |
| 单相推挽 | 漏感尖峰大，管压 2Vin，电流集中 |
| 单相四管全桥 | 能做，但 185A 挤在一组变压器/铜排上 |
| **四相交错全桥** | **每相 1.1kW / 46A，磁件小，输入纹波低，坏一相可降额继续** |
| LLC×4 | 效率高，四路过增益和均流调参工作量大 |

后级仍用 **单极性 SPWM 全桥**。HPM6284 正好 4 组 PWM：PWM0/PWM3 驱动四相原边，PWM1 留给逆变，PWM2 风扇。

### 2.2 输出并联 380V，还是串联 95V×4？

四相前级有两种接法，电应力差很多。

```
方案 A  IPOP（现方案）                 方案 B  IPOS
输入并联、输出并联                     输入并联、输出串联

24V --+-- FB1 -- 1:19 -- 380V --+     24V --+-- FB1 -- 1:4.7 -- 95V --+
      +-- FB2 -- 1:19 -- 380V --+           +-- FB2 -- 1:4.7 -- 95V --+  series
      +-- FB3 -- 1:19 -- 380V --+  parallel +-- FB3 -- 1:4.7 -- 95V --+
      +-- FB4 -- 1:19 -- 380V --+           +-- FB4 -- 1:4.7 -- 95V --+
                            |                                      |
                          380V                                   380V
```

方案 B 每级约 \(380/4=95\,\mathrm{V}\)。电池 20–30V、移相有效占空比 0.85 时，变比取 \(n\approx95/(24\times0.85)\approx4.7\)（例如 4:19）。

#### 效率（B 高约 2–3 个点）

原边电流两种接法几乎一样（每相仍约 46A），MOS 导通损耗相当。差别在磁件和副边。

| 损耗项（满载 4kW，单相 1.1kW） | A 并 380V | B 串 95V |
| --- | --- | --- |
| 变压器变比 | 1:19，漏感、邻近效应、层间电容都大 | 1:4.7，Coupling 好，漏感大约只有 A 的 1/4 |
| 原边吸收/钳位 | 漏感能量大，约 1–1.5% | 约 0.3% |
| 磁芯+铜耗 | 约 1.5–2% | 约 1% |
| 副边整流 | 650V SiC，Vf≈1.5V，\(2\times2.9\times1.5\approx8.7\mathrm{W}\)/相 | 150V 肖特基 Vf≈0.6V，\(2\times11.7\times0.6\approx14\mathrm{W}\)/相；同步整流 3mΩ 则约 1W |
| 前级整机效率（估） | **91–93%** | 肖特基 **93–95%**，同步整流 **94.5–96%** |
| 系统（×后级 97%） | 约 89% | 约 91–93% |

4kW 下差 2–3% 就是少耗 80–120W，散热器能小一圈。  
**效率：B 明显高于 A**，尤其副边上同步整流之后。

注意：方案 B 最上面那级副边对原边仍有近 380V 共模，隔离耐压不能按 95V 做，四只变压器都要按加强绝缘。省的是变比和整流管压降，不是爬电距离。

#### 控制（稳态 B 简单，故障 A 简单）

| | A 输出并联 | B 输出串联 |
| --- | --- | --- |
| 自然均分 | 无。必须 4 路电流环 + 均流 | **有。** IPOS 输入并联时，同占空比下输出电压自然均分 |
| 环路 | 1 个电压环 + 4 个电流环 | **1 个电压环 + 公共移相角**；四路模块电压只监视 |
| 电流传感器 | 四相原边都要（均流） | 串联电流只有 1 路，原边电流可只做保护 |
| 软启 | 四路可错开爬坡 | 必须四路一起爬，否则串联电容不均压 |
| 切相 / 冗余 | 坏 1 相仍是 380V，功率 75% | 坏 1 级电压塌成 ~285V，逆变掉电；要冗余必须给每级加旁路管 |
| HPM6284 | 要跑四路峰值电流 + 均流 | 四路 PWM 可同一比较值，软件轻很多 |

文献结论：IPOS（输入并、输出串）在模块一致、占空比相同时，输出电压自动均分；IPOP 没有这个性质。  
**日常控制：B 方便。要“坏一路还能出 220V”：A 方便。**

#### 性能（看指标，不是一句谁强）

| 指标 | 谁好 | 原因 |
| --- | --- | --- |
| 磁件可做性、EMI、开关尖峰 | **B** | 低变比，漏感小 |
| 副边器件应力 / 成本 | **B** | 150–200V 对 650V |
| 母线电容 | **B** | 100V 电解/聚合物能量密度和 ESR 都优于 450V；每级 \(C_{95}\approx4C_{380}\) 才能能量相当，但 100V 电容仍更便宜、更矮 |
| 输入纹波（90° 交错） | 相当 | 原边交错效果一样 |
| 母线动态 / 100Hz 脉动 | 相当 | 都靠母线能量和电压环带宽 |
| 短路限流 | B 略简单 | 串联电流天然是一路 |
| 模块共模 EMI | A 略干净 | A 四路副边共模都是 380V；B 四路分别浮在 0/95/190/285V，上层变压器共模电流要单独治 |
| 可靠性（单点故障） | **A** | 并联可降额；串联是一串糖葫芦 |
| 功率密度 | **B** | 磁件和高压电容都更小 |

**综合性能（效率、密度、波形、器件应力）：B 更好。**  
**容错性能：A 更好。**

#### 哪种合适（本机结论）

这是单箱 24V / 4kW 离网机，不是热插拔电源模块：

1. **首选方案 B（24V→95V×4 串联）**  
   效率高、变压器好绕、控制可以“一个电压环打四路 PWM”、副边可用 150V 同步整流。  
   必须做：四路同步软启、每级输出电压监视（不均压 >10% 关机）、上层变压器按 380V 隔离、建议每级反并联旁路晶闸管/MOS 以便某级失效时短接该 95V。
2. **只有这些需求才留方案 A（24V→380V 并联）**  
   要切相降额、四路热插拔、或每块板必须单独能出 380V。代价是 1:19 变压器和四路均流。

中间折中：两级 24V→190V 再串联（IPOS×2）。变比约 1:9.3，仍比 1:19 好绕，容错比四串强一点。一般不如直接四串干净。

下文引脚和采样按 **方案 A** 已展开（四路原边电流均流）。若改方案 B：四路 PWM 接法不变，ADC 改为 4 路模块电压 \(V_{o1\ldots4}\) + 1 路串联电流，均流环可删。

## 3. 主控资源划分

HPM6284：双核 RISC-V，最高约 600MHz，4 组增强 PWM（PWM0/1 为 100ps HRPWM），3×16bit ADC，4×ACMP，TRGM 互联，SDM ΣΔ 解调。

| 核 | 职责 | 周期 |
| --- | --- | --- |
| **Core0** | 四相全桥：母线电压环 + 四路电流均流、输入管理、保护、通信 | 60kHz 电流环，2kHz 电压环 |
| **Core1** | 后级逆变：PR/重复控制、50Hz 锁相、RMS、过载折返 | 20kHz 电流环，100Hz RMS |

PWM0 / PWM1 / PWM3 用 **SYNCTMR + TRGM** 对齐。四相载波相位：0° / 90° / 180° / 270°。ADC 在各相电流峰值或谷值采样。

过流比较器 **片内直连 PWM FAULT**，不经过 CPU，关断时间微秒级。

## 4. 引脚分配（eLQFP144）

原则：

1. PWM 走 **Port B 连续引脚**，方便等长和驱动器排线。
2. 模拟量全部放在 **VIO_02 的 Port C**，与数字 PWM 分区。
3. 故障输入用官方 `PWMx_FAULT` 脚，同时 ACMP 经 TRGM 内部触发。
4. 高压侧电流/电压优先走 **隔离运放或 SDM**，低压侧可用差分运放。

### 4.5 硬件比较器 ACMP（直连 PWM 关断）

| 比较器 | 正端建议 | 负端 | 阈值 | 动作 |
| --- | --- | --- | --- | --- |
| ACMP0 | I_AC（与 PC12 并联） | 内部 8bit DAC | ≈ ±70A | PWM1 FAULT，封逆变 |
| ACMP1 | 四相电流模拟或（二极管或） | 内部 DAC | ≈ ±80A/相 | PWM0 FAULT + TRGM→PWM3 |
| ACMP2 | V_BUS | 内部 DAC | ≈ 430V | 全部 PWM 关 |
| ACMP3 | I_IN | 内部 DAC | ≈ 350A | 断接触器 + 封 PWM |

比较器输出走 **片内 TRGM → PWMx fault**，不必占用 `ACMP_COMP_x` 引脚。若要外观察看，可引出：

| LQFP144 | Pad | 功能 |
| --- | --- | --- |
| 71 | PC14 | ACMP_COMP_0（调试，与 NTC3 二选一） |
| 70 | PC15 | ACMP_COMP_1 |
| 69 | PC16 | ACMP_COMP_2 |

量产建议比较器输出不引出，PC14/16 留给温度和辅源。

### 4.6 隔离 ΣΔ（可选，高精度）

HPM6284 带 SDM，可直接收 AMC1306 比特流，省隔离运放后级滤波。

## 5. 电压 / 电流检测

### 5.1 采样点位置

```
电池+ ──FUSE── 接触器 ──┬── 霍尔 I_IN ── 低压母排
                        │
                      分压 V_IN
                        │
          ┌─────┬─────┬─┴─┬─────┐
        相1   相2   相3   相4     各相源极 1mΩ → I_PHx
          │     │     │     │
         T1    T2    T3    T4
          └─────┴─────┴─────┘
                    │
              隔离分压 V_BUS

逆变桥 ── AMC1302 ── I_AC
LC 后  ── AMC1311 ── V_AC
```

### 5.2 分流电阻与满量程

**四相原边电流（均流 + 逐周期限流）**

- 每相分流：\(1.0\,\mathrm{m}\Omega / 2\mathrm{W}\) 四端子锰铜，装在该相下管源极汇流
- INA240A1（增益 20），偏置 1.65V  
  \(V_{adc}=1.65 + 20 \times I \times 0.001 = 1.65 + 0.02I\)
- 额定 46A → 2.57V；硬件阈值 80A → 3.25V（仍在 3.3V 内）
- 四路运放输出再经肖特基二极管 **模拟或**，送给 ACMP1，取峰值过流

**电池输入电流**

- 200A 霍尔 ACS772ECB-200B-PFF：约 10mV/A，0A=1.65V  
  200A → 3.65V，需衰减或改 400A 规格
- 软件校验：\(I_{IN}\approx I_{PH1}+I_{PH2}+I_{PH3}+I_{PH4}\)（差模平均）

**逆变电流**

- 桥臂不能直接共地采样（高压），必须隔离
- 方案 A：AMC1302 + 4mΩ 分流（±50mV → ±12.5A 太小）  
  4kW 峰值 26A、浪涌 80A → 分流 **0.5mΩ**，±50mV → ±100A
- 方案 B：霍尔 ACS724-50A（输出侧已隔离到控制地时可用）

**电压**

| 通道 | 一次 | 分压 | 隔离 | ADC 满量程对应 |
| --- | --- | --- | --- | --- |
| V_IN | 0–36V | 100k+10k（÷11） | 无 | 36V → 3.27V |
| V_BUS | 0–500V | 4.99M + 33k，再经 AMC1311（±250mV 或 2V 型） | 有 | 500V → ≈3.0V |
| V_AC | ±400V | 差动分压 + AMC1311 | 有 | 311Vpeak → 约 2.3V 偏置中点 |

所有 ADC 入口：

- 100Ω + 1nF C0G 到地（紧贴引脚）
- 串联 1k 防锁死灌电流
- 运放输出不超过 3.3V+0.3V，加 BAT54S 钳位

### 5.3 采样时序

```
PWM0 相1 峰值/谷点 → ADC0 转 I_PH1（同步）
PWM0 相2 错 90°   → ADC0 转 I_PH2
PWM3 相3 / 相4    → ADC0 转 I_PH3 / I_PH4
同触发（可 4 分频）→ ADC1 转 V_BUS

PWM1 载波谷点     → ADC0 转 I_AC，ADC1 转 V_AC
```

四相不要在同一瞬间抢 ADC0：按各自载波中点轮流触发，HPM ADC 2MSPS 足够。Core0 在 60kHz 里更新四路电流环；电压环 2kHz。

校准：每相单独通 20.00A，写四套增益/偏置。零点在接触器断开时采。

## 6. 保护

分三层，越靠近功率器件越快。

### 6.1 第一层：硬件（< 2µs）

```
I_PH1..4（模拟或） / I_AC / V_BUS / I_IN
        │
     调理运放
        │
   ┌────┴────┐
   │ ACMP    │ 片内 DAC 阈值
   │ 或外部  │ 比较器 LM311 / TLV3501
   └────┬────┘
        │ 低有效
   PWMx_FAULT + TRGM
        │
   PWM 输出高阻 / 全低（软件可选）
        │
   驱动芯片 DIS / /SD 同时拉低（硬件与）
```

**必须硬件与：** MCU FAULT 和驱动关断脚同时有效，避免 MCU 死机后桥臂直通。

外部建议再加：

- 原边：去饱和或驱动 DESAT（UCC27714 / 隔离驱动自带）
- 母线：TVS + 压敏（385V 压敏 + 440V TVS 组合要核算，高压侧更常用放电电阻 + 硬件比较）
- 输入：ANL 250A 熔断 + 反向二极管（防反接）+ TVS 33V
- 输出：压敏 470V + 气体放电管（视认证）

### 6.2 第二层：软件周期保护（20–60kHz）

| 保护 | 阈值（建议） | 动作 | 恢复 |
| --- | --- | --- | --- |
| 输入欠压 | < 20.0V，回差 21.5V | 降额 / 关机 | 自动 |
| 输入过压 | > 30.5V | 立即封 PWM | 手动或电压回落 |
| 输入过流 | > 240A / 100ms；> 350A 硬件 | 关机 | 手动 |
| 母线欠压 | < 320V | 禁止逆变 | 前级起来后自动 |
| 母线过压 | > 420V 软件，430V 硬件 | 封两级 PWM，泄放 | 手动 |
| 单相过流 | 峰值 > 70A | 该相逐周期限流；连续 50 次切该相 | 手动 |
| 四相不平衡 | 某相与均值差 > 25% 且持续 200ms | 切该相，三相容 75% 功率 | 手动 |
| 原边总过流 | \(\sum I_{ph}>260A\) 或 I_IN>240A | 四相全关 | 手动 |
| 输出过流 | > 28A / 10s；> 45A / 1s；> 70A 硬件 | 折返或关机 | 视等级 |
| 输出过压 | RMS > 242V 或峰值 > 380V | 降调制比 / 关机 | 自动/手动 |

| 风扇故障 | FG 丢失 > 3s 且温度 > 60°C | 降额 / 关机 | 手动 |

| 看门狗 | 双核互踢 + 硬件 WDG | 复位并安全态 | — |

### 6.3 第三层：时序与机械

1. **上电：** 辅源稳定 → MCU 自检 ADC/比较器 → 预充高压电容（电阻或有源）→ 母线到 50V 合主接触器 → 前级软启到 380V → 逆变软启 0→220V（100–200ms）→ 合输出继电器（过零）。
2. **关机：** 先封逆变 → 断输出继电器 → 封四相全桥 → 母线泄放到 < 42V → 断输入接触器。
3. **短路：** 硬件封波优先于继电器；继电器不断开带载电弧。
4. **反接：** 输入串联理想二极管控制器或大功率 MOSFET 反接保护，PCB 丝印 + 机械防呆。
5. **漏电（可选）：** 输出 CT 检测 I_L−I_N，> 30mA 跳闸（便携场景建议做）。

## 7. 控制算法要点

**前级四相全桥（Core0）**

- 外环：母线电压 PI → 总电流指令 \(I_{ref}\)
- 均流：\(I_{ref,k}=I_{ref}/4 + k_s(I_{avg}-I_{ph,k})\)，四路独立移相角
- 内环：每相峰值电流模式或平均电流 PI，输出该相移相角
- 载波：SYNCTMR 60kHz，相 1–4 偏移 0 / 1/4 / 1/2 / 3/4 周期
- 移相角限幅 0.85；轻载可关相 3/4（两相 180° 交错），再轻则只留相 1
- 100Hz 纹波：电压环带宽 20–50Hz，或前馈 \(P=V_{ac}I_{ac}\)
- 一相故障：置该相 PWM 高阻，\(I_{ref}\) 按剩余相数分配，功率上限 75%/50%/25%

**后级（Core1）**

- 电压外环：PR 控制器，谐振点 50Hz，\(G_r(s)=2k_r\omega_c s/(s^2+2\omega_c s+\omega_0^2)\)
- 电流内环：电感电流 P 或 PR（3、5、7 次谐波）
- 重复控制可选，改善非线性负载 THD
- 软启动：调制比斜坡，避免磁偏和冲击
- 限流：电压环输出限幅，短路时切恒流 20A 持续 2s 再跳闸

双核共享：`vbus`、`pout`、`fault_word` 放 D-cache 非缓存 SRAM，用硬件信号量。

## 8. PCB / 结构要点

1. **24V 功率：** 总母排仍按 200A；每相从母排用等长铜皮/铜排引出，四相布局对称，否则均流先失败。
2. **驱动：** 每相一组驱动地，门极 2.2–4.7Ω；四相 PWM 线等长或就近加数字隔离后再到驱动。
3. **磁件：** 四只变压器漏感要接近（建议同批次夹绕）；副边电感 DCR 差会破坏均流。
4. **模拟：** 四路分流开尔文，INA240 紧贴分流；模拟或二极管选低正向压差的肖特基。
5. **热：** 四相沿风道并列，避免上风相加热下风相导致电流抢。
6. **EMI：** 交错后输入纹波小，但仍要每相 RC/RCD；交流侧共模电感保留。
7. **安规：** 四只变压器都按加强绝缘爬电，不要只做一只的安规。

## 11. 风险（必须正视）

1. **24V / 200A 总母排**仍然在：四相只是把电流拆开，进线端子和接触器不会变轻松。
2. **均流**：漏感、门极延迟、分流误差都会让某一相吃满。必须做有源均流，不能只靠变压器阻抗。
3. **四相直通**：任何一相直通都足以炸母排。FAULT 必须同时封 PWM0 和 PWM3。
4. **母线 100Hz 纹波**：电压环太快会和输出抢功率。
5. **认证**：四路隔离变压器都要做耐压，本文不是认证报告。
