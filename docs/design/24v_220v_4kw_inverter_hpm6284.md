# 24V → 220V / 4000W 离网逆变器设计（主控 HPM6284）

> 封装按 **HPM6284IPA / eLQFP144**。  
> 本文给出可落地的拓扑、电参数、引脚分配、采样链路和保护架构。  
> 400V 母线与 220V 交流侧有致命电压，24V 侧持续电流约 200A，必须按安规与热设计评审后才能制板。

---

## 1. 设计目标

| 项目 | 指标 |
| --- | --- |
| 输入 | DC 20–30V（标称 24V，铅酸 / 8S 磷酸铁锂） |
| 输出 | 单相 220V ±3% / 50Hz，纯正弦 |
| 额定功率 | 4000W 阻性连续 |
| 过载 | 5000W / 10min，8000W / 5s（电机启动） |
| 效率 | 满载 ≥ 90%，半载 ≥ 92%（目标） |
| 空载损耗 | ≤ 25W |
| THD | 阻性满载 ≤ 3% |
| 冷却 | 强制风冷，双风扇 |
| 形态 | 离网 / UPS，非并网 |

### 1.1 电应力估算

效率按 90%：

- 输入功率 \(P_{in}=4000/0.90=4444\,\mathrm{W}\)
- 标称输入电流 \(I_{in}=4444/24=185\,\mathrm{A}\)
- 低压欠压点电流 \(I_{in,20V}=4444/20=222\,\mathrm{A}\)
- 5s 浪涌（8kW）输入约 \(370\,\mathrm{A}\)
- 交流额定电流 \(I_{ac}=4000/220=18.2\,\mathrm{A_{rms}}\)，峰值 \(25.7\,\mathrm{A}\)
- 母线按 380V：\(I_{bus}\approx4000/380=10.5\,\mathrm{A}\)

**结论：24V / 4kW 必须用高频隔离升压，不能单级 Boost。**  
24V 升到 380V 变比约 16，单级 Boost 占空比 > 93%，电感电流和开关应力不可接受。

## 2. 推荐拓扑：两级隔离

```
  24V 电池
      │
      ├─ 输入熔断 / 接触器 / 预充
      ├─ 电解 + 薄膜母线电容（低压）
      │
      ▼
 ┌────────────────────────────────┐
 │  前级：移相全桥 PSFB 50–80kHz  │  PWM0 (HRPWM)
 │  4× 并联 MOSFET 桥臂            │
 │  高频变压器 n ≈ 1:19            │
 │  副边全波整流 + LC              │
 └────────────────────────────────┘
      │
      ▼  360–400V 高压母线
      │  薄膜 + 电解
      ▼
 ┌────────────────────────────────┐
 │  后级：单相全桥 SPWM 20kHz      │  PWM1 (HRPWM)
 │  单极性调制 + LC 滤波           │
 │  继电器 / NTC 软启              │
 └────────────────────────────────┘
      │
      ▼  220V / 50Hz
```

### 2.1 为什么选移相全桥，而不是推挽 / LLC

| 拓扑 | 4kW@24V 评价 |
| --- | --- |
| 推挽 | 变压器利用率差，漏感尖峰大，管压 2Vin，4kW 不推荐 |
| 硬开关全桥 | 能做，但开关损耗和 EMI 差 |
| **移相全桥 PSFB** | **原边电流大时 ZVS 容易实现，器件应力低，控制与 HPM PWM 匹配** |
| LLC | 效率更高，但增益范围窄，宽电池电压 + 负载突变调参难 |

后级用 **单极性 SPWM 全桥**（不是工频变压器）：体积小、波形好，HPM6284 的 HRPWM + 死区 + 故障关断正好够用。

### 2.2 关键功率参数

**前级 PSFB**

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 开关频率 | 60kHz | 磁芯 / 损耗折中 |
| 变压器变比 | 1 : 18.6（取 4:74 或 3:56） | \(n=V_{bus}/(V_{in}D_{eff})\)，\(D_{eff}\approx0.85\) |
| 原边 MOSFET | 每桥臂 6–8 只 80–100V、≤1.5mΩ | 例如 IPT015N10N5 / BSC010N04LS 一类 |
| 等效 \(R_{DS(on)}\) | ≤ 0.4mΩ / 桥臂 | \(2\times185^2\times0.4\mathrm{m}\Omega\approx25\mathrm{W}\) 导通损耗 |
| 驱动 | 半桥驱动 UCC27211A 或隔离 UCC21520 | 原边参考电池地，可用自举 |
| 副边整流 | 650V SiC SBD 或超快恢复，≥20A×4 | 例如 FFSH2065A |
| 输出电感 | 约 200–400µH / 15A | 铁硅铝或铁镍 |
| 高压母线 | 380V 标称，360–400V 工作 | 4×680µF/450V + 数颗 2.2µF/630V 薄膜 |

**后级逆变**

| 参数 | 取值 |
| --- | --- |
| 载波 | 20kHz 单极性 SPWM |
| 死区 | 400–600ns（按驱动和米勒平台实测） |
| 开关 | 650V / 75A IGBT（IKW75N65EH5）或 650V 超结 MOSFET |
| 驱动 | 隔离双通道 UCC21520 / 2EDF7275K |
| 滤波 | L = 0.8–1.2mH，C = 4.7–10µF / 400VAC（差模） |
| 输出继电器 | 40A 磁保持或双触点，软件过零投切 |

### 2.3 辅助电源

从 24V 取电，与控制地共地（原边侧）：

| 电源 | 方案 | 负载 |
| --- | --- | --- |
| 12V / 3A | 同步降压（LM5145 等） | 风扇、继电器、驱动原边 |
| 5V / 1A | 降压 | USB、运放 |

## 3. 主控资源划分

HPM6284：双核 RISC-V，最高约 600MHz，4 组增强 PWM（PWM0/1 为 100ps HRPWM），3×16bit ADC，4×ACMP，TRGM 互联，SDM ΣΔ 解调。

| 核 | 职责 | 周期 |
| --- | --- | --- |
| **Core0** | 前级 PSFB 电压/电流环、输入管理、保护状态机、通信 | 60kHz 电流环，2kHz 电压环 |
| **Core1** | 后级逆变：PR/重复控制、50Hz 锁相、RMS、过载折返 | 20kHz 电流环，100Hz RMS |

PWM0 与 PWM1 用 **SYNCTMR + TRGM** 对齐，保证 ADC 在开关中点采样。

过流比较器 **片内直连 PWM FAULT**，不经过 CPU，关断时间微秒级。

## 4. 引脚分配（eLQFP144）

原则：

1. PWM 走 **Port B 连续引脚**，方便等长和驱动器排线。
2. 模拟量全部放在 **VIO_02 的 Port C**，与数字 PWM 分区。
3. 故障输入用官方 `PWMx_FAULT` 脚，同时 ACMP 经 TRGM 内部触发。
4. 高压侧电流/电压优先走 **隔离运放或 SDM**，低压侧可用差分运放。

| 117 | PB14 | PWM0_P_2 (ALT16) | 出 | 原边 B 臂上管 Q3 |

## 5. 电压 / 电流检测

### 5.1 采样点位置

```
电池+ ──FUSE── 接触器 ──┬── 霍尔 I_IN ── 低压母线 ── PSFB 原边
                        │
                      分压 V_IN

PSFB 原边下管源极 ── 0.2mΩ 分流 ── I_PRI（峰值电流环 + 逐周期限流）

变压器副边整流 ── 2mΩ 分流 ── I_BUS（平均电流、短路）

高压母线 ── 隔离分压 V_BUS

逆变桥下管 ── 分流/隔离 ── I_AC（PR 电流环、过流）

LC 之后 ── 隔离分压 V_AC（电压环、RMS、过压）
```

### 5.2 分流电阻与满量程

**原边电流（最关键）**

- 分流：\(0.2\,\mathrm{m}\Omega / 5\mathrm{W}\) 四端子锰铜，母排安装
- 满量程 250A → \(50\,\mathrm{mV}\)，正好匹配 AMC1302（±50mV）或 INA240（±内部增益后）
- 推荐：**INA240A2（增益 50）**，共地、带宽够 60kHz 电流环  
  \(V_{adc}=1.65 + 50 \times I \times 0.0002 = 1.65 + 0.01I\)  
  250A → 4.15V 会饱和，故分流改为 **0.15mΩ** 或增益改 A1（20）：  
  \(V_{adc}=1.65 + 20 \times I \times 0.0002 = 1.65 + 0.004I\)  
  ±300A → 0.45–2.85V，落在 0–3.3V 内

**电池输入电流**

- 200A 霍尔 ACS772ECB-200B-PFF：灵敏度约 10mV/A，0A=1.65V  
  200A → 3.65V，需衰减到 3.3V 或选 400A 规格
- 或与 I_PRI 共用分流（软件积分），省一只霍尔

**逆变电流**

- 桥臂不能直接共地采样（高压），必须隔离
- 方案 A：AMC1302 + 4mΩ 分流（±50mV → ±12.5A 太小）  
  4kW 峰值 26A、浪涌 80A → 分流 **0.5mΩ**，±50mV → ±100A
- 方案 B：霍尔 ACS724-50A（输出侧已隔离到控制地时可用）

**电压**

| 通道 | 一次 | 分压 | 隔离 | ADC 满量程对应 |
| --- | --- | --- | --- | --- |
| V_IN | 0–36V | 100k+10k（÷11） | 无 | 36V → 3.27V |
| V_BUS | 0–500V | 4.99M + 33k，再经 AMC1311（±250mV 或 2V 型） | 有 | 500V → ≈3.0V |
| V_AC | ±400V | 差动分压 + AMC1311 | 有 | 311Vpeak → 约 2.3V 偏置中点 |

所有 ADC 入口：

- 100Ω + 1nF C0G 到地（紧贴引脚）
- 串联 1k 防锁死灌电流
- 运放输出不超过 3.3V+0.3V，加 BAT54S 钳位

### 5.3 采样时序

```
PWM0 周期（60kHz）
  ├─ 中点 TRGM → ADC0 转 I_PRI
  └─ 同沿     → ADC1 转 V_BUS（可降频每 4 拍一次）

PWM1 周期（20kHz）
  ├─ 载波谷点 → ADC0 转 I_AC
  └─ 载波谷点 → ADC1 转 V_AC
```

Core1 在 20kHz 中断里跑电流环；电压环 10kHz 或更慢。RMS / 频率 / 保护 1–2ms 任务。

校准：出厂用 24.000V 源和 50.00A 分流器写 Flash 增益/偏置。INA240 和霍尔都要做零点（关机或继电器断开时采）。

## 6. 保护

分三层，越靠近功率器件越快。

### 6.1 第一层：硬件（< 2µs）

```
I_PRI / I_AC / V_BUS / I_IN
        │
     调理运放
        │
   ┌────┴────┐
   │ ACMP    │ 片内 DAC 阈值
   │ 或外部  │ 比较器 LM311 / TLV3501
   └────┬────┘
        │ 低有效
   PWMx_FAULT + TRGM
        │
   PWM 输出高阻 / 全低（软件可选）
        │
   驱动芯片 DIS / /SD 同时拉低（硬件与）
```

**必须硬件与：** MCU FAULT 和驱动关断脚同时有效，避免 MCU 死机后桥臂直通。

外部建议再加：

- 原边：去饱和或驱动 DESAT（UCC27714 / 隔离驱动自带）
- 母线：TVS + 压敏（385V 压敏 + 440V TVS 组合要核算，高压侧更常用放电电阻 + 硬件比较）
- 输入：ANL 250A 熔断 + 反向二极管（防反接）+ TVS 33V
- 输出：压敏 470V + 气体放电管（视认证）

### 6.2 第二层：软件周期保护（20–60kHz）

| 保护 | 阈值（建议） | 动作 | 恢复 |
| --- | --- | --- | --- |
| 输入欠压 | < 20.0V，回差 21.5V | 降额 / 关机 | 自动 |
| 输入过压 | > 30.5V | 立即封 PWM | 手动或电压回落 |
| 输入过流 | > 240A / 100ms；> 350A 硬件 | 关机 | 手动 |
| 母线欠压 | < 320V | 禁止逆变 | 前级起来后自动 |
| 母线过压 | > 420V 软件，430V 硬件 | 封两级 PWM，泄放 | 手动 |
| 原边过流 | 峰值 > 260A | 逐周期限流；连续 50 次关机 | 手动 |
| 输出过流 | > 28A / 10s；> 45A / 1s；> 70A 硬件 | 折返或关机 | 视等级 |
| 输出过压 | RMS > 242V 或峰值 > 380V | 降调制比 / 关机 | 自动/手动 |
| 输出短路 | I_AC 上升率 + 电压塌陷 | 封波，继电器断开 | 手动 |
| 过温 | MOS 95°C，IGBT 105°C，变 110°C | 先降额，再关机 | 温度回落 15°C |
| 风扇故障 | FG 丢失 > 3s 且温度 > 60°C | 降额 / 关机 | 手动 |
| 急停 | PC02 低 | 全关 + 继电器断 | 手动 |
| 看门狗 | 双核互踢 + 硬件 WDG | 复位并安全态 | — |

### 6.3 第三层：时序与机械

1. **上电：** 辅源稳定 → MCU 自检 ADC/比较器 → 预充高压电容（电阻或有源）→ 母线到 50V 合主接触器 → 前级软启到 380V → 逆变软启 0→220V（100–200ms）→ 合输出继电器（过零）。
2. **关机：** 先封逆变 → 断输出继电器 → 封前级 → 母线泄放到 < 42V → 断输入接触器。
3. **短路：** 硬件封波优先于继电器；继电器不断开带载电弧。
4. **反接：** 输入串联理想二极管控制器或大功率 MOSFET 反接保护，PCB 丝印 + 机械防呆。
5. **漏电（可选）：** 输出 CT 检测 I_L−I_N，> 30mA 跳闸（便携场景建议做）。

## 7. 控制算法要点

**前级（Core0）**

- 内环：原边峰值电流模式或平均值电流 PI
- 外环：母线电压 PI，带宽 20–50Hz，避免和 100Hz 输出脉动抢
- 100Hz 纹波：电压环前馈输出功率 \(P=V_{ac}I_{ac}\)，或电压环带宽压低、靠母线电容撑
- 移相角限幅、最大占空比 0.85，留谐振和死区
- 轻载：跳周期或降低移相下限，防丢失 ZVS

**后级（Core1）**

- 电压外环：PR 控制器，谐振点 50Hz，\(G_r(s)=2k_r\omega_c s/(s^2+2\omega_c s+\omega_0^2)\)
- 电流内环：电感电流 P 或 PR（3、5、7 次谐波）
- 重复控制可选，改善非线性负载 THD
- 软启动：调制比斜坡，避免磁偏和冲击
- 限流：电压环输出限幅，短路时切恒流 20A 持续 2s 再跳闸

双核共享：`vbus`、`pout`、`fault_word` 放 D-cache 非缓存 SRAM，用硬件信号量。

## 8. PCB / 结构要点

1. **24V 功率：** 铜排或 4oz + 多过孔，往返极短；电解就近并联薄膜。
2. **驱动：** 每个 MOSFET 独立门极电阻 2.2–4.7Ω + 1Ω 关断加速；Kelvin 源极；驱动环路 < 15mm。
3. **隔离：** 高频变压器原副边爬电 ≥ 6mm（加强绝缘按认证再加）；逆变驱动与采样隔离电源独立。
4. **模拟：** ADC 分区、单点接地；分流开尔文走线；霍尔远离变压器漏磁。
5. **热：** 原边 MOS 和变压器是主要热源；风道先过 MOS 再过变压器；NTC 贴壳。
6. **EMI：** 原边 RC/RCD 吸收；共模电感在交流输出；输入 π 型滤波。
7. **安规：** 输出对地、原副边按 IEC 62109 / GB 4943 做耐压和爬电。

## 11. 风险（必须正视）

1. **24V / 200A**：接触电阻 1mΩ 就是 40W，端子和铜排比拓扑更容易先烧掉。
2. **变压器漏感**：4kW 原边必须夹绕 / 平面矩阵，否则尖峰打穿 100V MOS。
3. **母线 100Hz 纹波**：电压环太快会和输出抢功率，表现为蜂鸣和电流振荡。
4. **直通**：死区、米勒钳位、FAULT 硬件与，三件套缺一不可。
5. **认证**：离网逆变器仍要做安规、EMC、温升，本文不是认证报告。
