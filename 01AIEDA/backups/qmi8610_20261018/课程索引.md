## 固定目标与验收方式

- 完整流程：原理图符号、Padstack、PCB 封装、原理图、布局、两层/四层精细走线、审查与生产输出。
- SI、PI、EMI 与辐射控制落实到实际器件位置、回路、参考平面、铜、过孔和信号路径；本主线不以软件仿真为前提。
- 走线按路径预判、分段操作和实际几何复核进行，不能用自动布线、网络连通或 DRC=0 代替设计质量。
- 每课保存来源/版本、前提、操作步骤、工程理由、实操文件、检查结果、问题和回退方式；先用隔离练习工程。
- 真实器件的编号、尺寸、电气要求与高度按具体数据手册核对；抽象练习尺寸单独标注。
- 已知限制：桌面控制尚未恢复，Capture 内部 Tcl 待验证；已验证的原生 CLI/SKILL 可继续用于适用操作。第 3 课几何精度疑点继续保留。

## 封装默认规范

至少包含以下文字层，锚点均为封装局部原点 **(0,0)**：

| 内容 | Class / Subclass | 坐标 |
| --- | --- | --- |
| 位号 | REF DES / SILKSCREEN_TOP | (0,0) |
| 位号 | REF DES / ASSEMBLY_TOP | (0,0) |
| VALUE | COMPONENT VALUE / ASSEMBLY_TOP | (0,0) |

默认 package height **1 mm**。具体 Cadence 属性和已完成的当前封装修订见 [封装默认规范](learning/notes/package_defaults.md)。
