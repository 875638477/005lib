# 公共封装替换时保留旧热焊盘连接铜

适用范围：Allegro 17.2将旧封装替换为公共标准封装后，原生引脚分区已经相同，但完整原铜覆盖检查仍发现缺片。这里记录通用判定方法；实际工程结果以最终原生报告为准。

## 先识别对象归属

不要仅按线段外观或端点猜测。独立打开只读源板，定位实际`line`，保存完整`parent`链、对象属性和父`path`属性，再遍历符号children确认是否属于`symbolEtch`。

- 板级手工走线：应按源网络、原路径、宽度、层和属性核查，不能因总连接数相同就忽略丢铜。
- 旧封装自带Etch：需要与允许替换的封装图形分开判断；不要把旧焊盘形状重新叠加到标准封装上。
- `path.thermal=t`且`symbolEtch=nil`：属于原热焊盘连接铜。替换焊盘会改变局部热连接，必须区分焊盘内部预期变化和外部原铜缺失。

## 用实际REGULAR铜做边界

取源引脚实际坐标、旋转和镜像后的REGULAR铜面，禁止用名称推尺寸、bbox或未变换的pad定义代替。将源线段完整铜面和旧REGULAR铜面在源板只读会话中冻结为detached native polygons，顶层打开独立候选板，再使用原生布尔计算：

```
missing = sourceThermalCu ANDNOT targetSameNetActualCu
outside = missing ANDNOT sourceActualRegularPad
inside  = missing AND sourceActualRegularPad
```

`inside`可属于已批准的标准焊盘几何替换，不应为了“源铜完全相同”把旧land补回。`outside`不属于旧land内部变化，需单独处理。实际完整铜必须包括同网走线、形状、符号Etch、引脚及过孔铜，不能只查是否有相同端点的旧线段实体。Cadence会自动并线，实体数变化不等于丢铜。

## 有限恢复与验证

只恢复已确认的`outside`原生缺片，逐片限定在实际源铜内；先检查与实际其他网络铜零交。若发现原设计已有跨网接触，必须保留原始失败并建立逐对象源基线，不能放开通用“允许交叠”。恢复后反向读取实际创建铜，对原生多边形双向比对，检查没有扩大到源铜外或把旧land带回。

另外必须独立验证全部引脚的实际连接成员，而不只比较分区数量。即便“分区数量不变”，也可能同时断开一组、误并另一组。无网络、空字符串网络和真正NC引脚必须保留各自类型。

完整核验还包括全部过孔的网名/焊盘/位置/属性、全部器件姿态与文字属性、封装缓存、原规则完整内容、网表与原生器件功能定义。恢复原连接并不代表完成全板DRC或制造签核。

## 本轮实测阶段记录

一个毫米4位精度模块的25条旧热焊盘线，原生检查为25条`thermal=t`、`symbolEtch=nil`。766条标准焊盘内部短段恢复后，全2698焊盘的915个连接分组与源逐组相同，1739个过孔逐项相同；但25条原铜中仍有缺片。严格源旧REGULAR边界检查显示21处外部缺片共约0.181194854 mm²，其余约0.882277921 mm²位于旧land内。旧land全包含假设的FAIL保留，不能把915组PASS当成铜完全保留。外部恢复及最终结果见后续有限原生恢复报告。

只读脚本：`run_public0010_source25_owner_probe_v1.py`、`run_public0010_source25_owner_probe_v2.py`。原生输入、属性、polygon及每一步FAIL/PASS均按SHA冻结；旧版本不覆盖。
