# 原生动态铜差复核方法

本方法用于统一封装之后复核动态铜重新计算造成的差异。修改封装得到的板文件仍须通过实际引脚网络、物理连通分区、规则、手工走线和文字属性等独立门禁；动态铜面积较小本身不是通过条件。

1. 用同一 Allegro 原生导出函数、同一单位和 `sstatus(fullPrecision t)`，保存源板与候选板的每个实际铜轮廓、全部孔、弧半径、网络、层及源边界。以板文件 SHA 绑定每次只读输出。不得仅导出动态铜的外边界。
2. 用十进制完整坐标规范化环起点；保留弧方向和有符号半径。完整相同的轮廓精确抵消。保留原始“全部铜相等”的失败报告，不能将后续有界接受结果覆盖到旧报告。
3. 另作未改封装的网表导入对照，区分一般保存行为和实际换封装引起的重新计算。比较每个引脚与器件的全部属性，避免把丢失热焊盘或连接属性误认为正常重算。
4. 对不等轮廓做原生 `ANDNOT`，分别保存新增铜和减少铜。相同的公共孔只有在属于两侧相同有效内部孔时才能抵消。保留全部片段的弧、孔、面积及边界；不能只检查总面积。
5. 如果删除的源孔可能已被同网铜覆盖，应从源板收集该区域的实际 REGULAR 焊盘、过孔、ROUND 线段及实际铜皮，再用原生差集计算孔中真正没有铜的区域。比较目标板同一孔区，不能只用焊盘 bbox 判断覆盖。
6. 每个新增铜片都必须与其它网的实际铜做原生相交检查，并增加严格的正安全检查边距。`axlPolyExpand` 的 `(nil)` 结果不能作为“无交集”的证据。

极小片段可能在原生扩张中消失。`native_polygon_margin_guard.il` 提供保守处理：先确认输入是正面积原生 polygon，再尝试正常扩张；若扩张为空，构造 bbox 外扩三倍 margin 的纯内存矩形，检查原生舍入后四侧仍至少保留两倍 margin，并以原生 `ANDNOT` 验证矩形包含原片。只有其它网铜与这个更大的矩形也无交集才允许继续。这个矩形用于更严格的接触检查，不是允许铜移动的范围。该独立通用文件是当前项目 V5 函数的参数化提取版本；其独立入口尚未另外做原生试跑。

另外，原生布尔算法可能返回非空的极小 polygon，其 `area` 访问器却舍入为零。此时不能把它当空集删除。当前项目后续版本保存完整对象和诊断，要求原生 bbox 仍有正宽、高，然后直接使用上述保守矩形与原生包含证明，并在报告中单独标明“原生面积访问器为零”。几何是否为空仍以完整原生对象和布尔操作为准，面积标量只是诊断。若 bbox、包含证明或其它网接触检查失败，应停止。通用提取文件目前仍只接受正面积输入，避免未显式处理此情况的调用者误用。

对大板应先为每个板建立一次实际铜对象索引：组件全部引脚、实际 ETCH 铜皮及网络分支中的过孔与完整 path，按 dbid 去重。完整 path 已包含线和弧，不再重复深入这些几何段。只有 `dbid->?` 明确列有 `children` 或 `segments` 的容器才遍历这些属性。每个片段只筛选索引中的网名、层和 bbox，原生 polygon 转换按 dbid+层缓存；原生相交门禁不变。索引仍须以源板已知的物理引脚和过孔总数作完整性检查。

较慢或不稳定的原生运行应在函数入口、每个收集阶段、打开第二块板前后以及每个差异 key 前后即时写入并 `drain` 一个阶段文件。等待超时后能据此区分打开板卡住、收集图遍历慢与布尔操作慢。进程未完整结束时，不得通过已有部分输出推测通过。

已遇到的17.2生命周期问题：在一个 SKILL 回调内调用 `axlOpenDesignForBatch` 打开第二块板可能卡住，阶段记录表现为源收集和源局部铜布尔均完成，仅停在打开目标板之前。可将流程拆成“源准备函数→顶层普通 `edit` 命令→目标完成函数”。源准备把所有需要跨板保留的 polygon 用 `axlPolyOffset(... '(0.0 0.0) t)` 生成独立副本，保存为本次工作独占的全局上下文，关闭源阶段日志端口；目标完成重新检查上下文、重新建立目标板对象索引并继续原来的完整门禁。不能跨板保留源 dbid 后当目标对象使用，也不能在 edit 前后复用对象或 polygon 转换缓存。原生普通 edit 命令也只作用于受控副本，检查过程不保存板文件。

后续实际校准：本机顶层 `edit` 仍进入 generaledit 循环；改用顶层 `open "目标副本.brd"` 后确实完成切板，目标收集、索引及局部铜阶段均成功。安装目录的官方 `doc/algroskill/14dsnctl.html` 说明 `axlOpenDesignForBatch` 对应 edit，而 `axlOpenDesign` 对应 open；open 会重设 commands/menus。遇到同样环境问题时应优先采用已验证的顶层 open 顺序，并保留此前的失败阶段记录。

不能只在扩张结果为空时检查：已观察到非空 `axlPolyExpand` 结果仍未完整包含原片。检查原片减去扩张结果的原生余片，若非空，应保留拒绝的扩张和完整余片证据，再改用保守 guard；最后的 guard 仍必须通过原生包含证明和其它网相交检查。此错误属于检查用扩张不可靠，不能推断原设计发生短路，也不能直接把余片忽略。

本方法中的额外0.01mil margin是诊断增强，不是自动加入用户设计的线间距规则，也不应在任务无此要求时自行成为永久阻塞项。可保留其严格FAIL，同时对真正新增generated片段与原始同网总铜逐片 `ANDNOT`：源阶段按冻结片段bbox预载同网实际pads/vias/whole paths/shapes独立polygon，顶层open目标后重算片段并先核对全部弧和孔，再减去源同网真实铜。bbox仅用于收集对象，不作为通过范围。若结果非空，逐片记录真实有界余片，不能宣称总铜相等；若全部为空，也只证明这些generated新增片被覆盖，不能推广到其它减少铜或换封装焊盘。

负片内层的原生多边形表示需要结合层类型解释。源板窗口中的跨网图形相交不能直接等同物理短路；应同时核实际引脚连通分区、网络状态、层语义及用户规则。最终有界接受应写清固定几何证据和具体适用范围，既不能把旧严格FAIL改成PASS，也不能因为任意自加诊断边距失败而无限拖延已经通过实际任务门禁的迁移。

原生空集必须与失败区别处理：`axlPolyOperation` 返回 bare `nil` 或有 `axlPolyErrorGet` 错误时应停止；合法空列表占位 `(nil)` 可移除其中的 nil 后按空集处理。最终完成标记只在全部片段遍历结束后写入，不能依据进程退出码为零或空交集文件判定成功。

最终报告必须绑定源板、候选板、原生输入副本和原始几何文件 SHA；逐片核对每个新增片都有正面积输入、完整 guard 与直接/边距两项检查。若接受有限的原生重算变化，明确列出网络、层、每片完整边界及量化面积，说明哪些部分不再与源铜完全相同。其它静态铜、手工铜、边界和未变化动态铜仍应保持完整精确门禁。

当前工程的精确文件、实际执行结果和正式发布 SHA 留在工程验证目录及正式发布记录中。本文件只记录可复用的方法；不会把尚未完成的原生运行记为通过。
