# 2698 个物理焊盘台账的字段范围

两份完整 `*_WITH_NONLOGICAL_IDENTITIES.ilist`、逻辑 572 元件 ilist 和非逻辑 21 对象 ilist 是交给原生检查器的预期台账。每个 pin 的预期字段严格为：脚号、世界坐标、具有类型的网络名、机械标志、通孔标志、padstack 名。所有 2698 个 pad 均有记录，含重复脚号、机械 pad、native nil 和带引号的空网络串。

JSON 是源快照与这些明确预期字段的审计容器。对迁移的 806 个 pin，JSON 中 `rel_x`、`rel_y`、`rotation` 沿用源快照用于追溯，**不能作为新封装相对坐标或朝向的预期值**；预期位置是四位 mm 网格的 `x`、`y`，新 padstack 是 `padstack`。新封装局部坐标、焊盘几何及旋转由目标独立 cold-native 定义另验。台账不声称已验证数据库实际附着、线端或完整铜连接；这些仍须候选保存重开后的全体 GetConnect 与原生几何检查。

非逻辑对象没有位号，使用名称、定义、位置、旋转、镜像及同姿态重复出现次序区分，不能把 21 个对象放进一个 nil 位号字典。它们包含 10 个 pad 和 11 个零 pad 对象，后者同样属于必须保留的物理对象。
