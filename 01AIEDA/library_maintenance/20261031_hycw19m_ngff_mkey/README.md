## 与立创下载包的差异

用户下载的 `ProLib_1pcs_2026-10-31.elibz2` 只有 PCB 封装，不含原理图符号。

| 项目 | 原厂推荐主版本 | 下载包中的立创版本 |
| --- | --- | --- |
| 焊盘 | 矩形 0.30×1.55 mm | 长圆 0.30×1.20 mm |
| 排中心 | Y=±2.955 mm | Y≈±2.900 mm |
| 铜外缘总跨度 | 7.460 mm | 7.000 mm |
| 定位孔表达 | 原生无铜 NPTH | 多层 FILL 圆形，没有 HOLE 记录 |

立创封装的脚号、X 坐标及定位孔名义尺寸与原厂布局一致。制作时未把多层图形当作已经存在的加工钻孔，而是建立了两个真正的不镀铜机械孔。原下载包保持原样；展开后的原件与完整差异表保存在制作归档的 `source/lceda_export`、`verification/lcsc_comparison.json`。

## 使用方法

1. Capture：在 Place Part 中 Add Library，选择本目录的 OLB，放置 `HYCW19M-05NGFF-530B`。其 PCB Footprint 已绑定为 `hycw19m_05ngff_530b`。
2. Allegro：把本目录同时加入当前项目的 `psmpath` 和 `padpath`。保留同目录的 PSM 与三个主版本 PAD；DRA 用于后续编辑。此任务没有修改全局库搜索路径或系统环境变量。
3. PCB 实例的位号在实际排板时移至可读位置；按库约定保留的中心锚点不是最终整板丝印排版结果。
