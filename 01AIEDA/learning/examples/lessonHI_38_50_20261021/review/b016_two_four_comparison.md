# b016两层与四层实铜比较（阶段记录）

记录日期：2026-10-22。两板均已保存及独立重开，但各剩16连接/14网，整板DRC为null。本文是中间阶段比较；第45/50课尚未完成。

以下长度从最新原生normalized.json逐段计算，只计fixedManualCline，排除generated thermal；它是同网所有平面线段之和，包含合法分支，不等于任意两脚间最短路径或延时。via数按实际对象，不把过孔桶长混进平面长度。两板80件/69网/272个pad一致。

| 比较项 | 两层b016 | 四层b016 |
| --- | --- | --- |
| CAN_RXD | 52.3953 mm / 2 via | 30.4067 mm / 2 via |
| VBUS_PRESENT_N | 54.2326 mm / 2 via | 35.9041 mm / 2 via |
| UART_RX | 25.1035 mm / 2 via | 25.1035 mm / 2 via |
| UART_TX | 32.5064 mm / 1 via | 32.8772 mm / 1 via |

两层CAN_RXD需绕开现有底层通道及接口结构，四层的实际参考平面安排允许较直接的底层路线。本版该网平面长度相差约21.99mm；这说明本次具体布局的取舍，不能推论任意四层板都必然更短。两板均需结合真实返回铜及换层位置验收。

参考初筛见[实际投影记录](reference_projection_screen_b016.json)。初筛保留真实填充polygon、全部孔与官方弧线，投影到2L的对面层，或4L的TOP→L2、BOTTOM→L3；明确排除HSE专用quiet岛。结果没有把同层地线、焊盘或via铜盘算成完整平面，也没有在此脚本中证明每片铜共地，因此只用于找开口。

上表缺口合计是各线段中心线落在所选plane外的长度，允许0.0001mm解析边界误差；不是一个连续开槽长度，不代表缺少任何返回途径，也不是SI合规判定。两层缺口主要位于MCU源端和接口附近，后续必须核查实际共地铜、同层地边、跨越缺口的返回绕行与换层接地；最终TOP铺地不会自动修复TOP信号下方的BOTTOM开口。四层两条共享段在L2投影连续，接口USB_DP的换层反焊盘仍须单独看返回，不可把有内层地视为全路自动合格。

本轮不使用整网USB_DP与USB_DM的线段总和当作差分失配：连接器双面脚、ESD通铜及共享DNP分支会影响总和，必须按实际接口路径和既定分支条件测量。两层bulk几何1.15/0.16mm和四层0.26/0.15mm的阻抗估算只描述相应局部截面；介质假设及实际短颈、反焊盘、参考开口未由该估算认证。

完整的端点、局部规则、HSE及原板保护证据见[b016原生报告](b016_native_report.json)；最终参考、全板DRC、完整GPIO和最终2L/4L比较保持待验。
