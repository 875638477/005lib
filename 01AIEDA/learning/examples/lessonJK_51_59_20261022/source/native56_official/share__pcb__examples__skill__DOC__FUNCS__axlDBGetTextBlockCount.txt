
  NAME
         axlDBGetTextBlockCount - get count of number of text blocks
 
  FUNCTION
         axlDBGetTextBlockCount(
         )
         ==> x_textBlockCount
 
  SYNOPSIS
         This function returns a count of the number of text blocks defined.
 
  NEEDS
 
  RETURNS
         x_textBlockCount: a count of the number of text blocks defined.
 
  EXAMPLES
         numTextBlocks = axlDBGetTextBlockCount()
         printf("This database has %d text blocks\n" numTextBlocks)
