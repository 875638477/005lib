# 四层电机控制板分层与功率走线规范

用户确认日期：2026-10-31。用于具有 TOP、L2、L3、BOTTOM 的电机控制板；具体工程的电气、制造和机械要求优先，不能未经判断套用于其他层叠。本规范与[信号转角及孔间内层铜皮规则](pcb_trace_angles_via_copper_continuity.md)共同使用，属于设计和复核要求，并不表示已自动配置为 Allegro 原生 DRC。

## 1. 分层及整改顺序

| 层 | 主要用途 | 实施要求 |
|---|---|---|
| TOP | 器件、局部引出及电机功率铜 | 电机输出优先使用连续铜皮；已有足够空间时保持在 TOP，不再为该段保留跨层绕线及背面功率铜。 |
| L2 | GND 参考平面 | 保持真实地铜连通；检查孔簇造成的避让合并、铜桥缺失、瓶颈和返回路径断口。 |
| L3 | 电源主干及电源铜区 | 电源主分配走本层，保留各支路的承流截面和接入端口；仅在不破坏电源分配和参考关系时适当走信号。 |
| BOTTOM | 主要信号走线 | 协调 TOP 电机铜通道后，将相应信号主干迁至本层；必要的焊盘短引出按实际密度和参考路径处理。 |

先识别功率与采样网络、确定 TOP 电机铜通道，再联合处理让路信号和 L3 电源。必须对整项联合修改进行重铺、连通和 DRC 检查；单独迁一段线可能切断旧跨层电机铜，不能因此保留不完整候选。

## 2. 电机功率铜与电流采集

- 区分驱动器开关节点、磁珠前后电机输出、分流功率端和独立采样端。网络名前缀不能代替实际原理图判断，尤其不能把 `M+`、`M-` 等功率网络当普通信号自动迁层。
- TOP 有空间时使用铜皮并尽量减少非必要换层；局部绕焊盘可收窄，仍须核查实际最小截面、收窄长度、负载工况、温升和器件端口。名义边界宽度、中心线宽或 DRC=0 均不证明实际生成铜达到该宽度或承流合格。
- 删除旧跨层铜之前，核对新 TOP 铜实际连接所有分流、滤波及输出端口；只删除确已冗余的过孔和其他层旧功率铜，不误删滤波电容或驱动器连接。保留必要的端子孔、散热孔及有明确用途的并联电源孔。
- 电流采集优先采用 Kelvin：采样线从分流电阻对应端子独立引出，在放大器端按实际电路连接，避免共用高电流铜上的压降路径。核查分流端真实接入点、正负采样网、功率铜与采样线隔离，以及后续滤波和放大器位置。
- 器件额定值与负载不符时记录换料待办及影响；若用户明确授权沿用封装先布线，应保留该待办，不能将几何完成写成物料承流已通过。

## 3. 信号、过孔与电源平面

- 通用信号折线内角严格大于 130°，优先平滑圆弧或 135° 转角。具体工程若另定大于 100°，应记录工程门槛，同时尽量满足通用目标。按真实连续中心线及电气分支判断，不能把正常 T 接点全部当作连续转弯，也不能漏掉支路尖折。
- 过孔间检查每个目标内层的实际避让和生成铜，确保应连续的铜皮在两孔及孔簇之间留有连通铜条。最小铜桥宽度按板厂、层叠和项目确定，不统一套用 0.20 mm；钻孔孔壁间距与内层铜桥是不同检查项。
- 调整孔阵列优先保持已有明确用途的孔数和孔径；每个供电孔均需核对 TOP 局部接入与 L3 主电源连接。只有证明冗余并复核电流与连接后才可减孔。
- 裁剪多余 TOP 电源铜以释放电机或信号通道时，保留实际供电焊盘、局部退耦回路及电源孔接入。移动孔或将电源迁至 L3 后，同时检查原电源铜的缩颈、分裂、孤岛、端口及对地返回路径。
- Allegro 动态边界重建时记录并恢复生效的局部覆盖，包括连接模式、SMD_OVERSIZE、热焊盘和形状优先级等；不得只复制边界外形而丢失原规则。优先级应避免冲突，并核对填铜后的实际结果。
