# Capture 网络标签与真实翻页符：强制执行规则

2026-11-07。用户将“用文本式翻页符冒充普通网络标签、格式修改后没有补齐跨页连接”列为严重错误；后续新建、转换、重建和整理原理图均执行本规则。

## 对象选择

- 同页局部网络使用原生 **Net Alias**，真实附着于导线。普通文本、器件属性、图形注释及无图形的 OffPage/Global 都不能代替 Net Alias。
- 跨页信号使用具有可见图形的真实 **Off-Page Connector**，各相关页面都要接入实际网络。不能只在新增页面放翻页符，而让源页面仍只有页内 Alias。
- 全局电源使用真实电源/地符号。改变显示格式不能改其名称、作用域或实际热点。
- 多个独立 DSN 之间不会因同名自动连接；跨板必须另核接插件逐针网络、正反面和实际针号。

默认普通标签采用用户已确认参考工程的原生 Alias 格式：Arial，高度 −9、宽度 4、水平、颜色 48；对应普通导线颜色 48、样式 5、宽度 3。后续任务提供新参考或另有明确要求时，以新要求为准。格式值须由原生导出核实，不凭截图推断枚举。

## 修改顺序

1. 冻结实际最新 DSN/PCB，原生导出 XML、PST、引脚、导线、Alias 和翻页符真实热点。不得拿旧导出 ID 操作新保存的文件。
2. 先建立各网络的页内电气分组和跨页关系。不要看到不同页面有同名 Alias 就自动相连；局部重名可能是独立电路。
3. 将本地标签改成真实 Alias，将需要跨页的端点全部接上真实翻页符；翻页符应有正常可见图形，名称显示不与图形或引脚混在一起。
4. 保持原生热点不动，或按新符号实际热点补偿位置。位置字段相同不保证真实接点相同，镜像/旋转也要重新读取。
5. 标签锚点必须在所属导线上。空间不足时只允许经过连通/碰撞校核的短自由端延伸或局部排版，不得制造长绕线、穿过其他引脚/网络、缩小到不可读或隐藏名称。
6. 原电路新接到另一页时，即使旧网络已改好格式，也要重新审查该源页 Alias 是否必须升级为翻页符；不能只检查新增页面。
7. 同一物理网络若有多个互相误导的名称，先核芯片功能、页间关系和全部端点，再明确选择规范网名，保存有意更名表。不能用“网名优先级改变”掩盖拆网或误并网。

## 强制验收

- 官方导入、保存、关闭并独立重开，再次导出全部 PST。检查最终交付的实际文件指纹。
- 逐 `RefDes.Pin` 比较网络分组、网名、NC 与封装；只比较页数、元件数或网络数无效。网络分组不变而规范名称改变也必须逐项说明。
- 检查拆网、误并网、缺脚、重复脚、悬空和仍带 NC 却接线的矛盾。新增电路必须另有完整预期逐针表。
- 注意 PST 自动追加 `_实例ID` 等后缀：这是跨页隔离或局部作用域的诊断线索，不得直接截掉后缀伪装已经连通。
- 器件从一页搬到另一页时保留真实器件、连线和属性；清理指向已删除页/图框的失效 occurrence，随后重新校核网表。
- 图形/可读性检查与电气检查分别记录。原生连接通过、规则设置、布线闭合和实际开机是不同结论。

这次失败的格式策略不得作为新设计模板继续复用。旧原件和历史报告保留；实际项目的输入、失败/修正记录、专用脚本和验证证据留在相应工程，学习库只保存本通用规则及方法。
