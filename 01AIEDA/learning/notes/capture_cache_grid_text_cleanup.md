# Capture 缓存复用、网格对齐与文字避让

适用于 AD 转 Capture 后的整理。实际工程的输入、副本、坐标计划、网表和校验结果放工程目录；本目录只保存通用方法与参数化工具。以下流程的每一步独立保存、重开、验证，不能把“脚本退出正常”当作最终验收。

## 先确定网格含义

Preferences → Grid Display → Schematic Page Grid 的 `Grid spacing 1 / 2 of pin to pin` 表示引脚间距的一半，并非 2mil、2mm 或小数位数。需要逐页读取 `GetPinToPin`、`GetDocUnitsPerInch`、`GetPhysicalGranularity` 和缩放因子。100mil 引脚间距、100 document units/inch 时，半间距是 50mil，即 5 document units。

`Pointer snap to grid` 勾选且 Connectivity/Drawing 使用 Master 时，Master 按 Coarse 工作。Part and Symbol Grid 是另一个设置。偏好设置只控制显示和鼠标吸附，不会自动修复已有脱网格对象。

## 整理顺序

1. 冻结源 DSN、OLB、配置和网表哈希，完整导出官方 XML、缓存、有序引脚映射、有效属性及实际电气热点。
2. 合并真正等价的缓存包，保留实例和 occurrence 属性。部分原生替换操作会重置引脚文字位置，因此合并应在最终排版之前。
3. 对齐实际引脚热点、线段、显式结点、端口和电源符号。优先整页统一平移；局部调整必须验证全部连接及交叉关系。
4. 若库原点与引脚格点不兼容，重基库的局部原点并反向补偿实例位置，不改变任何实际图形或引脚位置。
5. 再排文字，覆盖跨页端口、网络别名、电源名、位号、Value、引脚名及脚号。只读截图/PDF或已校准的原生显示数据用于视觉核对。
6. 保存、独立进程重开、重导网表，检查整个工程，再验证 PCB 导入。

## 缓存合并的判据

不能只按名字、后缀、外框或焊盘数量合并。需要比较完整有序的 Package → Device → Cell → Normal/Convert → Part → Pin 图、脚号位置映射、共享脚、隐藏脚、NC、BOM/PSpice 排除、电气类型、封装、图元、显示属性和字体。不要对引脚列表排序后再判定相同。

只有身份名不同的包可以直接改缓存引用并移除冗余包。结构相同而默认值不同的包，先按真实继承作用域计算差异：保留共同默认，去掉会错误继承的差异默认，把原有但实例未覆盖的有效值显式放到对应实例。原本不存在的属性不能擅自写成空串。occurrence 的覆盖必须单独保留。

用原生 `GetEffectivePropStringValue` 比较合并前后值；失败状态、错误码和值分别记录，失败不能当作空串。XML 里移除默认后，原生数据库可能重建空的内置默认，须逐项记录并证明当前有效值无变化。

Global、OffPage 和 Port 电气作用域不同；外形相似不构成跨类型合并依据。若网络符号缓存本来没有重复，保留它们并记录证据。

## 官方 XML 往返验证

先对未修改的完整导出做隔离往返，验证本机版本支持的范围，再用于正式变换。使用独立输出路径，输入保持只读。

Capture 17.2 的导入可能重新生成 INS 内部名、显示/引脚 ID、日期、MaxDbId，并把同一网络的 Junction 分配给另一条实际经过该坐标的线段。这些变化必须满足：ID 双射无冲突、引用无悬空、每个对应网络中完整结点多重集相等、所有结点位于归属线段。其余全树内容及顺序仍需精确比较。保留原始差异报告，不以排序全树掩盖变化。

导入控制台提示或退出码不是连接正确的证明。必须再独立重开，导出 PST 并比较全部物理 `refdes.pin` 的连接分组和有效器件定义。

## 网格调整的连接保护

按实际 pin hotspot 求器件刚性平移量，不能只四舍五入器件原点。对于有多个局部引脚余数的器件，单次平移无法修复，必须停止并单独分析。

比较全部线段之间的端点接触、无结点交叉、重合，以及 pin/port/global 对线段的附着、端点彼此重合、显式 Junction 对线段的归属。不能把没有结点的交叉变成连接。自由短线可能被吸附压为零长，只有确认自由端没有任何电气附件、方向和外物避让均保留时，才延长到一个网格，不能静默删线。

库原点重基应同时变换全部局部图元、引脚默认/实例覆盖、显示属性及包围框，并逐实例证明实际图元和热点不变。不同对象的坐标变换不同：本机读取已确认器件 DisplayProp 的实际位置是实例位置加 DP 局部位置，不能再施加器件旋转；旋转电源图元应以实际 hotspot 配准，不能盲用器件的原点公式。

## 文字测量和边界

使用完整 LOGFONT（含非零 width、字符集和精度等字段）及实际显示串；空属性也可能显示 `<属性名>` 占位符。GDI 字形墨迹比固定长度乘宽更可靠。缓存的 BoundingBox 可能为零且 dirty，不能据此宣称无重叠。

DisplayPropsIter 返回的 BaseObject 必须先转换成 DisplayProp 再读取专用方法。SDK 存在的方法不代表任何 owner 类型都可安全传入。默认 pin name/number 由 UI 管理，没有已验证文字 anchor 时，采用明确标注的保护包络；不能把估算当作 Capture 截图验收。未连接 Net/Wire、迭代结束与真实读取失败分开记录。

## 可复用校验脚本

- [隔离原生任务运行器](../scripts/capture_native_job.py)：记录本任务 PID、命令、耗时及受保护输入前后 SHA，只管理自己创建的进程。
- [PST 全引脚连接分组比较](../scripts/compare_pst_connectivity.py)：NC 逐脚分开，报告丢脚、多脚、重复、分组变化及网络改名。
- [PST 逐实体器件比较](../scripts/compare_pst_parts.py)：按位号比较脚号有序映射、电气属性、封装、Value、其它 body 属性和 section；仅库身份名变化单独记录。

通用工具的 `--help` 给出参数。输入路径、变换计划和生成物均指定为对应工程下的独立目录，禁止覆盖源设计。

[网格规划与原生只读工具说明](capture_grid_tools_portable.md)提供参数化的网格候选生成器、原生只读审计和公共会话函数，说明单位断言、未知图元拒绝、附件与交叉关系检查，以及四项负向校验。工具不包含工程坐标或固定路径。

[缓存复用、原点重基与完整XML工具说明](capture_cache_reuse_and_origin_rebase_xml.md)提供作用域保留、严格/条件合并、完整差分、有效属性比较和配套库核对等参数化工具。导出OLB后，除Package完整内容及脚号可见性，还必须比较库级DefaultValues；`CopyPackageAll`不会自动保留源设计的全部默认字体。用真实Design/Lib对象读取24套LOGFONT及默认primitive标志，复制到新库、保存并在新进程重开核对，不能通过PartInst调用默认字体静态函数。

当前已验证的工具范围是官方数据库往返、缓存复用和网表比较；文字与网格的候选生成仍需针对具体工程完成原生保存重开和视觉检查，不能把本教程当作整板 DRC 或生产放行。
