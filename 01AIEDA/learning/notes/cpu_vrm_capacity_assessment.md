# 从原理图评估CPU供电能力

冻结用户指定的最新已保存DSN和SHA，在ASCII任务目录原生导出。旧网表可能落后于保存文件；比较完整引脚分区、有效器件定义，再核原生XML的实例User_Value与采购身份，不按库别名推断装料。

逐相追PWM、驱动、MOS、开关节点、电感与输出；把CORE、GT、AUX分开，确认未使用相位的检测电平。按原厂二阶段电阻采样和ICCMAX表计算真实串并联网络，明确结果是启动strap推算，需读回寄存器及核固件覆盖。

相数乘电感标签、MOS极限Id均不能作为持续电流。核电感Isat/Irms/DCR、采样时间常数、MOS热态RDS与开关/热预算；辅助LDO按实际压差与对应CPU电源轨电流算耗散。共享源做总预算。

区分POST、限功耗稳定、默认峰值及超频。型号还依赖板级固件、内存训练、时序及实板散热。没有波形/温升实测时列验证候选，不能编造已验证CPU名单。提高ICCMAX配置不等于提高硬件能力。

原厂合并行/跨页表先渲染目视再计算。保留版本、页码、SHA、假设和复现脚本。用户分析期间保存时重新导出比较；若电气一致，不重复全部研究。工程数据存项目内，学习库只留通用方法。
