# Capture 原理图清晰排版与简洁连接方案

更新：2026-11-11。用于新建、PDF 重建和已有 Capture 原理图整理。核心风格来自用户要求：**阻容横放、1 脚左/2 脚右；位号紧挨 1 脚侧引线上方，Value 紧挨 2 脚侧引线上方，网络名排在两者外侧；文字互不覆盖，连接短而清楚**。本文件规定操作方法与验收，不代表某个工程已经完成这些检查。

用户于 2026-11-11 提供的 [R319 等同行示例及验收更正](capture_rc_horizontal_ref_value_layout_spec.md#2026-11-11-用户确认的同行示例与排版验收) 是本用户后续整理任务的参考。已清晰的器件与短直连接优先保留；不得把全部阻容挪到空位后用全页寻路追回端点。长回折、跨区穿表和文字挤压都属于排版不合格，即使网表完全等价也不能报排版完成。

> 2026-11-11 后续补充（本用户明确要求，优先执行）：原本已经横放的阻容，即使实际 1 脚在右、2 脚在左，也保留原脚序与清晰连接；**不能只为把 1/2 脚换到左右位置而改线**。位号仍在左侧引线紧上方，完整 Value 在右侧引线紧上方。新建或确需竖转横时才默认 1 左、2 右；极性及电气身份始终保持。

## 1. 排版规则

| 对象 | 默认方式 | 空间不足时 |
| --- | --- | --- |
| 普通二端阻容 | 新建或竖转横默认 1 脚左/2 脚右；已横放件保留原脚序和连接；位号贴近左侧引线上方，Value 贴近右侧引线上方，左右网名排在两者外侧 | 先移动文字、调整对齐，再协调局部短线；竖放仅按当前任务明确允许的例外处理 |
| 电感、磁珠 | 使用本地真实符号；文字保持相同的归属与避让原则 | 不为统一外观更改引脚定义或连接 |
| MOS、三极管、二极管 | 使用本地已有图形；按实际栅源漏、基集射、阴阳极布置 | 依符号形状安排文字，不能强套二端器件的坐标模板 |
| IC 与连接器 | 引脚名、引脚号清楚可读，位号与型号靠近器件 | 给长引脚名、分组和端口留空间；优先复用已有正确符号 |
| 网络名、翻页符 | 放在接线入口外侧的空白区，与引脚名、引脚号及器件文字分开 | 调整显示位置、对齐或短接线；必要时协调局部布局 |

示意只表达相对关系，不规定固定格数、字号或像素：

```text
NAT01       NR1          33/4       NAT08
────────────1──/\/\/──2─────────────────
NAT02       NR3          33/4       NAT07
────────────1──/\/\/──2─────────────────
```

- 不统一套用“上方两格”。依据实际字形、字体、符号和附近导线确定偏移。
- 2026-11-10 用户以 R332/R333 确认更具体的紧凑样式：左网名 → 位号 → 1 脚—器件—2 脚 → Value → 右网名；位号和 Value 分别贴近两侧引线的上方。优先遵守[阻容细则](capture_rc_horizontal_ref_value_layout_spec.md)及其通用 SVG；参考实例坐标不推广为所有符号固定偏移。
- 位号、Value 必须能明确对应本器件。不要移到邻近器件旁，或把多只器件的文字堆在一起。
- 完整保留原 Value、型号、位号、装配/不装配状态及属性。不能靠截断文字、缩到难读、白色遮盖块或隐藏必要信息解决重叠。
- 长采购型号可按本次任务允许的字段策略管理；排版任务本身不授权改电气值或规格。
- 采用本机库中的真实阻容、电感、磁珠、MOS、三极管、二极管等符号；大型专用芯片才按任务从参考工程取得。更换符号前逐脚核对编号、功能、极性和多单元结构，不能用方框替代已有基本符号。
- 原理图旋转不自动决定 PCB 的旋转与放置。

## 2. 网络文字与翻页连接

1. 分清 `DisplayProp`、`NetAlias`、翻页连接器、层次端口和电源符号。文字相同不等于任意层次、任意页面已经连接。
2. 优先移动显示属性及其对齐，不先移动电气热点。网名放在线入口的外侧空白处：左侧文字通常右对齐，右侧文字通常左对齐；先测完整字宽再确定间距。
3. 为引脚名、引脚号、端口图形、位号和 Value 分别留出空间。网名不能与芯片的引脚名连成一串；文字避开导线、器件轮廓、连接点、边框和其他文字。
4. 翻页符保留原类型、方向、网络名与作用域；页码提示如 `[14]` 属于显示引用，不得随意拼入电气网络名。总线、范围和总线入口也须保留真实连接。
5. 同页标签重复可以评估精简，但必须证明名称、实际网络和所属导线相同，且不会丢失远端阅读信息。不能批量清空别名、删除翻页符或把标签拖离导线。
6. 保存重开后按真实热点核对。镜像、旋转或替换符号可能改变热点，不能只比较对象的 `loc`。

PDF 重建时，一张原图页原则上对应一张工程页，沿用原图分组、网络与翻页关系。不能为了排版把同页局部网络拆散到若干页面，导致同名页内网络隔离。纸张由本次任务确定；A3 是已有工程的用户要求，不是所有未来工程的强制默认值。要求保持器件位置时，先检查换纸后是否越界，不自动整体缩放或移动器件。

## 3. 简洁连线

- 以原图的连接关系和阅读顺序为依据。相邻器件使用短直线或必要的少量直角转折。
- 独立信号就近接各自的器件、测试点或翻页符，保持行列关系。不要为让文字腾位置，把多路无关信号向下拉成长束，再沿外围折返。
- 对可用原生网络标签、翻页符或电源符号表达的远距离连接，可采用短引线表达；必须先确认当前作用域与真实网表连接允许这种表达。
- 电阻到地可就近接地符号；测试点靠近其所属短支路。不要把接地支路、测试点拉到远处制造长 U 形线。
- 交叉线是否连接取决于真实端点、连接点和 Capture 数据，不只看截图。避免新支路穿过其他引脚或热点而形成意外短路。
- 导线不能单纯按段数判断冗余：保存可能拆分共线段。比较时按页面、网络及样式归一化共线区间，再比较实际覆盖与连接。
- 需要改变局部导线时，带上端点关联的引脚、标签、端口、连接点、NC 与测试点一起核查。只有确认自由端无附着对象，才可按条件延伸；不可凭视觉猜测。

例如三路 CPU 信号应各自在引脚附近直接到翻页符，其中一路串联电阻；相邻测试点和接地电阻也就近连接。无需为了将 Value 放到固定坐标而向页面底部绕行。应先改变文字偏移，再判断是否需要调整短支路。

## 4. 可复用执行流程

1. **固定输入与边界**：记录本次源 DSN/OPJ、原图、库路径、纸张、是否允许移动器件、可修改属性和成功标准。在工程根保存来源 SHA256 与可恢复副本。学习库只存通用方法与参数化工具。
2. **建立真实场景**：从 Capture 原生导出 XML、引脚/导线/端口/标签/文字数据及当前网格。符号按 `pkgName + libName + GraphicName` 匹配，不只按图形名。旋转和镜像使用原生变换或三基点仿射，不能套用未经校准的旋转公式。
3. **测量可见内容**：使用实际字体的 GDI 字形范围，把可见引脚名、号码、器件轮廓、引脚线、导线、端口、文字与边框列为障碍物。脏缓存 bbox 和字符数只能辅助定位，不能作为最终避让依据。隐藏文字不制造虚假障碍，但真实引脚线仍须保护。
4. **生成局部修改计划**：先修位号/Value，再修网名与翻页符显示，最后处理确有必要的局部线。候选位置限制在本器件附近。找不到清楚的位置时记录待处理项，不无限移远或缩小字体。
5. **按原生锚点应用**：区分显示属性和电气对象坐标。已知导出器的 `DisplayProp` 常为 LEFT/TOP，`NetAlias` 常为 LEFT/BOTTOM，必须以实际版本验证；旋转注释文本保存后可能规范化为包围框左上角，应按完整旋转矩形校准，不能沿用旧基线假设。
6. **原生保存与重新打开**：检查 XML/XSD、编码与整数坐标，使用官方导入/保存，重新打开后导出新的实际数据。重新关联对象，不依赖旧的运行期 ID。
7. **分别验收显示与电气**：对重新打开的数据做字形碰撞、边界、器件归属和局部连线检查，生成逐页预览；再从实际交付 DSN 导出网表，逐 `RefDes.Pin` 对比网络分区、网络名、NC、关键属性及封装，说明每项有意差异。只比较网络数量不足以证明连接正确。
8. **完成交付证据**：有 PCB 交接要求时运行真实主工程的 Create Netlist 和严格 Allegro 导入，检查缺件、引脚不匹配、忽略项和错误日志。不得靠排除器件、临时探针设计或旧日志冒充主工程通过。GUI 阅读检查单独记录完成范围，几何预览不自动等于 GUI 已验。

格式示例仅说明相对摆放，不能替代第 7 步的实际验收。

## 5. 修改计划与验收记录

项目记录放工程根，推荐每条修改包含：

| 字段 | 内容 |
| --- | --- |
| 输入身份 | 源文件 SHA256、Capture 版本、页名、源库与符号 |
| 对象 | RefDes、单元、属性或网络对象类型、稳定匹配依据 |
| 修改 | 旧/新位置、局部偏移、对齐、字体、实际字形边界 |
| 理由 | 避开的障碍物、归属器件、为何需要局部线调整 |
| 电气关联 | 相关引脚、端口热点、连接点、NC 及预期网络 |
| 例外与证据 | 未解决项；原生重开、几何、网表、GUI、PCB 导入分别记录状态与文件 |

验收不通过的典型情况：文字互盖或压线；网名与引脚名混成一串；Value 靠近错误器件；长绕线只为让出文字位置；翻页显示相同但实际网络隔离；热点离线；意外短路；交付源文件和所验源文件不一致。未验项目写“未验”，不能写通过。
