# Capture 翻页符、电源与地端部对象：优先规范

版本：**ENDPOINT-20261116.2**；日期：2026-11-16。适用于本用户原理图中的全部 OffPageConnector、Global 电源与地，以及整理前已有接插件的保留检查。进入设计、重建或显示整理前，先读本规范和[机器 contract](capture_endpoint_symbols_contract.json)。端部对象的 Name、方向与电源支路规则以本版为准，优先于旧笔记中冲突的平接、统一标签或固定偏移表述；R/C仍执行其独立现行规范。

## 本版追加：GND的bar顺序与电源Name紧贴

用户进一步纠正了三个互相独立的要求：GND方向必须识别bar长度顺序，电源自身Name应紧贴圆圈外缘，同功能阻容应紧凑成组且器件到网络符号的引线适当短。后两项的分组与引线方法另按[简洁排版规范](capture_compact_schematic_layout_method.md)执行；本页端部检查通过不等于分组/行距/引线长度已合规。

本轮用户图中的箭头所指GND正确、打X者错误；电源图上两行Name紧贴圆圈正确、下行大空隙错误。**判断依据是以下几何关系，不是箭头、X或颜色本身。** 本轮原图仅留工程本地作审核证据，不随公开规则上传；下文抽象关系可以复用。

### GNDORDER：从电路向外，地线bar必须由长到短

针对当前这种由多条平行bar组成的原生GND图形，最大bar必须靠近电路，随后向外逐级缩短。右端关系为 `电路 → 最大bar → 较短bar → 最短bar`，左端镜像。经旋转后bar在屏幕上可能是竖线，判据仍是相对电路的顺序，不固定为屏幕横向或某个rotation/mirror值。

先从实际连接导线末段确定“由电路向外”的轴，再读取**全体实际变换后的bar端点及显示线宽**。将bar中心沿该轴由近到远排序，实际墨迹长度须严格递减，bar彼此平行、中心在同一轴上，且垂直于该轴。保持原生真实热点、图形和作用域；调整方向后仍需验证所有邻行图形、导线和文字，不能为避碰把bar顺序翻反。

“全部glyph落在热点外侧”“原生库身份正确”“profile_verified=true”“碰撞为零”都不证明GND方向正确。无文字的常规GND同样必须执行GNDORDER，不能借Name隐藏模式跳过。使用不同结构的接地符号时，须有其对应的明确原生结构规范与独立检查；不能拿未知图形套本bar规则后直接填PASS。

### POWERGAP：圆圈外缘到自身Name墨迹必须紧贴

使用圆圈标记的电源须保留真实Global及自身可见完整Name。右端读作 `电路——○Name`，左端为 `Name○——电路`；Name位于外侧并紧邻圆圈，不能在圆圈与Name之间留明显长空白或用导线尾段填空。也不能用Alias代替自身Name。

间距从**实际圆圈最外侧墨迹边缘**量到**完整Name最靠近圆圈的实际字形边缘**，不是从热点、属性锚点、整个符号BBox或字符数估计。按当前字体、单位和原生正例校准Name基准、允许最大gap及原生量化容差；不得从截图像素直接杜撰文档单位，不能固定加5或加10便声称“紧贴”。Name仍须完整可读、在外侧且不压圆圈。

机器验收须同时有实际圆圈几何/线宽、真实Name墨迹边界和经过校准的用户正例上限；再从正例圆圈/Name几何重算gap，防止任填一个大上限放行。还须比对垂直于导线轴的Name墨迹区间与圆心关系，不让文字上下移远但水平gap小的情形冒充紧贴；详细基准仍按批准原生profile独立校准。缺正例几何、明确上限、原生身份、匹配单位/字体或量化证据时为UNKNOWN；外置但过远为FAIL。不同电源图形或尚不支持的非轴向显示不能假定符合圆圈规则，另列未验。

## 原生对象与Name不可混用

1. 页内局部标识用真实 `WireScalar/Alias`；跨页信号用真实可见 `OffPageConnector`，相关页端点齐备；全局电源/地用真实 `Global`。遵守[强制对象与连接规则](capture_alias_offpage_mandatory.md)，保留名称、作用域、电气类型和连接。
2. OffPage和电源的完整名称必须是**该对象自身有效可见的Name**。实例与库继承的显示属性都要读回。不得关闭Name，再在导线上添加同名Alias、普通文字、悬空Name或透明端口以取得相似外观。原生电气连接相同也不能豁免。
3. GND必须有真实、完整、可辨的接地图形；常规无文字地符号可沿用经批准原生profile的无文字显示模式，不强迫新增GND文字。若该profile显示GND名称，则必须用该Global自身Name并放在外侧，不用Alias代替。
4. 局部Alias的“锚点在线、文字紧邻线上方”只适用于Alias。端部Name按自身原生显示框架定位到外侧，不得把Alias的线内基线规则套给Name。局部名与端部名可以按原拓扑并存，避免重复、误导与干涉；不能因新增标签凭空添加连接圆点，也不能删除真实T结点。

## 依据实际图形校准方向与文字位置

- 水平左端：`Name >> —— 电路`；水平右端：`电路 —— << Name`。翻页符的可见尖头指向所属电路内侧，完整Name位于符号外侧空白。这个阅读方向不替代输入/输出/双向的真实电气类型。
- 内外侧由**真实连接热点、所属导线最后一段和电路所在侧**确定，不能只按页面左右、坐标大小或文件中的`left/right`名称判断。非水平末段、镜像或非标准符号先用对应原生正例校准，再按变换后的实际轮廓核验，不能硬套一组角度。
- 读取批准原生实例与其库符号：对象类型、库/符号身份、图形/热点、rotation、mirror、有效Name显示模式、字体/字向/对齐和显示偏移。变换热点、完整符号轮廓与实际字形边界后核验，不凭locX/locY或原始rotation值声称正确。
- Name与所属导线的行基准、符号间距按原生正例的实际显示框架校准；放置于外侧并不等于任意偏远位置。不得复制截图绝对坐标、固定加10等常数或把零缓存BBox当作无文字。
- 位置、热点和文字按当前工程网格校验。局部空间不足时先调整文字/端部偏移与支路留白，再按已授权范围调整短线；不能把线名推入内侧、缩到不可读或隐藏。

## 电源、GND和合理支路

沿原理判断供电母线、去耦、反馈与返回路径，保留已有清楚拓扑。第四图的母线向上短竖支路是正例，不能为形式统一改成水平圆点加Alias，也不能把电源和去耦关系拆成孤立网名行。

本来就是水平自由端、且有经批准原生profile时，电源/地可按末段自然平接，Name在外侧；不要仅为符号默认方向添加无意义折线。这个选择**不授权删除已有合理竖支路或一律旋转电源/GND**。电源图形和地符号须与批准的真实库符号一致，不能随取一个非GND模板换名。

GND热点及完整图形从原生profile读取，方向另按本版GNDORDER识别实际bar顺序，不能仅信profile布尔标志。完整轮廓须与相邻GND、电源、导线和名字留有可读间距。单个符号锚点在网格上不等于多行排列合格；截图02这类重叠必须检出。

## 先冻结原生正例，再批量修改

1. 固定磁盘最新DSN/PCB、库和导出SHA；记录本次输入，不能拿旧导出ID操作后来保存的文件。
2. 从当前用户认可的原生实例提取profile；关联截图只证明视觉关系，不能代替原生字段。分别校准左/右翻页、电源以及所用GND显示模式；缺profile或未覆盖的变换列`unknown`，不盲批量生成。
3. 先验证一组涉及的方向与密集邻行小样，重开确认Name、轮廓、热点及连接，再应用同类实例。保留未变的合理原有对象，不为统一格式重建全部端口。
4. 盘点所有端部对象并记录逐项事实，检查完整符号、完整字形与邻接场景；同时对全部RefDes.Pin比较连接分组、网名、NC及关键属性。连接验收和显示验收分别记录。

## 既有接插件与预留必须保留

设计前冻结已有接插件实例和位号清单；未用、预留、额外或仅某方案使用的接插件都保留。引脚兼容、另一芯片引脚较少、暂时未接线不构成删除理由。未经用户对具体对象的明确许可，不删除接插件、改位号以掩盖删除，或通过不导出/改变装配状态把它移出交付。

用户已经明确授权的调位、增针或逐针修改按任务白名单实施并重新核验，不扩大成删除授权。前后逐位号比较，所有未获准删除项必须仍是实际交付中的原生器件，不能只在报告或旧备份中“保留”。

## 强制验收与报告边界

使用[端部事实检查器](../scripts/capture_layout_tools/check_endpoint_symbol_contract.py)核对其覆盖的事实：真实对象类型、非空网名、Name有效显隐/自身来源、完整文字边界外置、实际尖头向内、GND实际bar长度顺序、电源圆圈到Name实际gap、原生profile核验声明、完整邻接图面review声明，以及接插件前后位号集合。输入JSON采用[机器contract](capture_endpoint_symbols_contract.json)的字段，顶层包含`objects`、独立枚举的`expected_endpoint_ids`、`connectors_before/after`、最终`native_source`路径及`native_source_sha256`。经批准的无文字地符号需同时提供`is_ground=true`、`native_ground_without_name=true`、`profile_verified=true`，还必须提供`ground_geometry`并通过GNDORDER；电源须提供`power_geometry`及已校准gap_profile并通过POWERGAP。

**该脚本是有限范围facts checker，不是全量验收器或原生提取器**；它不读取本contract自动执行全部要求，也不能证明提取事实真实、正例确获用户批准、图面覆盖完整、电气等价、实际热点连通、网格、合理拓扑、紧凑分组/短引线或最后一次原生重开。以上项目必须另提供绑定证据，不能以脚本PASS替代。逐项事实至少绑定最终源件/导出身份、页/对象ID、对象种类与原生符号身份、网名、实际热点及末段、Name有效显示模式/归属、profile、完整图形与文字边界、方向、内外侧、网格和完整邻接场景；GND另记录其批准profile是否显示名称、全体bar端点/线宽及独立bar清单，电源另记录实际circle、Name墨迹及原生正例的gap校准几何。接插件还须以原生实例/装配导出清单确认保留，集合包含不能证明实例身份未变。

全部盘点对象与适用检查均须有绑定证据。字段缺失、未经校准、原生显示继承无法解析、图形/字形未覆盖或原生重开未完成时为`unknown`；存在冲突为`fail`，不得作为`pass`。检查器只能核对输入事实，调用方不得凭估计填充true；原生快照、图形/文字模型和人工图面核查的证据须可回溯。

ENDPOINT-20261116.1的旧PASS没有检查实际GND bar顺序或电源gap上限，不能迁移成新版这两项的通过证据。补齐新几何事实后重新验；规则同步本身不代表任何DSN/BRD已经整改。

R/C检查器通过、Alias锚点在线、PST相同、碰撞计数为零或离线渲染`unresolved=0`，均不能单独代替本规范的端部验收。最后一次图面修改后原生保存、关闭、独立重开并重新导出；逐页及密集区完整检查。GUI、离线模型、电气与PCB交接各自报告；后台不激活GUI，未做GUI就不声称GUI已验。任一已知错误或关键未知未解决时，不宣称相关端部/全页整改完成。
