# PCB布线基本原则与实际验收规范

更新：2026-11-09。适用于后续PCB设计的默认工作规范；具体平台、器件、板厂及用户当次要求优先。角度与层功能为用户设计约定，不冒称IPC或芯片厂商的统一强制标准。

## 转角、线宽和通孔

- 线段优先水平、垂直及45°方向；连续走线采用45°倒角或合适圆弧，避免90°直角和锐角。
- 转角按两条线段指向转折点外侧的内角计算，当前主板整改的验收下限为不小于120°；其他工程未单独指定时沿用既有通用严格大于130°的目标，不降低旧项目标准。方向改变45°对应135°内角；不要把“45°转向”误判为45°内角。同网同层应合并中心线重叠并建立交点，检查不同path的接续及外露分支相邻扇区；外露三分支优先用120°Y形。焊盘/过孔内汇接须证明整个线宽位于真实端子铜内，不能仅以中心点在焊盘内免检。T接点与铜皮边界另分类，不误判也不漏判。
- 常规线宽/线距优先不小于4/4mil，即0.1016/0.1016mm。受控阻抗宽距按真实叠层、铜厚、阻焊、参考层和目标阻抗计算；电源按载流、温升和压降设计。
- 3.5mil乃至3mil（0.0762mm）只用于确实避不开的极限局部逃线，不能成为整网或全板默认。线距没有同步放宽，仍按4mil优先。逐段记录网络、层、起止、长度、原因与复核结果；出密集区尽快恢复正常或阻抗宽度，限制缩颈长度并审查阻抗不连续。
- 首选通孔10/18mil：孔径0.254mm、焊盘0.4572mm。局部最后兜底8/16mil：0.2032/0.4064mm，尽量不用；两者名义单边环宽均为4mil。真实焊盘、反焊盘、层跨与板厂公差均须读回，不能只看名称。

## 层功能与返回路径

四层默认层序为TOP-L2-L3-BOTTOM；TOP器件/信号，L2连续公共GND，L3真实电源铜域，BOTTOM信号。L2不拿来逃线，L3不拿来普通信号跨线；需要改变时先报告理由并取得对应设计范围的授权，不静默占用平面。

“满层GND”指板框允许范围内连续接地平面，保留异网反焊盘、机械孔及必要禁布；不能为了视觉满铜造成短路。L3按实际电源源端、负载和电压分区，不把多条电源互连，也不以层类型或颜色代替实际网络赋值。

TOP高速线优先参考连续L2。BOTTOM的相邻参考为L3，必须检查具体电源区、缝隙、孔阵列及去耦回路；禁止跨分割或把分割电源层当成完整地。换层需要明确的返回路径，信号从GND参考变为电源参考时，仅加一颗地过孔不自动完成回流。

两层固定TOP-BOTTOM。信号和电源在两面安排，尽量保存连续地铜并用同网地过孔连接；不把四层“第二层全地、第三层电源”的层号要求机械套用到两层板。

## 表层铜型与铜皮转角

沿用GitHub已有[表层静态铜规范](pcb_outer_static_copper_and_corners.md)：TOP/BOTTOM优先静态铜，确需动态铜时记录原因；修改附近走线/孔/器件后必须重做实际避让。铜皮外露轮廓也避免直角、凹直角和尖刺，优先圆弧/135°倒角，检查实际生成铜及内孔边界，不能只修母边界。修角不得破坏铜桥、承流、端口或Kelvin。另见[完整转角与孔间铜规则](pcb_trace_angles_via_copper_continuity.md)。

## 电源铜皮、过孔与孤岛

- 电源优先采用同网铜皮和短宽连接，依据真实源—负载回路规划；大电流路径核铜颈、连接焊盘、层间过孔数量、压降与温升，不使用通用4mil信号线代替。
- 稳压器输入电容、开关功率回路、输出电感/电容、负载去耦分别审查。SW/PHASE高dv/dt节点保持必要的小面积，不能因为“电源用铜皮”把噪声节点扩铺整层；反馈、远端采样和VREF按安静信号/Kelvin路径处理。
- 地/电源过孔必须真实接入各自同网铜区。信号过孔必须真实接入信号路径，并安排相应返回；异网之间保持隔离，不要求信号孔接到GND或电源铜。
- 过孔阵列不能把参考铜切成栅栏、细颈或悬空岛；核实际反焊盘后的铜桥，而非仅看两孔中心或钻孔间距。铜桥制造下限与实际载流/回流能力分别验收。
- 同网地/电源via优先采用实际铜全连接，同时核原生全局、Shape实例和对象覆盖。Full contact不等于铜区外或孤岛上的via已经连到源端；器件引脚热焊盘另按可焊性和载流处理。
- 无端点浮铜应清理；包含必需端点但未接源的铜岛必须先补通或调整，不能直接删除端点铜来消除告警。以真实铜接触和跨层导通追踪到公共地/电源锚点，不以网名相同或铜色相同判连通。

## 差分、DDR和执行顺序

先固定叠层、焊盘、板框和参考铜规划，再做关键通道。差分优先同层、同参考、对称过孔/隔直电容和必要短支路；对内相位、组间时序及跨板完整路径分别核对。DDR按通道、字节、DQ/DQS、CA/CK和rank定义端点，不把所有DDR线做同一总长度，也不把P/N公差当成DQ对DQS预算。

用户指定的信号/电源执行优先级要写进项目规格；供电铜面积、去耦位置与关键回路先预留，优先级不意味着等高速走完才开始考虑电源。其他平台实例的线宽、长度、公差、封装延时和拓扑应逐项判断适用范围，不直接搬用。

## 必须留存的验收证据

先记录原生输入和SHA256，再记录修改、保存与新进程重开。分别验证：实际层序/铜网/填铜，原理图逐针，差分和等长数值，新增线段及转角，细线/小孔例外，所有pin/via/铜区的源端可达性，平面孔阵列铜桥，当前DRC及检查模式。路由器要使用45°转角策略并在导入BRD后独立检查几何。

未实际实现或执行的检查写“未验证”，不能写通过。规则定义、网络连通、DRC、SI/PI时序与上电POST为不同层次，自动布通不代表可投板或保证启动。相关原生方法见[铜皮全连接与实际铜验收](allegro_shape_contact_and_power_voiding.md)和[层命名/功能约定](pcb_layer_naming.md)。

## 技术来源与适用边界

1. [TI SNLA302，§2–4](https://www.ti.com/lit/an/snla302/snla302.pdf)：连续参考、避免跨平面分割、45°转角及差分对称等通用方法；其LVDS具体阻抗/时序值不替代DDR、PCIe或本项目规格。
2. [TI SLVA959B，§3–6](https://www.ti.com/lit/an/slva959b/slva959b.pdf)：过孔阵列造成地平面割裂、大电流回路、去耦和开关节点等方法；文中示例过孔电流不能当通用额定值。
3. [Altium：四层电源平面的正确使用](https://resources.altium.com/p/right-way-use-power-planes-4-layer-pcb-stackup)：SIG/GND/PWR/SIG的返回、分区和换层限制。
4. [华秋制程能力](https://www.hqpcb.com/ability.html)与[阻抗工具](https://www.hqpcb.com/quote/impedance)：制造能力及具体叠层计算；厂家最低能力不自动变成本工程默认几何。

用户2026-11-08/09明确的>=120°、4mil优先、极限局部3mil、10/18通孔优先及四层L2地/L3电源要求在本规范中单独保留；工程专用文件、日志、参考板及执行结果留工程目录，不上传到通用学习笔记。
