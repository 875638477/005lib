# Capture 网络名称、端口与导线的排版方法

整理日期：2026-10-23。适用于转换后的整套 Capture 原理图检查。本文保存纯操作方法，不含项目数据、脚本或工程验收结论；所有工作副本、改动清单与证据归 `<工程根>`。

相关入口：[人工转换教程](ad_to_cadence_gui_workflow.md)、[通用转换方法与验收](ad_to_cadence_conversion_workflow.md)、[网表导出与导入排错](capture_allegro_netlist_troubleshooting.md)。

## 1. 先分清电气对象与显示对象

同一个网络附近可能同时显示 Port 名称和 Net Alias。它们可能来自源图原本就存在的两个对象，不能一概认为转换器错误复制。

排版前记录页名、对象名称、端口真实连接点、接入导线、镜像／旋转以及文字的偏移、对齐和字体。对照源图确认是名称重叠、名称缺失还是连接缺失，分别处理。

优先调整 Port 的 Name 显示属性，不移动端口本体、导线或电气接点。旋转文字与旋转整个端口不同，不能选中整个电气对象后用旋转或镜像代替文字排版。

## 2. H 水平镜像不一定保持真实连接点

H 镜像可以改善端口图形朝向，但其变换可能围绕符号包络进行。端口位置数值不变，真实连接点仍可能移动；文字还可能被软件按字宽重新安排。

人工操作时先保存副本，记录端口当前真实接点，镜像后放大检查接点仍落在原导线上。批量处理或疑似接点移位时，需要原生审计分别读取变换前后的绝对热点，按两者差值补偿端口位置，再保存重开核对。

不能只用符号原点或未经变换的局部热点推算绝对连接点，也不能通过挪导线来凑视觉朝向。已有正确人工镜像应保留，并以其当前实际热点作为检查对象。

## 3. 独立调整 Name 的位置、对齐和字体

1. 选择名称显示属性，保持文字水平可读；确有源图或版式理由的竖排文字单独处理。
2. 名称放在连接点左侧时，通常用右对齐，让文字末端与端口保持固定间隙；放在右侧时通常用左对齐。不要用每个网名共用一个固定负偏移来代替对齐，因为名称长度不同。
3. 用统一、清晰的字体与适当字号，核对实际字体宽度和行间距。自动字宽与固定字宽的效果不同，修改后看实际渲染。
4. 名称尽量放在导线伸入电路方向相反的空白侧，避开端口图形、器件本体、引脚名、脚号和相邻网络文字。
5. 页面边距不足时，可把名称放在导线上方并留出可见间距，或调整局部布局／扩大纸张。不要把文字直接压在线上，也不要整体缩小字号来掩盖拥挤。

在界面中使用 Left／Right 等实际对齐选项。需要技术支持批量设置时，按本机已核实的枚举和字体定义执行，不猜内部数值。修改显示属性后应确认端口位置、镜像、旋转和绝对热点均未变。

## 4. 判断引线方向时处理短段与分支

不能仅用端口相连的第一小段导线判断文字该放哪一侧。转换、人工镜像或结点拆段可能产生很短的 stub，后面的主要导线却朝相反方向延伸。

从真实热点检查所有接触线段，沿共线短段追踪到主要电路方向，同时核对附近器件边界。存在多个方向、分支、内部接入或交叉时，列入人工复核，不自动选择一个方向。

短线段不一定导致网名截断。先确认属性中的完整字串及正常阅读缩放下的显示，再处理方向、对齐和间距。只有确实需要调整电路布局时才修改导线，并重新核验网络；不能为了放长文字盲目延长 stub。

## 5. 受控归并近端重复 Alias

近端同名双显可以用 Port Name 作为唯一显示，但删除 Alias 前必须逐项满足：

- 位于同一页面，名称逐字一致。
- Alias 所属导线的实际网络与 Port 网络一致。
- Port 的绝对热点精确落在 Alias 所属导线的某一真实线段上，包括共同端点。
- Alias 锚点位于事先约定的近端范围内，且确认为重复显示。

同一个结点连接多条线段时，软件可能把 Port 关联到其中另一条线段。此时不能只比较内部导线编号；应由原生审计证明热点确实位于 Alias 所属线段，并检查网络一致。仅靠同页同名或距离相近不足以归并。

若同网同名标签的字框实际覆盖端口图形，可在上述电气条件全部成立时按受控视觉条件归并，记录覆盖证据和调整范围。不能仅凭距离放宽或把所有远处标签一起删除。

保留远处有阅读意义的源标签、不同名标签、电源名称和带局部作用域限定的名称。远处文字有遮挡时调整其显示位置，不能因为整段导线上已有一个 Port 就全部删除。

每个被替代的 Alias 都保留名称、位置、方向、字体、所属导线、源记录及匹配 Port 的追溯表。源标签覆盖检查把“已由 Port 名称替代显示”作为明确状态，不能误记成漏转换。

不要把 Alias 名称改为空来隐藏。显示名缓存即使临时为空，也可能保存重开后恢复。采用其他显示方案时先验证持久性与电气语义。

## 6. 碰撞模型与 bbox 的限制

离线数据库中的文字 bbox 可能为零、未更新或带 dirty 标志。零 bbox 不代表没有重叠；非零旧 bbox 也可能带来假碰撞。

检查器件边界时区分局部缓存边界、实例实际边界和绝对坐标，按当前单元及其旋转／镜像处理。不能把其他单元、隐藏图元或旧缓存的范围当作当前可见本体。

字宽估算、导线方向和器件边界模型用于筛选问题，不能代替 Capture 实际显示。估算碰撞需结合真实图形复核，不为消除一个模型告警随意移动电气对象。

## 7. 分批修改与保存后验收

1. 在独立副本先处理一小组，保存改动前后的显示／电气字段与来源。
2. 计划中的内部对象编号必须来自同一待修改副本。保存、重新包装或重建可能改变编号，不能拿历史编号操作新文件。
3. 修改后确认全部 Port 的位置、真实热点、镜像、旋转及导线覆盖保持；逐页核对完整网名和被替代标签。
4. 保存、关闭并独立重开，读取实际显示属性。不能仅根据修改函数返回成功就认为保存完整。
5. 对最终 DSN 重新导出 PST，与修改前快照及源 AD 的物理引脚网络分组比较，检查缺失、新增、重复、拆网、误并网和每脚网名变化。视觉去重不允许改变连接。
6. 在 Capture 正常阅读缩放与打印预览中逐页检查文字不压线、不遮脚、不越界，密集区放大检查。

记录“原生几何／网络已核”和“GUI 视觉已核”各自状态。尚未完成实际渲染检查时保留待验，不能写成整个工程排版已通过。
