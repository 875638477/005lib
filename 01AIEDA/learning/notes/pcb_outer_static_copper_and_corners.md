# 表层静态铜与铜皮转角规范

用户确认日期：2026-11-01。适用于后续 PCB 设计与整改，与[分层、电机铜与 Kelvin 规范](pcb_layer_motor_routing_rules.md)、[信号转角及孔间内层铜规则](pcb_trace_angles_via_copper_continuity.md)共同执行。本文件是设计和验收规则，不表示已自动配置为 Allegro 原生 DRC。

## 1. TOP、BOTTOM 优先静态铜

- TOP 和 BOTTOM 的铜皮尽量采用静态铜，尤其是电机输出、局部功率连接及已经确定外形的铜区。新建或重做这些铜区时优先选静态方式；内层用途继续按工程层叠要求执行。
- “尽量”是优先原则。确需保留动态铜时，记录网络、层、区域、采用动态方式的具体原因及后续复核项；不能无说明地沿用默认动态方式。
- 现有动态铜转静态前，先更新实际填铜并保存来源，保留网络归属、必要端口、热连接或全连接方式及原生约束。检查转换后的实际铜，不能只转换母边界就宣称等价。
- 静态铜附近移动器件、过孔或走线后，重新处理实际避让并复查间距、板边、连通、孤铜、功率颈部与 Kelvin；不能沿用修改前的验收结果。未完成局部避让的静态铜不得提升为已验收板。

## 2. 铜皮也不留直角

- 铜皮的外露轮廓也不能有直角，包括外凸的 90° 角和凹入的直角缺口；同时避免尖角、窄刺与细碎铜。优先圆弧过渡，或用 45° 倒角形成 135° 的平顺折边。
- 检查实际生成铜的外轮廓、内孔/避让边界、铜区拼接及收窄处。仅把母边界倒角、用其他铜覆盖或改变显示方式，不算完成整改。
- 圆弧与直线的连接处也应平顺，不能在圆弧端部留下新的直角或尖折。折边的长度、圆角半径按空间、承流和制造条件确定，不虚构全板统一数值。
- 倒角或圆角后保留原网络、有效连接、功率最小截面、热焊盘、绝缘间距和板边要求；不能为消角而割断铜桥、缩成不合格细颈或影响采样隔离。
- 器件焊盘、原生热连接/反焊盘、机械边界形成的轮廓应分别识别，检查其与铜区结合后的实际外露边缘。无法在现有约束内消角时，记录网络、层、坐标、轮廓来源和处理限制，列为待处理；不得擅改封装或板框，也不得据此宣称铜皮角已全部通过。

## 3. 保存与验收

1. 记录来源/候选 BRD 哈希，以及各表层铜区的静态/动态类型；动态保留项说明原因。
2. 分别检查实际铜轮廓的转角、孤铜、孔间铜桥、关键电源端口和功率颈部；对角度/圆弧无法可靠读取的对象保留待核实项，不静默跳过。
3. 原生保存后独立重开，复查物理连通、飞线、实际铜、fresh DRC、Kelvin 和受影响接口。DRC=0 不能代替本规范的铜皮类型和轮廓检查。
4. 通用规范保存在 AI 学习库并更新入口索引；工程脚本、候选板、图片和验收证据留在对应工程根。新增说明和文本日志使用 `.md`。
