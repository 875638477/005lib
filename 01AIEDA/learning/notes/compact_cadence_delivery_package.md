# Cadence 工程的小体积交付包

打包先确定范围：当前正式SCH/PCB、用户手工变体、原始AD输入、实际改动脚本、方法、配置和关键记录。旧工作转储、已生成的重复原理图库/PCB库、Git/浏览器/运行依赖、第三方参考工程和历史备份按用途留在原盘，不重复带入交付包。用户特别指定保留的历史原件仍保留本机，不能因缩小交付包而删除。

遍历只接受实际普通文件，不跟随node_modules等junction或符号链接。不要直接用递归通配符打包整个工程：压缩软件可能跟随链接，把盘外依赖带入；已有ZIP/GZ又通常无法靠外层重复压缩大幅减小。

原理图保留DSN的内嵌Design Cache。外部原理图库只收实际来源OLB；PCB按当前实际封装PSM、同名DRA和引用PAD建立依赖闭包，补齐规则允许的via PAD。若PAD有自定义shape/flash，还须收SSM/FSM/BSM等辅助依赖，不能只凭焊盘名字猜测齐全。使用当前文件SHA绑定既有原生导出；缺绑定的少量文件在隔离副本用本机官方导出工具核查，不修改共享原件。只携带工程实际用的一套库，普通库与_pc命名仍按本机既有规则保留。

为每个入包文件记录归档相对路径、来源、大小、mtime及SHA256。暂存目录可以使用同卷硬链接，但不能改写暂存硬链接内容；需要改路径的说明或新配置另生成普通新文件。RAR5可用最高压缩和solid，128MB字典、有限线程；采用UTF16LE+BOM的精确普通文件清单、关闭递归，不使用会丢失路径层级的参数。输出必须为新文件。

压缩后完整解压到新隔离目录，对比完整成员集合，并逐文件核对大小和SHA256；再核原来源未变。验证成功后只删除本轮创建且已核验的暂存/解压文件和空目录，保留压缩包、清单、脚本和小型记录。迁移到另一电脑时，按随包库目录调整Capture及Allegro库路径；收集库文件不等于已经验证另一台电脑的GUI、许可证或整板DRC。
