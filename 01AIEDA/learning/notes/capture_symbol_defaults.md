# Capture 符号单元与引脚完整性规范

用户于 2026-10-19 明确的长期设计偏好：**普通器件优先采用单单元符号，普通 MCU 在一个符号中完整呈现全部引脚；CPU 等复杂器件按实际需要分单元。** 本规范针对 Capture OLB 中的原理图符号及逻辑单元，即用户所说的“原理图封装”。

## 普通器件与 MCU

- 将数据手册对应型号、封装的全部物理引脚放在同一逻辑单元内；按供电、接地、复位、时钟、调试、接口及 GPIO 等功能分组排布，保持可读性。
- 通过调整符号外形、引脚排列、连线和图纸尺寸容纳完整器件；A4 放不下可以扩大纸张，不为迁就 A4 而把普通 MCU 拆成 U1A/U1B 等多个单元。
- 核对每个物理编号、引脚名称和电气类型，完整呈现供电/接地及手册要求的 NC 等引脚，避免通过隐藏或遗漏引脚获得紧凑外观。引脚未使用与手册规定 NC 的处理须分别核对。
- 单单元器件使用正确的完整位号和空单元后缀，避免曾发生的 U101 变成 U1011；不能为拆分符号另造多个独立物理器件。

## CPU 等复杂器件

高引脚数、功能域复杂的 CPU 等器件，可按电源、存储器接口、各 I/O 域等需要拆为多个逻辑单元。各单元仍属于**同一个物理器件、同一个基础位号和同一个 PCB 封装**；必须核对全部物理引脚映射及必要的交换规则，避免遗漏或错误重复。

多单元是按器件结构和可读性作出的选择，不是所有器件的默认做法。第13课的 74HC00 多门示例保留为软件能力与网络作用域练习，不据此将普通 MCU 默认拆分。

## 页面组织与既有工程

单单元符号不意味着整块电路必须画在一页。MCU 外围供电、接口等独立电路可以另页组织；这与把 MCU 本体拆为多个逻辑单元不同。[纸张规范](capture_page_defaults.md)允许按内容扩大图纸。

现有 D/E 整理版的 U1 在 MCU_CORE 页内保持单单元、完整 48 脚；MCU_SUPPLY 页放置外围供电/去耦器件，不是 U1 的另一个单元。本轮只记录并落实后续规则，没有重建既有 CAD 文件。

验收时依次检查：数据手册全针表 → 单元组织理由 → 每针电气定义 → 基础位号/单元后缀 → PCB 封装编号 → 实际网表及显示。相关经验见 [第12课符号与引脚](lesson12_capture_symbols_20261019.md) 和 [第13课多单元与作用域](lesson13_completion_20261019.md)。
