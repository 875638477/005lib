# Allegro 17.2：金手指连接器原生建库和独立载入

本方法用于新建、变更针数的卡座及其配套金手指。先固定原厂尺寸图、具体型号、视图方向和物理编号，再创建符号；同系列外形不能按针数比例缩放。完整制造放行仍由实际工程单独审核。

## 从尺寸证据建立定义

1. 将型号、图纸版本、实际型号对应表行、文件 SHA 和来源固定在工程审核目录。扫描/矢量图须查看清楚的原图；模糊表格先高分辨率渲染局部，不把初看或 OCR 当作最终数字。
2. 分别核卡座焊盘与卡边接触片。记录每面的触点数、针距、缺口前后触点数、缺口宽度、首末中心距、两排中心距、非镀孔及位置。定位孔没有电气针号，不能计入接口针数。
3. 把原厂尺寸、由尺寸链计算的结果、工程配合间隙分开保存。卡座触点的自由间隙不能直接当作推荐板厚。没有配套卡图时，舌宽、插入深度、键槽间隙、板厚、倒角及硬金工艺仍须样品配合验证。
4. 原理图可用与工程一致的分组方式表示物理针序，保留全部实际针号；卡扣或定位键所在的真实分界必须清楚可辨。原理图外框只是逻辑表达，不宣称按机械尺寸绘制。

## 新空 DRA、保存和重编

优先在自有输出目录新建空的 package symbol，不依赖删除旧多针封装的全部对象来保证结果。后台入口采用本机已验证的 `allegro.exe -product Allegro_performance -safe -nographic -symbol package -s <脚本> -p <自有目录> <新DRA路径>`。新建前拒绝覆盖已有同名成果。

在脚本中设定单位、精度、绘图范围及明确的 padpath，然后通过 `axlDBCreatePin` 建立每个有物理编号的接触点；机械定位孔以无针号的机械 pin 创建。不能把 DRA 删除 API 返回、同一会话的 pins 缓存或脚本退出码当成实际针数的唯一证据。

绘制真实装配外形、放置边界、第一脚和键槽标志；按[封装默认规范](package_defaults.md)补齐三项文字及高度。卡边的 board-edge 图形只是配合轮廓参考，真正板框由工程维护。修改尺寸后，不能继续绑定原针数的 STEP；无合格模型则明确无映射，按[3D 持久化方法](allegro_step_model_persistence_and_portable_paths.md)另行验证。

先 `axlSaveDesign` 保存 DRA，再 `axlCompileSymbol` 生成 PSM。保存可能使 dbid 失效，随后重新获取对象。若有单位转换或缩放取整警告，保留原文，并用独立重开后的实际坐标和焊盘尺寸核实影响，不能只因退出码为零而略过。

## 两道独立核验

第一道是在新的无图形进程只读重开 DRA，逐针比较编号、重复数、位置、焊盘名、旋转、上下层和机械属性，核图形、孔、文字锚点、高度与 STEP。焊盘文件存在不能代替真实读回。

第二道是在一个没有该同名封装定义的自有 PCB 副本中首次载入新的 PSM，并实际摆放至少一个实例，保存后再重开，核实际实例的定义、针数和焊盘。只刷新原 PCB 的旧缓存定义、重开 DRA 或看到 PSM 文件，均不能代替这一道。

若 PSM 首次载入失败，先核当前会话的有效搜索路径及依赖。可通过明确的列表设置 `axlSetVariable("psmpath" list(<变体库> <公共库>))` 和 `axlSetVariable("padpath" list(<PAD库>))`，再用 `axlLoadSymbol("PACKAGE" <不含扩展名的小写封装名>)` 区分库载入失败和摆放失败。不要先改已验证的 PSM 掩盖路径错误。未使用的 symdef 可能在保存时被清理，因此必须核实际实例。

`axlDBRefreshId` 只刷新所给对象，不递归刷新其属性中保存的其他 dbid。创建/摆放/保存后，应重新按稳定身份获取 component、symbol、definition 和 pins，不能因旧 `component->symbol` 仍为 nil 就判摆放失败。

## 公共库和同步边界

公共库保存可复用 OLB、DRA、PSM、PAD、已核模型及通用说明；工程输入、副本、具体针表、脚本、日志、参考图和审核清单保留工程目录。同步以仓库相对路径和 SHA/Git blob 身份为依据，保护同名不同内容，不把项目审核目录上传到学习库。

额定电流必须连同测试条件引用。例如“每针 3 A，只有两针通电”不能推导为全部并针数乘以 3 A 的连续载流保证。并针分流、铜厚/铜宽、连接器整体温升与实际负载另作工程验收。

本机接口依据：`share/pcb/examples/skill/DOC/FUNCS/axlLoadSymbol.txt`、`DOC/FUNCS/axlSaveDesign.txt`、`DOC/FUNCS/axlCompileSymbol.txt`，`doc/algroskill/03dbcre8.html` 及 `07dbaccs.html`。本方法只说明核验链路，不代表任何工程已获得生产放行。
