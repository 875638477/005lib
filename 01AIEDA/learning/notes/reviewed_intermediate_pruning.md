# 已审查中间文件的精确删除

适用于用户明确允许放弃历史中间产物、保留当前设计及脚本方法的清理。通用工具为 [prune_reviewed_project_files.py](../scripts/prune_reviewed_project_files.py)。工程盘点、候选、参数、清单和实际回执放在对应工程目录，公共库不存工程副本。

先区分当前正式设计、用户手工变体、原始输入、用户特别指定保留的文件与历史生成物。目录名含 staging、backup、archive 不能单独作为删除依据。源码、参考工程、BIOS、仍需用的运行依赖保留；已生成的旧 CAD、原生转储、渲染预览、失败下载和编译缓存可按实际用途审查。未知文件保留。现有版本的普通库与 `_pc` 库继续并存，清理工程不能附带清理公共库。

大压缩包先列成员。若含独有脚本、方法、配置或旧记录，先提取到工程内的保留目录，逐项读回核对 SHA256，记录原包、成员、目标和大小。只保留文件名或空占位不能代替原字节。当前有效记录和原始核验清单不能误当成大转储删除。派生模型若只需保留结论，可另存明确标注的摘要：保留状态、输入绑定、异常、限制及原文件 SHA；摘要不代替历史逐字段证明。

工具分两步运行：

```powershell
& $python $tool freeze --request $requestJson --plan $planJson
& $python $tool apply --plan $planJson --plan-sha256 $frozenPlanSha256
```

request 指定 root、task_relative、baseline_inventory、selected、protected_files、protected_prefixes 和 allowed_prefixes。盘点中的每项文件须含 relative、size、mtime_ns；links 单独记录，errors 必须为空。selected 为审查后的精确路径和理由，不使用通配符。freeze 绑定所有候选 SHA、重点保护 SHA、完整未选文件的路径/大小/时间，并保护手写代码和 Markdown 等方法文件。输出目录必须位于任务根且独立于被删文件。

apply 需传入实际清单 SHA。它先核对清单、工具身份、全部候选和保护文件；拒绝根、控制目录或源文件经过 junction、符号链接等重解析点。发现盘点后有更改则停止。实际删除逐文件再次核对字节与元数据，写入批次日志，只清理空目录，不递归删除。结束后核对所有未选文件元数据、重点保护 SHA 和链接清单。

本工具直接永久删除清单内文件，不自动新增归档。执行后记录净释放空间、保留位置、删除清单及回执。已删中间物或归档涉及的旧恢复说明须加现状说明，历史报告本身仍保留其当时结论。中断后根据日志核清已完成范围，再生成新计划，不盲目重跑旧计划。保护、变更拒绝、错误清单 SHA、大小写冲突、精确删除和真实重解析点拒绝已在小型隔离样本验证；工程结果以各自回执为准。
