# 公共被动器件封装后缀合并为唯一 _pc 的方法

适用于已明确允许普通两端 R/C/L/FB 按类别和尺寸采用一个标准封装的库整理。工程验证与本机公库维护分开留档；不要把某个工程目录、器件清单或日期写成工具默认值。

## 先冻结范围和用途

逐文件记录 PSM、DRA、Device TXT、PAD、OLB、公共模块 BRD、脚本和环境文件的原路径、长度和 SHA256。分析阶段和原生导出阶段只读公库。输出用独立新目录；改库前检查全量保护表，修改后按允许清单逐项核验。保留原件或可恢复归档、原生报告和重定向清单。

普通两端器件使用 r0402_pc、c0402_pc、l0402_pc、fb0603_pc 等名称。类别必须来自实际符号/器件用途，不能把裸 0402 直接当电阻或电容。尺寸代码还要确认采用英制或公制。既有目标 _pc 定义优先；没有目标才从已核准的通用 base 定义建立公库。不得直接覆盖同名但几何不同的既有用户库。

用户批准的是采用一个标准时，旧版本只因方向、丝印、3D、焊盘宽度或间距不同，仍可归并；这些实际变化必须逐项写入差异表，不能伪称原文件几何完全相同。排阻、三端/四端电感、IC、穿孔、极性/特殊材料电容及特殊脚号需要保留功能区别，不能只凭名称里的四位数字删除。只有两脚且都为 SMT 仍不是全部功能证明，还应结合符号、器件值和实际用途。

原生加载出现穿孔也需要核对器件意图。如果微小 SMT 家族的两个脚距、PLACE_BOUND 和本体轮廓都支持普通贴片，而外部通用 PAD 名被解析为远大于本体的镀槽孔，应记录为疑似 PAD 名碰撞或损坏引用。以冻结证据确认意图后，可按批准范围退役这个异常旧变体并换成正确的标准 SMT；不能把异常孔当作合法功能差异永久保留，也不能为修复一个封装而直接改掉其它器件共享的通用 PAD。旧/新实体尺寸和孔变化必须明确列出。

## 取得完整原生证据

逐 PSM 提取原始单位、精度和绘图范围，再在独立空板以相同参数加载。不得先把全部源量化到低精度后再比较。记录完整符号图形、字体、用户属性、STEP、实际引脚号、每个物理 pad、各层铜/阻焊/钢网及钻孔，并将实际加载 PAD 文件路径与当前 SHA 绑定。板中派生的四层图形不能代替完整 PAD XML 的全部制造字段。

Cadence 17.2 的 axlOpenDesignForBatch 在某些批处理场景会长时间停在重新打开空板这一步。A/B 两个空文件轮换的短 canary 通过，也不能据此认为大批处理可靠。遇到这种情况，采用每个 PSM 一个独立 Allegro 进程：从命令行已打开的空板开始，第一个也是唯一一个 PSM 直接设置单位/范围后加载，完全不调用 reopen。每个进程使用自己的 TEMP、pcbenv、空板和输出目录；为自建进程设置有界超时，保留失败项，不能把缺输出当作不存在或已通过。并行数按机器与许可的实际验证结果决定。

- C:/Program0/Cadence/SPB172/doc/algroskill/14dsnctl.html，axlOpenDesignForBatch（710593）、axlDBChangeDesignUnits（706311）、axlDBChangeDesignExtents（706236）。wf 用于丢弃修改而不确认，l 关闭文件锁；文件不存在可能显示绘图参数窗口。单位与范围函数没有文档化的确认参数，不能把无输出直接解释为单位转换弹窗。

## 引用清单决定能删哪些文件

Capture 要查 Package 默认 PCB Footprint、Cell/视图的显式默认属性、工程 Cache 和每个实例覆盖。FootprintName 等 AD 追溯文本单列，不当作 PCB Footprint 自动改写。共享 R/C 图形不必按 PCB 尺寸拆成不同原理图库，实例保留各自的 Value、NC_、封装和连接。

Allegro 要同时查已放置的真实 symdef 和未放置 component 的逻辑 package。公共 BRD 可能是带网络、走线和过孔的实际电路模块，不是器件调色板。当前能显示，是因为内部嵌入了缓存；删除外部旧名仍会影响日后 Update Symbols 或重新导入网表。旧模块未迁移前，要保留可恢复兼容资产与清楚的引用报告，不能声称所有本机引用已统一。

Device TXT 的 PACKAGE/PINORDER/FUNCTION 通常是同名封装自己的定义，需要与旧 PSM/DRA 一起归档或按核准计划重建。脚本、env、INI、devices.map 要按完整名称 token 搜索；0402 出现在 Value 的尺寸段不能当作确认的 footprint 引用。日志、逗号备份、快捷方式及压缩包分别标记用途，不从纯文本没有匹配推断二进制容器没有引用。

PAD 是多封装共享依赖，不随旧 PSM 名称成批删除。先从保留和新建全部封装收集真实 PAD 引用，再单独评估无引用 PAD。

## 应用和验收

先在副本更新原理图显式封装字段及确需改变的库默认字段，按精确对象路径冻结修改表；原生保存后导出完整有序 XML，仅逆转获准字段后必须与源完全相同。实例没有显式属性时，不得为方便校验写入虚构空值。字体比较需使用完整 LOGFONT 字段，不能仅比字体名称。

已布线板按逐位号映射替换真实 symbol，并保留原有连接对象；实际封装更新后再以新 PST 的 IfSame 同步逻辑 package。Always 虽保位置，仍可能重建路径。验收使用完整物理 pad 的实际 GetConnect 成员分区，并核网络、重复脚号、机械 pad、nil 与空名字 net 对象。不能以零错误日志、相同网表或铜图并集相同替代连接验收。详见 [公共库迁移与 _pc 命名](public_shared_library_migration_pc_naming.md)。

正式保存并独立重开后，枚举全部 design->symdefs，包括 instances 为零的定义，再在全新空目录执行 File → Export → Libraries。该界面对应 dlib；批处理 dump_libraries -ac 输出全部 Package 的 DRA 与 PSM，并默认输出 PAD 依赖。不要复用有旧文件的目录，否则不能判断旧后缀是否再次生成。比对完整定义 stem 集、导出 stem 集和批准目标表，确认旧后缀残留为零。

官方依据：C:/Program0/Cadence/SPB172/share/pcb/batchhelp/dump_libraries.txt；doc/dcoms/dchap.html 的 dlib；doc/algroskill/26logacc.html 的 axlWritePackageFile。删除未使用定义的行为见 doc/algroskill/03dbcre8.html 的 unused symbol definition / Save / Refresh；不要删除仍被组件使用的定义。

只有全部引用迁移、原生重开检查、实际连接与制造几何检查都通过后，才按冻结清单移除旧资产。报告需分别说明已移除、保留功能差异、仍被历史模块引用和失败未核验的项目。

## 扩展到型号前缀与非 R/C 器件

先对全库做名称、长度和完整 SHA 盘点，再列出“型号_已有通用封装”、明确数字复制后缀、标点别名以及完整字节相同的候选。报告分别写全库盘点数、进入原生核验的候选数和实际成功数。不能把“全库名称都看过”写成“每个封装的全部几何都已判重”。对唯一而没有真实别名关系的特殊封装，保留其功能定义。

合并依据分三类记录：完整原生图形相同；编号焊盘、全层制造字段相同但丝印或字体等图形不同；用户批准采用同一标准而实体有明确变化。第三类需要逐引脚位置、PAD、孔径、旋转和实际布线附着迁移计划，不能标成几何相等。通过全字节相同证明的候选也要确认实际加载依赖，避免同名 PAD 被不同路径解析。

SOT23 的三个脚号都存在，仍可能是一边单脚 1、另一边双脚 2/3，和单脚 3 的通用符号不兼容。SO8 带散热焊盘的九个实体 pad 不能并进八 pad 的 SOP。机械孔的 1/2/3/4 与 4/5/6/7、USB 缺键位置和分裂脚号都必须保持。没有准确现成通用库时，按真实编号或结构建立独立语义名称，复制源 PSM/DRA 并独立冷启动验证；不得覆盖已有通用库。

最终 canonical 表要把所有正在使用和准备迁入的目标列为 KEEP。源到目标不得成环，不保留需要再次跳转的多级别名。后续补发现的同名字节群也不能将已确认目标选成待删除文件。所有公共 OLB、DSN 和 BRD 都按完整名称重扫，含未放置器件和实际电路模块；不能只查本工程。

## 路端覆盖需要包含线宽

从实际缓存和真实元件姿态取得原 pad，而不是用旧公库同名文件代替。把目标真实胶囊形、圆角矩形或其它已解析轮廓变换到板坐标，连同每条实际线或弧的半线宽判断源端是否仍接触新 pad；只测端点中心或矩形包围盒会误判。没有网络和对象身份的几何快照只能做保守候选预筛，不直接生成电气修复。

即使所有旧脚中心和路端几何均被新 pad 覆盖，原生数据库也可能没有建立相同附着。仍须比较完整 GetConnect 成员分区，并检查实际源路径到新 pad 的连接对象。修复短线按原网、原层及真实源邻接逐项冻结；验证笔画能落在目标铜内，保存独立重开后再验全板。保留原线和原线宽，不用改画全板路径来掩盖差异。

## 退役执行与备份复用

冻结精确的 PSM、DRA 和同名自引用 Device TXT 文件清单。Device 字段可以用单引号包名称，按实际语法解析 PACKAGE、PINORDER、PINUSE、FUNCTION 的 owner；不把引号当名字的一部分，也不误删引用其它器件的文本。PAD、SHAPE、FLASH 和既有原件、发布件、ZIP 不随这个清单删除。

已验证的备份 ZIP 可直接复用：核归档本身 SHA，再逐成员解压计算完整 SHA 和长度；只为新增成员建立增量归档。dry-run 只核路径、源 SHA 和全量保护表；stage 只做备份与回读；apply 另要求所有待退役名称的工程实例、Cache 默认、公共 OLB/DSN、公共 BRD 的逻辑与放置引用闭合。按精确单文件目录项移除并逐项刷盘记日志，不用通配或递归删除。硬链接的其它目录项不改内容。
