# PCB 信号转角与过孔间内层铜皮规则

适用于后续 PCB 设计及修改。除非用户对具体工程给出不同门槛，信号线拐角执行下列通用标准；器件数据手册、接口时序/阻抗、制造能力和项目其他约束仍须同时满足。本文件是设计及审查规则，不能声称已自动配置为 Allegro 原生 DRC。

## 一、信号线转角

- 信号线不要使用直角或更尖锐的折线。优先采用平滑圆弧；使用折线时，每一处实际中心线的转角内角严格大于 130°，不是大于或等于 130°。
- 角度定义：从拐点分别朝相邻两段远端形成两条射线，取二者 0°～180° 的夹角。直线是 180°，45°方向改变是 135°，直角是 90°。因此通常的 45° 折线满足 >130°；恰为 130° 不通过。
- 优先布线时就选用 45° 或圆弧模式；不得仅把线段拆短、叠铜或使用视觉显示来掩盖锐角。圆弧应检查弧与相邻线段/圆弧的连接处及曲线内部连续性；若连接处有不满足门槛的尖折，仍须整改。不能把圆弧近似成粗分段后误判为实际锐角。
- 从实际数据库读取完整信号中心线，按同网络、同层和实际接续关系逐顶点检查；短线、过孔附近、分支和焊盘引出也要检查。对分支检查每条真实电气走向的两段组合，区分正常 T 形连接与同一路线的连续转弯，不能将两段相同几何的反向直线误判为转角，也不能忽略支路真实尖折。端点在焊盘或元件内部造成无法确定的几何应标“待人工复核”，不悄悄免检。
- 接口的阻抗、耦合、长度、返回路径和实际 DRC 应与转角要求同时满足；修角后重新填铜、更新 DRC 和核对连通，不改变网络归属或破坏 Kelvin / 差分等敏感走线。确因焊盘密度等不能达到门槛的区域须记录层、坐标、网络、角度、原因及用户确认；不得报告全板通过。

## 二、过孔间的内层铜皮

- 摆放过孔时考虑相邻过孔在每一目标内层的实际反焊盘/避让轮廓，留出足够宽的连续铜，使原本应连通的地或电源平面在孔间不被掏空或割断。只满足钻孔孔壁间距或普通过孔到过孔 DRC，不足以证明内层铜条存在。
- 按每层各自的网络、连接模式、实际 padstack、生成铺铜、其他孔及导体的避让和铜区边界判断；异网孔的 anti-pad、同网全连接或热焊盘以及非圆形/盲埋/槽孔均可能不同。应审查所有会影响该平面的邻近过孔组合和孔簇，而非仅相邻两孔或仅看中心距。
- 对同一目标连续平面，两孔之间可承载的完整实际铜条净宽应不小于 `W_min`，并与所需平面实际连通；`W_min` 根据板厂最小铜宽、层叠、热/载流和项目约束确定，取适用要求的严格值。用户或板厂尚未确定时不得虚构数值，也不能仅凭无 DRC 宣称通过；记录待确认参数。
- 对简单圆形、各向同性避让且不受其他障碍影响的预排布，可用 `中心距 >= 实际避让半径1 + 实际避让半径2 + W_min` 作为必要几何估算；半径必须是该层的实际孔避让边界，不是默认钻孔半径。它只作预估，必须对更新填铜后的真实铜几何及连通性复核；局部可用铜还可能被其他障碍、铜区边界、缩颈、热连接或邻近多孔改变。
- 在铺铜确实设计为空白、隔离区、不同网络分区、keepout 或无目标平面的区域，不得错误声称有完整同网铜皮；根据意图标记不适用或待人工判定。对于需要连续平面的区域，检查孔间剩余铜的最小宽度、其两侧与周边同网铜是否接续，以及孔簇对平面和信号返回路径是否造成断口、瓶颈或孤岛。局部跨孔间有铜不等于整层参考路径完整。
- 优先调整过孔位置、组合扇出或减少非必要换层，且不放宽孔壁、铜间距、板边、阻焊、差分、热及其他既有约束。不可通过降低 DRC、缩小避让、制造不达标细铜桥、隐藏标记或强行消除孤岛来制造通过结果。

## 三、验收与复核

1. 记录来源板和候选板哈希，分清项目定义的信号、地、电源及内层目标铜区；确认角度阈值、`W_min`、板厂能力与用户特殊要求。
2. 候选板重铺实际铜后原生保存、独立重开；核对物理连通、未连通飞线、动态铜更新状态、孤立铜、fresh DRC 及生效的规则模式。保留旧问题与新增问题的差异，而非只比较 DRC 总数。
3. 输出每个尖角的网络、层、坐标、真实角度和分类；圆弧需检查端点切向连续性。过孔/孔簇记录对象位置、目标层及网络、实际避让形状、铜条最小净宽、与目标平面连通性及不足原因。对实际铜的任意采样图形应说明精度与覆盖范围。
4. 对尺寸/拓扑取不到、圆弧语义不明确、板厂 `W_min` 未定、参考层有断口等情况列为未验证或待确认；无足够几何证据时不要给出整板通过结论。输出可复核的前后记录、必要截图和设计文件；不要把仿真或温升实测作为仅由几何/DRC推断的结果。
