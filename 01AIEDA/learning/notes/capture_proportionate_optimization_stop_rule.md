# 原理图适度优化：合格即保留，不为优化而优化

版本 APPROPRIATE-20261117.1。此条是原理图设计与审核规则，优先约束紧凑化的改动决策；保留现行库、字向、引脚线、网格、电气和完整文字要求。

## 判断目的与停止条件

优化的目的是让人容易看懂电路、追踪信号与检查功能关系。缩小面积、减少导线长度或产生更多改动都不是独立目标。逐页检查不等于逐页必须修改；不能为了显示工作量或获得更低面积数字重排已经合适的电路。

用户已明确认可近期ADC分压/滤波模块的程度，也认可两页原样复用的3.3V/5V及5VSB转换电路。它们是“已经足够好，应停止继续压缩”的适用正例。公共规则只复用判断方法，不公开工程电路，不把其绝对坐标、行距、器件方向或面积当作通用模板。

当电路功能分组清楚、阅读顺序自然、关键反馈/控制/去耦关系可追踪，文字完整无干涉、局部引线与留白适当时，保留现状。DCDC允许为反馈、补偿、功率流和阅读留出空间；这种必要空间不是浪费。只有明显过长引线、无理由大块空白、模块散乱、文字干涉或明确规则错误，才构成修改理由。达到用户认可的可读程度即停止；不能因为还存在可压缩的几个网格就继续挤压。

## 灵活运用的可复用流程

1. 读取当前源件、实际功能、用户批准参考及锁定范围，先判断现状是否合适。
2. 对拟修改区域写明具体可见问题及预期阅读收益；没有具体收益则保留。区分功能必需的空间和无理由的间隔。
3. 选择保留、局部短线/移位、按功能成组、必要时模块重排中足以解决问题的最小范围。横/竖/混合由电路功能决定，随后按既定方向执行R/C文字规则。
4. 不破坏原理连续性，不把所有器件拆成独立标签表，不缩字/隐字/改针距，不为面积指标继续压缩，不因纸张看起来空而填满。
5. 与当前版本比较实际收益及副作用，达到认可程度后停止；逐页记录“已改及理由”或“保留及理由”，锁定页单列校核。保留也是正常审核结论，不能伪造改动。
6. 原生重开、逐针电气、PCB同步及显示/避让分别报告。用户要求后台时不得以GUI打印弹窗替代后台；显示缺证如实保留，不用面积下降或规则已同步冒充全量显示通过。

## 与紧凑度门禁的关系

COMPACT预算必须是可读且适度的局部方案，不是数学最小面积。用户独立认可的现有布局可作为适用的批准参考；不能把任意当前布局自设为合格预算。对已经合适的区域无需再寻找极限短线方案。只有更短候选带来实质阅读收益且不损害原理/文字，才触发整改；不再采用“只要还能缩短就必须改”的解释。

工程新增用户认可或锁定范围应记录在该工程；公共学习库仅保存本判断流程、适用正例的说明及不含工程电路的通用规则。规则与实际工程落实及GitHub同步三者分别核对。
