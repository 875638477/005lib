## 第 1 章软件角色

Cadence SPB 17.2 通过多个程序承担不同环节。阅读教材时，应先判断所处环节和工具，再对应菜单及文件类型。纸页 10 明确说明，原理图、PCB 和仿真分析分别在不同软件界面中完成。

| 工具或模块 | 教材中的职责 | 来源纸页与 PDF 页 |
| --- | --- | --- |
| OrCAD Capture、OrCAD Capture CIS | 原理图设计；CIS 增加元器件库管理能力 | 2 / 21，10 至 11 / 29 至 30 |
| Design Entry CIS | 教材称其与 OrCAD Capture CIS 相同；以 Allegro 产品入口启动 | 2 / 21，10 至 11 / 29 至 30 |
| Design Entry HDL | 原理图设计，可使用表格、原理图及 Verilog HDL 描述设计 | 2 / 21，11 至 13 / 30 至 32 |
| Library Explorer、Part Developer | 数字元件库管理，以及元器件符号和模型的建立 | 2 / 21 |
| PCB Editor | 完整的 PCB 设计工具，承担 PCB 编辑 | 2 / 21，13 / 32 |
| PCB Router | 布线工具 | 2 / 21 |
| PSpice AD | 原理图仿真 | 2 / 21 |
| PCB SI | PCB 高速互连与信号完整性分析，包括信号、串扰、电源完整性及 EMI 等问题 | 2 / 21，14 至 15 / 33 至 34 |
| Model Integrity | 教材的信号分析环境入口之一 | 14 / 33 |
| Package Designer | 高密度 IC 封装设计 | 2 / 21 |
| Physical Viewer | Allegro 浏览器模块 | 2 / 21 |

教材在纸页 10 列出 Windows 版本 OrCAD Capture 的原理图扩展名为 `.dsn`，元器件库扩展名为 `.olb`。这条属于 Capture 路线，不能据此推定其他工具的库格式。教材第 8 章目录使用 Library Explorer、元器件编辑器等标题，需与第 5 章的“原理图库”区分后再衔接现有库。

## 第 1 章设计流程

纸页 9，即 PDF 第 28 页，将从任务到文档保存的过程归纳为七步。下表按教材顺序记录，并保留其检查环节。

| 步骤 | 本轮理解 | 与元件库工作的联系 |
| --- | --- | --- |
| 1 案例分析 | 先明确设计任务，决定电路及 PCB 规划 | 先确定器件实际用途和设计约束 |
| 2 绘制原理图元器件 | 自带原理图库不能覆盖所有器件，必要时自行建库 | 确定原理图符号及库管理方式 |
| 3 绘制电路原理图 | 放置和连接器件；完成后用 ERC 检查并修正 | 符号要能正确参与电气连接与检查 |
| 4 电路仿真 | 对不确定的电路行为进行验证，也可辅助确定关键参数 | 需要仿真的器件还涉及模型，不能只关注外观 |
| 5 绘制元器件封装 | 现有封装库不能覆盖全部器件，必要时自行建立 | 独立制作 PCB 所需的物理封装 |
| 6 设计 PCB 电路板 | 定义板框和层数，通过网络表转入连接关系，再布局、布线和 DRC | 检查封装是否能进入 PCB 设计流程 |
| 7 文档整理 | 保存原理图、PCB 图和元件清单等资料，便于维护 | 保留可追溯的库文件、验证结果和修改记录 |

表中“与元件库工作的联系”是结合当前任务的理解；前两列来自本章流程。后续实践应同时验证原理图连接和 PCB 物理实现，不能以“图形已画完”作为库制作完成的唯一依据。

## 版本和安装边界

本教材主要演示 Cadence SPB 17.2，截图中可见 `17.2-2016`；现有视频目录标明 16.6。纸页 3 至 5 专门介绍 17.2 新增功能，其中包括新的 Padstack Editor 界面、层叠设置界面、Color Dialog 和焊盘保持相关行为。因此，教材与视频中的按钮、对话框和默认值需要按实际软件版本对应。

本章安装部分为纸页 5 至 9，区分 License Manager 与 OrCAD/Allegro 产品组件，并展示产品和工作目录等设置。本轮仅完成阅读，未据此安装或改动许可、产品选择、路径或配置。纸页 1 的平台介绍和纸页 2 的市场定位属于该教材的版本背景，不作为当前环境的兼容性或选型结论。

纸页 11 对 Capture 与 Capture CIS 的选择给出元器件管理方面的建议；纸页 13 同时提醒，PCB 产品选择会影响主界面选项。跟进现有元件库前，应使用本机实际可用的工具与许可入口来核对工作流。
