## 封装模型与电气符号

纸页 210 至 214 将物理封装的尺寸、焊盘排列和外形，与原理图中的电气表达分开。纸页 211 指出焊盘编号应能区分封装中的各焊盘；纸页 214 强调原理图符号要关联相应 PCB Footprint，才能把设计连接关系带入 PCB。

对当前库工作的应用是：每个器件分别保留原理图符号、封装、焊盘依赖及其来源，核对编号对应关系后再进入板级练习。封装类别名称或文件名只能辅助检索，不能代替机械图和编号表。

## 文件关系

以下关系由教材纸页 212、222、227 与本机官方库开发帮助的文件类型表交叉核对。

| 文件 | 本轮确认的用途 | 后续检查 |
| --- | --- | --- |
| `.dra` | 绘图源文件，在符号编辑模式中创建和修改 | 保存可编辑来源，与生成结果一并留存 |
| `.psm` | Package symbol，用于元件 PCB 封装 | 由相应绘图生成，检查实际编号和图形 |
| `.pad` | Padstack，关联引脚或过孔的焊盘、钻孔和相关层定义 | 检查名称、单位、层字段及依赖 |
| `.ssm` | 自定义 Shape symbol | 异形焊盘等引用时须同时定位其来源和成品 |
| `.fsm` | Flash symbol | 用于相应 Flash 定义；具体用途按所引用的字段核对 |
| `.bsm` | Mechanical symbol | 按机械用途区分，不能当作 Package symbol 使用 |
| `.osm` | Format symbol | 图纸格式类符号 |
| `.txt` | Device 文件相关逻辑信息 | 按实际设计流程判断是否需要，不以扩展名推定内容已正确 |

官方帮助在 Library Development Process 中要求每个 Package pin 关联 Padstack。因此实际创建顺序先明确焊盘，再放置和编号；生成 `.psm` 后仍需要核对其对应的 `.dra` 与依赖版本。

## 建库前需要确定的参数

纸页 218 至 220 展示环境设置和创建入口。已整理的准备项如下。

- 器件完整料号、封装变体、原厂机械图与推荐焊盘图所在位置。
- 实际焊盘数量、编号、间距、尺寸、排列方向和定位标记。
- 单位、精度、坐标原点、绘图范围及格点。
- 每类引脚要使用的 Padstack，以及 Pin 1 是否采用不同的标识或形状。
- 外形、丝印、装配信息、放置边界和高度需要分别表达的内容。

教材的 mil、整数精度、工作区尺寸及例子中的高度是示范参数，不作为当前毫米封装的默认值。`1 mil = 0.0254 mm`，文本输入应连同单位一起记录。

## 向导创建封装

纸页 220 至 222 演示 File → New，Drawing Type 选择 Package symbol (wizard)。流程包括选择封装类型、模板、输入单位与生成单位、参考位号前缀、引脚数量与间距、封装尺寸、默认及 Pin 1 焊盘、原点和生成选项，最后保存绘图和符号。

向导中有“输入尺寸的单位”和“创建符号的单位”两个位置，不能只记录其中一个。Default padstack 与 Padstack to use for pin 1 也分别设置。生成后按实际焊盘数量、位置、编号和尺寸复核，不能把文件名视为自动校验结果。

## 手动创建封装

纸页 223 至 227 演示 Package symbol 模式中的手动流程。

1. File → New，选择 Package symbol，指定绘图名称及输出目录。
2. 在设计参数中确认单位、精度、范围等环境设置。
3. Layout → Pins，选择 Connect 和 Padstack，设置旋转、数组数量、间距、编号增量及编号文字位置。
4. 按坐标放置 Pin 1，再放置其余引脚；逐项确认编号及方向。
5. 添加放置边界并设置高度，按所需层表达外形和装配信息。
6. 添加 RefDes、Device Type 等标签并检查文字层、位置和方向。
7. 保存 `.dra`，使用 Create Symbol 生成 `.psm`；按所采用流程处理 Device 文件。

教材纸页 224 至 226 的 Layout → Pins 与 Labels 属于封装对象操作。纯图形矩形或文字不是带电气编号的引脚，后续检查应针对实际 Pin 对象。

## 层与边界如何区分

| 对象 | 本轮理解与依据 | 后续实践检查 |
| --- | --- | --- |
| 铜焊盘 | Padstack 的导电层几何，用于引脚连接；官方帮助 chap2 的 Regular 定义 | 看实际 Padstack、导电层和 Pin 对象 |
| Soldermask | 与焊盘相关的阻焊定义，独立于铜层 | 检查开窗对应层及尺寸 |
| Pastemask | 与锡膏相关的定义，独立于阻焊 | 按器件和工艺资料核对，不从阻焊值自动推定 |
| Silkscreen | 外形、位号等印刷标识；教材纸页 225 至 226 | 检查文字和图形所属层及可见性 |
| Assembly | 装配相关图形或标签，教材纸页 226 的 Device Type 示例使用该层 | 与丝印和放置边界分别检查 |
| Place Bound 与高度 | 官方帮助 chap3 说明其用于元件占用的空间与高度检查 | 保存对应形状和高度属性，不以一个矩形代替全部层内容 |

官方 17.2 应用说明在 SMD 示例中分别定义 TOP 与 SOLDERMASK_TOP，支持把铜层和阻焊作为不同对象核对；这也与本批视频第 02 讲逐层填写参数的画面对应。[Cadence Padstacks and Allegro SKILL，纸页 13](https://community.cadence.com/cfs-file/__key/communityserver-discussions-components-files/137/MakePadstackInAllegroSkill.pdf)
