## Capture 原理图库

教材第 5.3 节从 OrCAD Capture CIS 内建立 `.olb` 库，与当前工作区的 Capture 库用途直接对应。

| 环节 | 教材操作与字段 | 学到的用途 | 来源纸页 |
| --- | --- | --- | --- |
| 建立库 | File → New → Library | 创建存放原理图元件的 `.olb` 文件 | 108 |
| 打开已有库 | File → Open → Library；工程 Library 节点下 Add File | 将已有 `.olb` 加入库管理环境 | 108 至 109 |
| 建立元件 | Design → New Part | 设置 Name、Part Reference Prefix、PCB Footprint | 109 |
| 划分子部件 | Parts per Pkg、Homogeneous 或 Heterogeneous、Alphabetic 或 Numeric | 让同一个器件按多个符号部分表达 | 109、112 至 113 |
| 绘制外形 | Place → Rectangle，并调整编辑边界 | 根据引脚布局安排符号空间 | 110 |
| 逐个添加引脚 | Place → Pin | 分别填写 Name、Number、Shape、Type | 110 至 111 |
| 批量添加引脚 | Place → Pin Array | 指定起始名称、起始编号、数量、增量和间距，再逐个复核 | 111 至 112 |
| 批量编辑 | 选择引脚后 Edit → Properties 或 Ctrl+E | 在 Browse Spreadsheet 中统一检查名称、编号和电气类型 | 112 |
| 调整可见性 | Part Properties 中 Pin Names Visible、Pin Numbers Visible | 控制图面显示，不改变所代表的引脚身份 | 111 |

纸页 110 明确区分 Name 与 Number：Name 表示引脚名称，Number 要对应实际管脚编号。Shape 是显示线型，Type 是电气类型。这四项应分别记录。教材连接器示例使用 Passive，后续不能把该示例值直接作为所有 IC 引脚的默认选择。

纸页 109 的 PCB Footprint 字段用于填写封装名称。教材允许在尚未建封装时暂空；结合当前工作，我把“进入 PCB 前已完成封装关联”列入后续验证项。

## Library Explorer 的库管理

第 8.1 节展示 Library Explorer，从库项目进入 Build 与 Ref 两个区域，并可调用 Part Developer。它不是第 5.3 节 Capture `.olb` 编辑操作的同一个界面。

纸页 189 描述：Build 区用于创建和修改库，Ref 区用于引用经过校验的库；需要修改引用库时，先导入构建区，完成后再导回参考区。纸页 190 至 192 进一步展示建立库、导入库以及新建元器件条目。

学习后准备采用的管理习惯是：练习中的库放在独立工作目录，验证结果明确后再决定是否加入常用库。此项是对当前工作的应用安排，不表示已经迁移或改动现有库。

## 教材元件创建示例

第 8.4 节纸页 201 至 209 的操作顺序如下。

1. 建立 Package，并添加物理部分 Pack Type。
2. 添加逻辑引脚，区分向量、标量、信号、电源、地及其电气类型。
3. 手动定义或从 Footprint 提取物理引脚编号。
4. 将逻辑引脚逐项映射到物理引脚，教材使用 Map To 按钮。
5. 映射 Global Pins，核对后保存。
6. 生成符号，调整符号中的引脚位置并保存。

这里最有用的结论是：完成符号外观之后，仍需要检查实际引脚编号和封装的对应关系。自动生成符号或导入封装引脚，不能代替对应关系的复核。

## 已发现的教材待核对项

| 编号 | 可定位现象 | 后续处理 |

| B01 | 纸页 203 的向量范围为 MSB 8、LSB 0，按端点包含计算为 9 项；纸页 205 又描述为“8 个 A、O 选项” | 建立向量时按范围和最终表格核对数量，不照抄文字中的数量 |

| B04 | 纸页 206 的映射步骤文字写 A<0> 选择 Number 9；纸页 207 图 8-75 显示 A<0> 对应 1、A<8> 对应 9 | 映射时逐项核对原始编号表，不直接套用这段文字 |
