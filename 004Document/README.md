## 下载大文件

不小于 64 KiB 的现有文档和二进制资料使用 Git LFS，源码与管理文本保留为普通 Git 文件。完整克隆或更新本库时需要安装 Git LFS；在仓库中执行：

```sh
git lfs install
git lfs pull
```

若文件内容仅有 `version https://git-lfs.github.com/spec/v1` 等几行，说明当前拿到的是 LFS 指针，需要拉取对应正文。新增大文件时需同时更新本目录的 `.gitattributes`。

本库保留源码、PCB、驱动、压缩包等配套文件。资料版权和使用范围以原文件说明为准。
