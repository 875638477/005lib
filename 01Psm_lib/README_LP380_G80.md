# LP380-G80-B0R01 公共库定义

本库用于 80 个电气触点的 LXWCONN LP380-G80-B0R01 卡座与配套卡边。可用于工程 PCB 导入；卡边机械配合及负载温升仍须实物验证，当前不得直接作为生产放行依据。

| 用途 | 文件/Package |
| --- | --- |
| 原理图库 | `../01captureLib/MOD41_LP380_80.OLB` |
| 卡座原理图 Package | `LP380_G80_B0R01_SOCKET` |
| 金手指原理图 Package | `LP380_G80_FINGER` |
| 卡座 PCB | `lp380_g80_b0r01_socket.dra` / `.psm` |
| 金手指 PCB | `lp380_g80_finger.dra` / `.psm` |

原理图均为实际 1～80 脚，奇偶两侧表达；定位键位于 44/45 之间，即两面第 22/23 个触点之间。不同用途复用相同卡座和键槽不会产生机械防误插功能。

## 原厂依据与卡座

依据 LXWCONN `LP380-xxx-B0R01`、Rev A、2020-03-25 原厂尺寸图的 **POSITION 80** 行，立创商品为 C52269383。[官方分销商原厂 PDF](https://datasheet.lcsc.com/datasheet/pdf/4d5845ea1e2bf04b5cd09ce0f3cd8ed3.pdf?productCode=C52269383)。已核 PDF SHA256：`ef9539cb520cfce77bc07494f20bb965be6808f62b3ca95e974104f049c28b2f`。

全部尺寸为 mm。图纸表列 A=39.80、B=36.60、C=18.90、D=15.70、E=16.80、F=34.40、G=37.40。封装 X 原点为首末触点中心距的中点，Y 原点为两排中心线。

- 每面 40 个触点，正常节距 0.80；键前每面 22 个、键后每面 18 个。
- 首末触点 X=-17.20/+17.20；键前最后 X=-0.40，键后最先 X=+3.60，两中心间隔 4.00。
- 卡座奇数脚 Y=-1.70、偶数脚 Y=+1.70；焊盘为 0.50×1.20，外侧跨距 4.60。
- 两个无针号定位孔：(-18.70,-1.50) 和 (+18.70,0)，非镀通孔径 1.27。
- 装配本体外形 39.80×7.00；定位键宽 2.00，X=0.60～2.60。放置边界为 X±20.40、Y±4.00。
- 截面名义高度 7.98；当前高度上限使用图纸一般公差预留后的 8.23。没有绑定未经验证的 3D 模型。

原厂注明 **3 A per pin，ONLY TWO PINS POWERED**。没有取得全部触点同时载流时的降额曲线，不能把并针数直接乘以 3 A 宣称连续额定能力。

## 金手指的工程配合设计

金手指继承相同 X 位置，奇数脚在 TOP、偶数脚在 BOTTOM，铜片宽 0.45、长 2.60，中心 Y=2.80；每面共 40 片。原点 Y=0 为卡边。

以下是工程配合假设，**不是原厂配套卡尺寸图**：

- 卡舌宽 36.40、X±18.20，对卡座 B36.60 留总计 0.20 的间隙。
- 键槽 X=0.50～2.70、宽 2.20，对 2.00 键宽留总计 0.20 的间隙。
- 键槽深 6.50；卡舌肩部 Y=7.00。
- 板厚目标 1.60，尚未取得该具体型号的原厂推荐配套板厚及公差。

卡舌参考折线为 `(-18.2,7) → (-18.2,0) → (0.5,0) → (0.5,6.5) → (2.7,6.5) → (2.7,0) → (18.2,0) → (18.2,7)`，当前为直线轮廓。工程须另核圆角/铣刀可达性、插入深度、板厚公差、接触片长度、硬金厚度、倒角及实际插拔配合。

## PAD 依赖与验证范围

依赖公共 `../01Pad_lib/` 中的 `lp380_smd050x120.pad`、`lp380_npth127.pad`、`lp380_finger_top045x260.pad`、`lp380_finger_bot045x260.pad`，没有新建重复 PAD。

DRA 已从新空 package 创建、原生保存及编译；独立重开核对 80 个唯一电气脚、卡座两个机械孔、实际焊盘层/尺寸/坐标、三项文字锚点和空 STEP 映射。工程首次新载入 PSM、网表和实例验证另由对应工程保留证据。本说明不包含任何主板的专用针功能分配。

通用操作与首次载入检查见[原生建库方法](../01AIEDA/learning/notes/allegro_cardedge_native_library_creation.md)。
