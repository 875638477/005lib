# 机械笼子说明

## 1. 功能

电源笼子提供：

- 两只 Common Slot 电源的导轨与定位
- 插拔行程与防反插（依赖键位/导轨宽度）
- EMI 弹簧指/挡板（若从服务器拆件复用）
- 与背板的螺丝固定界面
- 进风/出风通道对齐模块风扇

## 2. 获取方式

| 方式 | 说明 |
| --- | --- |
| 拆机件 | 从 HP/HPE 双电源机箱拆下笼子+原背板，做逆向参考 |
| 淘宝/二手 | 搜 “Common Slot 电源笼子 / 服务器电源位” |
| 自制钣金 | 按模块外形做 U 形导轨 + 后部安装背板 |

## 3. 模块大致外形（需实测）

DPS-1200FB 为标准 Common Slot 尺寸量级：宽约一卡槽、深较长、后部金手指。不同厂商公差略有差异。**开模前用卡尺量你手里的两台电源与目标笼子。**

关键尺寸要量：

1. 模块宽度 / 高度 / 长度
2. 金手指相对底面与侧面的偏移
3. 两槽中心距
4. 背板螺丝孔相对金手指中心线的位置
5. 插入深度（插座接触位置）

## 4. 装配顺序建议

1. 先把背板固定到笼子
2. 空载检查插座平行度
3. 无电插拔模块，感觉卡滞则先改机械
4. 再接线做电气测试

## 5. 风道

- 不要让输出线缆挡住出风口
- 双路满载时风扇噪声大，实验室可外加进风
- 若做静音改造（降风扇转速），需 PMBus/硬件改法并监控温度，超出本 Rev A 范围
