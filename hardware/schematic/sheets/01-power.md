# Sheet 01 — 功率汇流

```text
                 J1 (SLOT A)                      J2 (SLOT B)
              +12V pins                         +12V pins
                  │                                 │
                  │                                 │
                  ▼                                 ▼
               V12A ──────────────┬──────────────── V12B
                                  │
                                  ▼
                             VBUS_12V
                                  │
                     ┌────────────┼────────────┐
                     │            │            │
                   Cbulk       Ccer xN       TVS(opt)
                     │            │            │
                     └────────────┼────────────┘
                                  │
                                  ▼
                            OUT + 铜柱
                                  │
                             系统负载
                                  │
                            OUT - 铜柱
                                  │
                                  ▼
                                PGND
                                  ▲
              GND pins J1 ────────┴──────── GND pins J2
```

设计要点：

- Rev A：`V12A`/`V12B` 直接短到 `VBUS_12V`
- 每槽插座旁至少 4–8 颗 10µF/25V
- 母排中部放大容量电解/固态电容
- 铜柱尽量靠近母排中心，减小左右环路不对称
